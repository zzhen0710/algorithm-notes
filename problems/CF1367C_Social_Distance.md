# CF 1367C — Social Distance

题目：[Codeforces 1367C](https://codeforces.com/problemset/problem/1367/C)。分类：贪心、连续零段、区间约束转化。

收录原因：建立从“逐点尝试放置”转向“先求可行域”的视角：把固定约束转成不可用范围，再判断剩余部分能否独立求解，减少对具体过程的模拟。

## 题意与核心收获

长度为 `n` 的二进制串，任意两个 `1` 之间至少有 `k` 个 `0`，即下标差严格大于 `k`。初始串已经满足条件，求最多还能添加多少个 `1`。约束：`1 <= k <= n <= 200000`，所有测试的 `n` 之和不超过 `200000`。

> 把已有 `1` 左右 `k` 个位置假想标成不可用，缩小可用区间，再计算各段还能容纳多少个新 `1`。

不需要模拟扩散，也不真正删除字符。下标与距离仍按原串计算；剩余位置只是候选位置，**新放的 `1` 之间仍需保持间距**，不能任意填满。

## 个人做法：三类空段分别计算

原实现保留三分类逻辑，仅整理排版与注释；改进实现统一扫描连续零段。

令 `D = k + 1`，相邻两个新 `1` 的最小下标差为 `D`。

| 空段类型 | 原零段长度 | 处理方式 |
| --- | --- | --- |
| 左端或右端 | `m` | 一侧受已有 `1` 限制，贡献 `m / D`（整数除法） |
| 两个已有 `1` 之间 | `m` | 两侧各扣除 `k`，剩余长度 `L = max(0, m - 2*k)` |
| 全零串 | `n` | 不受已有点限制，剩余长度 `L = n` |

剩余区间长为 `L` 时，从其最左侧开始，每隔 `D` 放一个：`L=0` 贡献为 `0`；`L>0` 贡献为 `ceil(L / D)`。单侧限制的零段也可以先扣除 `k`，所得计数与表中 `m / D` 相同。

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
using pii = pair<int, int>;
using pll = pair<ll, ll>;

int n, k;
string s;

int get_l() { // 第一个已有 1；全零时返回 n
    for (int i = 0; i < n; ++i) {
        if (s[i] == '1') return i;
    }
    return n;
}

int get_r() { // 最后一个已有 1；全零时返回 -1
    for (int i = n - 1; i >= 0; --i) {
        if (s[i] == '1') return i;
    }
    return -1;
}

int get_lcnt(int l) {
    return l / (k + 1); // 左端零段：只有右侧已有 1 的限制
}

int get_rcnt(int r) {
    return (n - r - 1) / (k + 1); // 右端零段：只有左侧限制
}

int get_midcnt(int l, int r) {
    vector<int> pos; // 保存已有 1 的位置，分别计算相邻空段
    for (int i = l; i <= r; ++i) {
        if (s[i] == '1') pos.push_back(i);
    }
    int cnt = 0;
    for (int i = 0; i < pos.size() - 1; ++i) {
        int range = pos[i + 1] - pos[i] - 1 - 2 * k; // 扣除两侧禁区
        cnt += range / (k + 1) + (range % (k + 1) > 0); // 原计数式保留
    }
    return cnt;
}

void solve() {
    cin >> n >> k >> s;
    int l = get_l();
    int r = get_r();
    int cnt = 0;
    if (r == -1) { // 没有已有 1，整个数组是一个可用区间
        cnt = n / (k + 1) + (n % (k + 1) > 0);
    } else {
        cnt = get_lcnt(l) + get_rcnt(r);
        if (l != r) { // 至少两个已有 1 才计算中间段
            cnt += get_midcnt(l, r);
        }
    }
    cout << cnt << '\n';
}

int main() {
#ifdef LOCAL
    freopen("input.txt", "r", stdin);
#endif
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T; // 多组测试；各次 solve 中的局部状态重新初始化
    cin >> T;
    while (T--) {
        solve();
    }
    return 0;
}
```

时间 `O(n)`；额外空间 `O(n)`，主要来自保存已有 `1` 位置的 `pos`，不计输入字符串。

原式的两个细节：

- 中间 `range` 可以为负。题目保证初始合法，所以中间零段至少长 `k`，即 `range >= -k`；C++ 整数除法向零截断，原计数式在这段负数范围内仍得到 `0`。这不是本题中的错误，但依赖了输入条件，显式判断非正长度更直观。
- `i < pos.size() - 1` 有有符号/无符号比较警告。本程序通过 `l != r` 保证调用时至少有两个位置，因此不构成本题的空容器错误；独立复用时可改为 `i + 1 < (int)pos.size()`，减少边界依赖。

## 改进实现：统一扫描连续零段

三类空段的共同对象都是**一个极大连续零段**，区别只在于左、右邻居是否存在。扫描得到半开区间 `[l, i)`：

1. 原长度为 `i - l`。
2. 若 `l > 0`，左邻一定是已有 `1`，扣除左侧 `k` 个禁用位置。
3. 若 `i < n`，右邻一定是已有 `1`，再扣除右侧 `k` 个位置。
4. 有效长度非正则贡献为 `0`，否则按相同间隔计算容量。

这也自然包含全零串：左右均没有已有 `1`，无需额外分支。

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
using pii = pair<int, int>;
using pll = pair<ll, ll>;

int n, k;
string s;

int get_cnt(int len) {
    if (len <= 0) return 0; // 两侧禁区可能重叠，此时无可用位置
    return (len + k) / (k + 1); // ceil(len / (k+1))，从最左侧开始放
}

void solve() {
    cin >> n >> k >> s;
    int cnt = 0;

    for (int i = 0; i < n;) {
        if (s[i] == '1') {
            ++i;
            continue;
        }

        int l = i;
        while (i < n && s[i] == '0') ++i;
        // 原零段为 [l, i)，i 是第一个非零位置或 n。
        int len = i - l;
        if (l > 0) len -= k; // 左邻已有 1，扣除左侧影响
        if (i < n) len -= k; // 右邻已有 1，扣除右侧影响
        cnt += get_cnt(len);
    }

    cout << cnt << '\n';
}

int main() {
#ifdef LOCAL
    freopen("input.txt", "r", stdin);
#endif
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int T;
    cin >> T;
    while (T--) {
        solve();
    }
    return 0;
}
```

时间 `O(n)`，额外空间 `O(1)`，不计输入字符串。内层扫描只前进，所有零段累计访问 `n` 个位置，不是二重循环的 `O(n²)`。

## 为什么可以这样计数

**段内最优：** 长度为 `L>0` 的可用区间，把第一个新 `1` 放在最左侧，再每隔 `D` 放一个，数量为 `1 + (L-1)/D`，等价于 `(L+k)/(k+1)`。把任意方案的第一个点左移到区间起点，不会压缩右侧空间；后续依次尽早放置，同样不会减少可放数量。

**段间独立：** 以一个已有 `1` 的位置 `p` 为界，左段最右候选点至多为 `p-k-1`，右段最左候选点至少为 `p+k+1`，二者距离至少为 `2k+2`，不会互相冲突。因此各零段最优数量可以相加。不能只看到“有一段不可用位置”就默认两侧独立，迁移时要重新证明。

## 进步空间与如何想到

| 比较 | 个人三分类 | 统一零段 |
| --- | --- | --- |
| 对象 | 首尾零段、相邻两个 `1` 的中间段 | 所有极大连续零段 |
| 边界表达 | 单独函数与全零分支 | 左右邻居是否存在 |
| 工作量 | 多次线性扫描，记录位置 | 一次扫描，常数辅助空间 |
| 改进重点 | 公式正确，分类清楚 | 合并重复逻辑，显式处理禁区重叠 |

原方法已经是线性时间，改进不在时间复杂度降阶，而在**找到分类背后的共同对象**。发现路径：三种情况都在处理连续零段 → 差别仅是受几侧影响 → 将影响量先从长度中扣掉 → 剩余段统一使用同一个容量函数。

边界重点：全零、只有一个 `1`、首尾为 `1`、禁区恰好覆盖或重叠、`k=n`。若题目不保证初始合法，还需另行检查已有点之间的间距；本实现不会修复不合法输入。

两版均用 C++17、`-O2 -Wall -Wextra` 编译。原版有上文的有符号/无符号比较警告，统一版无警告；均通过原题 6 组样例、2,304 个合法小输入的独立穷举核验，以及 4 组 `n=200000` 边界。
