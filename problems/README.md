# Problems

从独立刷题、比赛或补题过程中筛选并专门积累的好题与复盘。

不记录全部刷题历史。收录依据是题目带来的长期学习价值，例如巧妙构造、关键反例、意外转化、重要技巧或暴露出的思维问题；难度高、代码长或跨专题本身不构成收录理由。

## 与知识笔记的分工

- 为学习某项知识安排的配套典题留在 [Notes](../notes/README.md)，原 AC、完善 AC 和改进分析完整写在该章节，不迁入本目录，也不在这里重复建立题目索引。
- 本目录的题目来自独立做题过程中主动筛选的积累，参考现有 [CF 2271B — MEX Game](CF_MEX_Game.md)：围绕真实思考记录初始方案、错误、个人 AC、进一步推导和改进实现。
- 归档按题目收录的来源与目的决定，不按题解长度或涉及的知识点数量决定。知识笔记需要引用这里的题目时，可简要说明用途并链接既有正文。
- 每题按实际需要记录题意与约束、个人思路和实现、核验依据、完善方案、进步空间，以及从题目线索发现改进的过程。不把助手解法写成个人经历，整理版与修正版明确区分。
- “完美 AC”表示充分推敲后的完善版本，不默认唯一最优；仅经静态分析或本地测试的代码标为“改进实现”，平台通过依据确认后再标 AC。原做法已经合适时不制造第二份代码。
- 可迁移的识别与建模方法提炼到 [Patterns](../patterns/README.md)，稳定可复用实现关联 [Templates](../templates/README.md)；题目正文保留原处，抽取内容与来源互链。
