# CF 2276C — Subarrays

题目：[Codeforces 2276C](https://codeforces.com/contest/2276/problem/C)。来源：Educational Codeforces Round 195 比赛复盘。分类：前缀和、同余、频次统计。

收录原因：学会把多重约束拆成“哪些历史状态可以参与”和“参与后按什么条件匹配”，通过控制状态的加入时机，在一次扫描中完成区间计数。

## 题目模型

给定正整数数组，统计同时满足以下条件的连续子数组：

- 元素和能被 $k$ 整除；
- 长度**严格大于** $k$。

约束：$1\le k<n\le2\times10^5$，$1\le a_i\le10^9$，多组数据的 $n$ 之和不超过 $2\times10^5$。

## 从区间条件转成前缀配对

设 $P_i$ 为前 $i$ 项之和，$P_0=0$。把左端点前的位置记为 $j=l-1$，区间就对应两个前缀 $P_j$ 与 $P_r$。

### 1. 整除条件：只需匹配相同余数

从带余除法出发，分别把两个前缀和写成“商乘模数，再加余数”：

$$
P_r=q_r k+s_r,\qquad P_j=q_j k+s_j,
\qquad 0\le s_r,s_j<k
$$

其中 $q_r,q_j$ 是商，$s_r,s_j$ 是余数。两式相减：

$$
P_r-P_j=(q_r-q_j)k+(s_r-s_j)
$$

第一项一定能被 $k$ 整除，因此是否整除只取决于**余数之差**。

- **余数相同 ⇒ 差能整除。** 当 $s_r=s_j$ 时，余数之差为 $0$，整个差就是 $k$ 的整数倍。
- **差能整除 ⇒ 余数相同。** 若整个差能被 $k$ 整除，减去第一项后，$s_r-s_j$ 也必须是 $k$ 的整数倍。但两个余数都在 $[0,k-1]$，所以：

$$
-(k-1)\le s_r-s_j\le k-1
$$

这个范围内唯一的 $k$ 的整数倍是 $0$，因此只能有 $s_r=s_j$。

这就是本题使用的同余性质：**两个整数模 $k$ 的余数相同，当且仅当它们的差能被 $k$ 整除。** 代回区间和得到：

$$
(P_r-P_j)\bmod k=0
\iff P_r\bmod k=P_j\bmod k
$$

因此固定右端点 $r$ 后，不必逐个求区间和，只需统计**合法历史前缀中，与当前前缀同余的个数**。

### 2. 长度条件：决定前缀何时进入计数表

区间长度是 $r-j$，所以：

$$
r-j>k
\iff j\le r-k-1
$$

> **同余决定查哪个桶，长度决定哪些前缀能入桶。** 两个条件分别处理，不必在每次匹配时重新检查长度。

当 $r$ 从小到大移动，允许参与的前缀下标范围不断扩大。每轮只新增下标 $r-k-1$，之前加入的前缀仍然合法，**无需删除**。

## 变量与执行流程

- `pre[i]`：前 $i$ 项的和；下标范围为 `0..n`，第 `0` 项是空前缀。
- `cnt[v]`：**当前已满足长度条件**、余数为 `v` 的前缀个数；余数只在 `0..k-1`，因此容量为 `k`，与元素最大值无关。
- `r`：当前子数组的右端点；最短合法长度为 $k+1$，从 `k+1` 开始枚举。
- `ans`：已经统计的合法子数组总数，使用 `ll`。

执行顺序：

1. 读入数组，建立前缀和。
2. 枚举右端点 `r`，将刚获得资格的 `pre[r-k-1]` 加入对应余数桶。
3. 查询 `cnt[pre[r] % k]`，累加以 `r` 结尾的全部合法区间。
4. 右端点继续右移，复用已经建立的频次表。

## 我的实现

保留原实现逻辑，仅调整排版并补充过程注释。通用头文件、类型别名与多测入口沿用[竞赛基础模板](../templates/cpp-contest-template/README.md)，其中 `ll` 为 `long long`。

```cpp
const int maxx = 2e5 + 5;
ll pre[maxx]; // 全局数组初始为 0，pre[0] 始终保留为空前缀

void solve() {
    int n, k;
    cin >> n >> k;

    for (int i = 1; i <= n; ++i) {
        cin >> pre[i]; // 先覆盖旧值，再构造本组前缀和
        pre[i] += pre[i - 1];
    }

    vector<int> cnt(k);
    ll ans = 0;

    for (int r = k + 1; r <= n; ++r) {
        // j=r-k-1 刚好对应长度 k+1，先纳入当前合法范围
        ++cnt[pre[r - k - 1] % k];

        // 桶内所有前缀均满足长度条件，同余即可组成合法区间
        ans += cnt[pre[r] % k];
    }

    cout << ans << '\n';
}
```

## 用一组数据看加入时机

取 $a=[2,1,3,1,4]$，$k=2$，前缀余数依次为 $[0,0,1,0,1,1]$，包含空前缀。

| 右端点 `r` | 新加入的前缀下标 | 当前合法前缀下标 | 查询的余数 | 本轮贡献 |
| --- | --- | --- | --- | --- |
| 3 | 0 | `0` | 0 | 1：区间 $[1,3]$ |
| 4 | 1 | `0..1` | 1 | 0 |
| 5 | 2 | `0..2` | 1 | 1：区间 $[3,5]$ |

最终答案为 $2$。虽然前缀余数已经全部算出，**频次表只能保存当前获得资格的那部分**，不能提前统计全部前缀。

## 正确性与复杂度

回答当前右端点前，频次表恰好包含下标 $0..r-k-1$ 的前缀：首次加入 $P_0$；以后每轮新增一个边界前缀，旧前缀持续合法。

因此每次查询得到的配对都满足长度限制；同余又保证区间和能被 $k$ 整除。反过来，任何合法区间的前缀下标都在该范围内，并且落在被查询的桶中，必然被统计。

每个区间只在自己的右端点被统计一次，既不遗漏，也不重复。

时间为 $O(n+k)=O(n)$，按有效数据规模使用 $O(n+k)$ 空间；原实现为前缀数组固定预留 `maxx` 个槽位。每个输入元素都需要读入，线性时间已经最优，不需要另写排序、哈希或二分版。

## 易错边界

这些是实现时需要核对的边界，不代表比赛中实际出现过这些错误。

- **严格大于不是大于等于。** 长度下界为 $k+1$，新加入的是 `r-k-1`，不是 `r-k`。
- **先加入，再查询。** 新加入的前缀本轮已经合法；调换顺序会漏掉长度恰好为 $k+1$ 的区间。例如 $k=1$、数组 $[1,1]$，应计入整个数组。
- **空前缀也要参与。** 首轮自然加入 `pre[0]`，才能统计从第一个元素开始的区间；无需再提前设置 `cnt[0]=1`，否则会重复加入。
- **保留频次，不能只记是否出现。** 多个不同前缀可以同余，它们对应不同左端点，都需要贡献答案。
- **前缀和与答案都需要 `ll`。** 前缀和最大为 $2\times10^{14}$；当 $k=1$ 时答案为 $n(n-1)/2$，最大为 $19\,999\,900\,000$。单桶频次不超过 $n$，`int` 足够。
- **多测不需要清空整张全局表。** 本组 `pre[1..n]` 读入时逐项覆盖，`pre[0]` 从未修改，`cnt` 每组重新创建；未访问的旧数组尾部不影响结果。

题目保证元素为正，因此 C++ 的 `% k` 可直接作为下标。如果以后允许负数，应将余数规范到 `0..k-1`，不能照搬负余数作数组下标。

## 如何想到与进步空间

```text
枚举每个区间，重复检查区间和与长度
→ 用两个前缀表示区间
→ 整除变成同余，按余数聚合历史前缀
→ 把长度条件解成前缀下标上界
→ 只让合法前缀进入频次表，每轮直接查询
```

**前缀和不只用于多次区间求和，也可以把区间条件改写成两个状态之间的关系。** 本题虽然顺序扫描，仍需要历史前缀参与配对，不能仅因“顺序遍历”就省去这些历史信息。

原实现已经简洁且达到最优时间复杂度。可选的状态精简是只保存每个前缀的余数，而非完整前缀和；但不会改善渐进复杂度，当前数值范围也不会溢出，不必为此另存一份重复代码。

可迁移的切入点是**先控制参与资格，再在合法状态中做匹配**：

- 若要求长度至少为 $L$，固定右端点时只加入下标不超过 $r-L$ 的前缀。
- 若长度还不能超过 $R$，合法下标为 $[r-R,r-L]$，需要同时加入新前缀、移除过期前缀，形成频次窗口。

相关知识：[前缀和](../notes/02-sequence-techniques/01-prefix-sum.md#2-一维前缀和状态与推导)、[滑动窗口](../notes/02-sequence-techniques/05-sliding-window.md#5-频次窗口出现次数与种类数)。本题只有长度下限，历史候选不断增加；并非所有频次维护都需要收缩窗口。
