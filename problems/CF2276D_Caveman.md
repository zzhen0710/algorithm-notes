# CF 2276D — Caveman

题目：[Codeforces 2276D](https://codeforces.com/problemset/problem/2276/D)。分类：图的结构、度数、方案分类。

收录原因：当问题只区分“没有、极少、很多”时，可以放弃精确计数，转而寻找方案被完全锁定的特殊结构；再证明其他结构一定保留额外自由度。

## 题目模型与条件

给无向简单图的每个点染红色或蓝色，要求**每个点至少有一个异色邻居**。两种方案只要有一个点的颜色不同，就算不同。

- 无合法方案：输出 `Brain Melt`。
- 方案数为 1 或 2：输出对应数量。
- 方案数超过 2：输出 `Many`。

约束：$3\le n\le3\times10^5$，$0\le m\le\min(n(n-1)/2,3\times10^5)$，**没有自环、没有重边**；多测的 $n$ 之和、$m$ 之和分别不超过 $3\times10^5$。

### 先区分：不是二分图判定

[二分图染色](../notes/06-graph-and-tree/02-bipartite-coloring.md)要求**每条边两端都异色**。本题只要求**每个点找到至少一个异色邻居**，其他邻居同色也没有关系。

例如三角形不是二分图，但染成“两红一蓝”时，每个点都能找到异色邻居，因此有合法方案。

**给图增加边不会破坏已有合法方案**：原来满足条件的异色邻居仍然存在。这一点可以用于构造和扩展方案。

## 从方案数量转向结构分类

### 1. 为什么不可能恰好只有 1 种

对任意合法方案，将所有红色与蓝色互换，异色关系完全不变，所以仍然合法。

全图至少有一个点，交换后的方案一定与原方案不同。因此方案成对出现，**答案不会为 1**。

### 2. 孤立点：无法满足最低要求

度数为 0 的点没有邻居，不可能找到异色邻居。

所以只要存在孤立点，就输出 `Brain Melt`。没有孤立点时为什么一定有解，会在后面的扩展构造中一并说明。

### 3. 星形图：选择中心颜色后，其余全部被迫确定

[星形图的定义与图示](../notes/06-graph-and-tree/01-graph-basics.md#常见树形星形树)：一个中心连接其他所有点，叶子之间没有边。

每个叶子只有中心这一个邻居，因此**叶子必须与中心异色**。

1. 中心选红色，所有叶子只能为蓝色。
2. 中心选蓝色，所有叶子只能为红色。

两种方案都满足中心的要求，且没有其他选择，因此恰好为 2。

> **叶子将局部选择锁死；一个中心把所有局部约束连成同一个整体。** 不是有叶子就只有 2 种，而是整张图必须被这一个中心统一约束。

### 4. 为什么没有孤立点、又不是星形时一定为 Many

只需证明**至少有 4 种合法方案**，不必求精确数量。

#### 情况一：能找到两条没有公共端点的边

设这两条边为 $(a,b)$ 和 $(c,d)$。

- 让 `a、b` 异色，有 2 种选择。
- 让 `c、d` 异色，也有 2 种选择。
- 四个端点互不重合，所以这两次选择相互独立，得到 $2\times2=4$ 种初始染色。

此时四个点各自已经有异色邻居。还需要说明：**每种初始染色都能扩展到全图。**

1. 若一个未染色点有已染色邻居，就将它染成该邻居的反色。新点立刻满足要求，旧点的满足状态也不会失去。
2. 重复扩展，直到这些连通块全部染完。
3. 若还有未处理的连通块，由于没有孤立点，其中一定存在一条边。先将这条边两端染成异色，再按同样方法扩展。

因此四种初始选择都能成为完整方案，而且端点颜色仍不同，**至少有 4 种完整方案**。扩展时不要求所有边异色，已有异色邻居就足够。

这同时证明：任意没有孤立点的图，都能从每块的一条边开始得到合法方案。

#### 情况二：任意两条边都有公共端点

没有孤立点且 $n\ge3$。若每个点的度数都为 1，图至少包含两条互不相接的边，属于情况一。因此这里可以取两条相接的边 $(a,b)、(b,c)$。

- 若所有边都经过 `b`，无孤立点保证其他点都与 `b` 相连，整张图就是星形。
- 若存在不经过 `b` 的边，为了同时与上述两条边相接，它只能是 $(a,c)$，三点构成三角形。

此时不能再有三角形外的点：外部点若有边，连接三角形中的任意一个点，都会与另外两个点之间的边不相接；连接其他外部点也会产生不相接的边。两者都与本情况矛盾，而孤立点又已排除。

因此非星形时只剩**三角形**。它的全部染色共有 $2^3=8$ 种，排除全红、全蓝后，其余 6 种都合法，所以仍为 `Many`。

**分类已经穷尽：无孤立点时，星形恰好 2 种；其他图一定多于 2 种。**

## 度数为何足够判定星形

本题是无向简单图。若存在一个点的度数为 $n-1$，它就连接了其他全部点。

若剩下 $n-1$ 个点的度数全部为 1，它们唯一的边只能连向这个中心，也不可能再有叶子之间的边。因此图恰好是星形。

将有效度数排序后：

- `deg[1]==0`：存在孤立点。
- `deg[n]==n-1`：最大度数对应一个连接所有点的中心。
- `deg[n-1]==1`：第二大度数为 1；中心已经保证其余点的度数至少为 1，所以其余点全为叶子。

**一般的度数序列不能唯一确定图；这里是已经证明这组特殊度数足以确定星形。** 同样，只有 `m==n-1` 不够：四个点的链有 3 条边，却不是星形。

## 原实现

保留原逻辑，仅调整排版和注释。通用框架沿用[竞赛基础模板](../templates/01-basic-problem-solving/cpp-contest-template/README.md)，继续读取多测，不重复展示 `main()`。

### 状态与执行流程

- `deg[u]`：点 `u` 的度数；按点数分配 `n+1`，有效点编号为 **1-based 的 `1..n`**。
- 每读入一条无向边，两端度数各加 1；只需结构统计，不必存邻接表。
- 排序后，下标表示度数排名，**不再对应原点编号**；本题之后不需要恢复点身份。
- 依次判孤立点、星形、其余情况。局部数组每组重新初始化，不需另清理。

```cpp
void solve() {
    int n, m;
    cin >> n >> m;

    vector<int> deg(n + 1);

    while (m--) {
        int u, v;
        cin >> u >> v;

        ++deg[u];
        ++deg[v]; // 无向边对两端的度各贡献 1
    }

    sort(deg.begin() + 1, deg.end()); // 不包含预留的 deg[0]

    if (deg[1] == 0) {
        cout << "Brain Melt\n";
    }
    else if (deg[n] == n - 1 && deg[n - 1] == 1) {
        cout << "2\n"; // 一个中心，其余全部为叶子
    }
    else {
        cout << "Many\n";
    }
}
```

时间 $O(m+n\log n)$，数组空间 $O(n)$。本题范围内度数最多为 $n-1$，`int` 足够。原实现已经适合题目规模。

## 可选改写：只扫描需要的特征

排序只是为了取得结构特征，**题目并不需要完整顺序**。可以扫描统计孤立点、叶子数量，以及是否存在度数为 $n-1$ 的点。

以下为整理实现，不是个人原稿。读边部分与原版相同，完整 `solve()` 如下：

```cpp
void solve() {
    int n, m;
    cin >> n >> m;

    vector<int> deg(n + 1);
    while (m--) {
        int u, v;
        cin >> u >> v;

        ++deg[u];
        ++deg[v];
    }

    bool isolated = false, has_center = false;
    int leaves = 0;

    for (int u = 1; u <= n; ++u) {
        if (deg[u] == 0) isolated = true;
        if (deg[u] == n - 1) has_center = true;
        if (deg[u] == 1) ++leaves;
    }

    if (isolated) cout << "Brain Melt\n";
    else if (has_center && leaves == n - 1) cout << "2\n";
    else cout << "Many\n";
}
```

时间降为 $O(n+m)$，空间仍为 $O(n)$。收益是省去排序且保留点编号，代价是多维护几个特征；**无需为了这点改写否定原方案**。

## 易错边界与核验

| 例子或条件 | 结论与原因 |
| --- | --- |
| 空图或任意孤立点 | `Brain Melt`，不存在满足该点要求的颜色 |
| 三点链 | 它本身就是星形，恰好 2 种 |
| 四点链 | `Many`，两条端边互不相接，存在额外自由度 |
| 三角形 | `Many`，本题允许同色边，不能套二分图判定 |
| 两个互不相连的单边 | `Many`，两块分别可翻转颜色，共 4 种 |
| 星形加一条叶子间的边 | `Many`，不再是所有叶子都只能依赖中心 |
| 排序包含 `deg[0]` | 预留零值会被误认为孤立点 |
| 输入存在重边或自环 | 原题已排除，不能脱离简单图前提套用度数特征 |

## 如何想到与迁移

**只区分 0、1、2、更多 → 利用整体翻色排除 1 → 找无法满足条件的点 → 找所有颜色都被锁定的结构 → 证明其他结构能产生额外自由度 → 将结构压成度数特征。**

这题的难点是完成分类证明，最终实现只负责检查已证明的特征。不必因为题面是一张图，就先建立邻接表并启动遍历。

也不能将“排序无妨”推广到所有图题：这里舍弃点编号后仍保留了判定所需的信息，若之后还要输出点集或判断具体连接关系，就需要保留更多状态。
