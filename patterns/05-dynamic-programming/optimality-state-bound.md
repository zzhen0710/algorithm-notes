# 从最优性推出状态上界：超过太多，就删掉一步

[本章范式索引](README.md) · [全部范式](../README.md)

“至少达到目标”往往允许无限多的终态，但求最小费用时，超过很多的状态未必可能最优。先检查：**删掉一次选择后，还够不够、是否合法、能不能更便宜？**

## 1. 适用条件

- 目标总量至少为正整数 $T$。
- 每次选择增加正整数 $w$，且 $w\le W_{\max}$。
- 总费用是各次正费用之和，需要最小化。
- 从某方案中移除一次选择后，除总量下降外，不破坏其他合法条件。
- 至少存在一种可行方案。

条件不要求一定无限供应；核心是删除后仍合法。完全背包的独立购买是常见例子，有额外必须保留、依赖或配套条件时需重新检查。

## 2. 反证：最优方案不能超过这么多

设一个最优方案的总量为 $S$。假设：

$$
S\ge T+W_{\max}.
$$

选其中任意一次增加量 $w$，由于 $w\le W_{\max}$，删除后：

$$
S-w\ge S-W_{\max}\ge T.
$$

删除后仍满足目标；又因为该次费用为正，总费用严格减少，与原方案最优矛盾。

所以：

$$
S<T+W_{\max}.
$$

再结合总量是整数、必须至少满足目标，得到：

$$
\boxed{T\le S\le T+W_{\max}-1}.
$$

**这是最优答案可能出现的范围，不是在说更大的合法总量不存在。** 更大的方案可以合法，只是一定还能删减并变得更优。

## 3. 证明怎样落实到 DP

若用 `dp[s]` 表示**恰好达到总量 `s` 的最小费用**：

1. 状态从 0 建到 $B=T+W_{\max}-1$，保留计算前驱需要的低总量。
2. 按使用次数和正增量安排转移，不能遇到第一个满足需求的状态就停止。
3. 答案在 $[T,B]$ 内取最小费用，既不是只查 `dp[T]`，也不是寻找第一个可达状态。

总量不超过 $B$ 的方案，其各次正增量形成的中间总量也不会超过 $B$，因此无需为了计算这些终态而保存更大的前驱。

普通 $n$ 种容量 DP 的时间为 $O(nB)$、空间为 $O(B)$。**有限上界仍可能很大**，证明后还要核对规模，不能仅因有公式就直接开表。

实际模型、错误路径与原 AC 见 [P2918 Buying Hay](../../notes/05-dynamic-programming/03-complete-knapsack.md#92-洛谷-p2918buying-hay)。

## 4. 哪些线索值得试一试

| 题目表现 | 检查的问题 |
| --- | --- |
| 至少买够一定重量、容量或数量 | 超过目标很多，能否去掉一包仍然够？ |
| 每次增量都有统一上界 | 删除一次最多损失多少总量？ |
| 每次选择都增加正费用 | 删除后能否严格改善目标？ |
| 超出部分没有额外奖励 | 达标以后再多买，是否只是增加花费？ |

这与普通“枚举到某个题面最大值”不同：上界来自**最优方案不可能含有可删除的冗余**，需要写出合法性和费用改善两方面依据。

## 5. 不能照搬的情况

- **要求恰好达到目标**：删掉后能否仍然恰好，要另外判断；本证明针对至少型。
- **存在负费用**：多买反而可能降低费用，甚至没有有限最优值。
- **费用为 0**：删除不一定严格改善费用，不能直接推出每个最优方案都在范围内；若要证明存在一个范围内的最优方案，还需补充删减或次级目标的论证。
- **删除破坏其他约束**：例如必须买至少 10 包、存在配套依赖、批量折扣等，不能只检查总量。
- **增量不是正整数**：正增量关系或整数减 1 的边界需重新论证。

可迁移的问题是：**假设最优方案大到某个程度，能否构造一个仍合法但更便宜的方案？** 找到这种改善方式，才能把无限或过大的状态范围缩小。
