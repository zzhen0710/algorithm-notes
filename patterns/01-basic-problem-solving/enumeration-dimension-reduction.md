# 枚举降维

[本章范式索引](README.md) · [全部范式](../README.md)

## 什么时候想到

题目中有多个变量，但它们之间存在：

- 等式
- 比例
- 函数关系
- 固定总和 / 固定乘积
- 某个变量由其余变量唯一确定

此时先不要给每个变量都套一层 `for`。

先问：

> 哪些变量必须主动选择？哪些变量其实可以直接算出来？

---

## 核心思想

只枚举真正的自由变量，其余变量通过约束直接计算。

例如：

```cpp
// x + y + z = S
for (int x = ...; ...; ++x) {
    for (int y = ...; ...; ++y) {
        int z = S - x - y;

        if (valid(x, y, z)) {
            ...
        }
    }
}
```

原本三维枚举，降为二维枚举。

## 常见形式

```cpp
x + y + z = S
→ 枚举 x、y，计算 z

a : b : c = A : B : C
→ 先处理比例，只枚举公共尺度

a² + b² + c² + d² = N
→ 枚举 a、b、c，由余量确定 d
```

------

## 继续优化

降维后还可以继续检查：

```text
约束进入循环边界
→ 缩小枚举范围
→ 消除重复状态
→ 预处理重复计算
→ 数学判断代替循环
→ 利用枚举顺序提前退出
```

------

## 搜索末端：变量少了，可以换成方程

搜索前半段可能仍需枚举；但前缀固定后，最后几个变量之间往往只剩很少的等式。**到这里再问一次：还需要递归吗？**

```text
前面：枚举选择 → 更新剩余量 → 回溯
末端：列出剩余变量的等式 → 换参数或消元 → 验证整数性与原约束
```

**用途速记：** 已知当前前缀与剩余条件，把末端搜索换成小方程求解；仍需检查得到的根是否为整数、顺序与范围是否满足。换参数后仍有循环时，应比较实际枚举区间，不能仅凭“用了公式”就认定更快。

[P1763 埃及分数](../../notes/03-search/06-iterative-deepening.md#814-核心优化最后两项用和积还原)中，剩余两分母满足分数等式。约分后用整数 k 同时表达两根的和与积，再由二次方程还原分母；具体范围与求根检查在原题复盘维护。

它还说明了另一点：**数学求解后想在首个合法候选处结束，仍要证明候选顺序对应目标的单调性。** 本题只对固定前缀的末端成立，不能让整棵 DFS 都首解即停。
