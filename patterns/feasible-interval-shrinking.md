# 排除不可行空间：约束扩张与区间收缩

## 什么时候想到

已有点、障碍或固定占用区间会限制后续选择，逐个尝试“放哪里”时不断重复检查相同约束，可以先问：

> 哪些位置已经必然不可用？排除它们后，剩余问题是否更简单？

适合固定约束已知、影响范围可以直接描述的情况。提炼的对象是**可行域**，不是某一种模拟写法。

## 核心模型

```text
识别固定约束源
→ 将约束转成不可行范围，或直接收缩候选区间
→ 合并重叠禁区，得到剩余可行域
→ 分析新选择之间是否仍有约束
→ 证明各段独立后，分别求解并合并答案
```

一维有序位置上，固定点 `p` 要求新点距离大于 `k`，便禁止闭区间 `[p-k, p+k]`，再裁到实际定义域。多个禁区重叠时按并集处理，不能重复扣除长度。一般可排序合并禁区，复杂度 `O(m log m)`；已按顺序给出的零段则可直接扫描，无需显式构建并集。

“删除”只是一种思考方式：保留原下标和长度。把字符串实际删短、拼接剩余片段，会改变距离，破坏原约束。

## 来源：CF 1367C

[Social Distance 完整复盘](../problems/CF1367C_Social_Distance.md)中，已有 `1` 左右 `k` 个位置不能放新 `1`。对每个极大连续零段，按左右是否有已有 `1` 各扣除 `k`，得到非负有效长度 `L`。

剩余段内仍要求新点间隔至少 `k+1`，所以容量为 `ceil(L/(k+1))`，不是 `L`。两侧禁区重叠时容量为零。已有 `1` 及其缓冲范围也保证了不同零段的新点互不影响，故容量可以相加。

例：位置 `1..15`，`k=2`，已有点在 `6、12`。禁止 `[4,8]、[10,14]`，剩余 `[1,3]、[9,9]、[15,15]`，容量分别为 `1、1、1`，共新增 `3` 个。

这题不需要真的标记每个禁用位置；直接收缩零段两端便已表达完整约束。**先由已有点排除候选，再对新点之间的约束做贪心。**

## 可以迁移到哪里

| 场景 | 约束转化 | 剩余问题与成立条件 |
| --- | --- | --- |
| 固定会议之外安排任务 | 合并占用时段，取空闲时间窗 | 等长任务耗时 `d`、不能跨会议、无额外冷却与总量约束时，各窗容量为 `floor(窗长/d)` |
| 长度为 `d` 的物体完全落在可用线段 `[L,R]` 内 | 用左端点 `x` 表示位置，约束为 `L <= x <= R-d` | 先收缩合法起点范围；若还要放多个物体，再处理相互重叠限制 |
| 点与障碍保持安全距离 | 将障碍按安全半径扩张，中心只能选在其外 | 先求单点可行域；多个新点是否能独立选择，需要另行分析 |

以上是迁移示例，不是新的平台题目或验证记录。离散点数与连续时间长度不同，不能把本题的取整公式直接照搬。

## 关键边界：分段不自动意味着独立

反例：位置 `1、2、3` 中，只有位置 `2` 被外部障碍禁用；新点要求下标差大于 `2`。剩余两段 `{1}`、`{3}` 各能放一个，但两点距离只有 `2`，同时放置不合法，总答案只能为 `1`。

因此“取补集后按段求和”至少要确认：

- 跨段选择不会冲突；本题由已有 `1` 的缓冲区保证，而任意障碍未必保证。
- 没有跨段共享的总配额、预算、顺序或其他耦合限制；有这些条件时可能还需全局贪心或 DP。
- 固定禁区不会随选择变化；新放的点产生的新约束不能当作早已处理完毕。
- 边界是闭区间、半开区间还是离散下标已明确，禁区重叠和空可行域均正确处理。

本质是先把反复判断的固定约束转成可行域，再在可行域上求解。能否分段计数，取决于后续约束，而不是“已经删过一遍”。
