# 前后缀分解：排除元素后的信息合并

## 什么时候想到

题目要求对同一组**静态数据**，反复考虑：

- 去掉第 `i` 个元素，求剩余元素的某种统计信息；
- 去掉连续区间 `[l, r]`，求两侧剩余部分的结果；
- 枚举一个“被排除的对象”，但每次真实删除、重算、恢复的代价很高。

先问：

> **排除对象之后，剩余信息能否由左侧摘要与右侧摘要合并得到？**

---

## 核心模型

排除第 `i` 个元素：

```text
[a1 ... a(i-1)]  [ai]  [a(i+1) ... an]
     左侧       排除         右侧
```

用 `⊕` 表示合并两个部分的摘要：

\[
\operatorname{ans}(i)=\operatorname{pre}[i-1]\oplus\operatorname{suf}[i+1]
\]

预处理：

```cpp
// merge(a, b)：将相邻两段的摘要合并
pre[i] = merge(pre[i - 1], value[i]);
suf[i] = merge(value[i], suf[i + 1]);

// 排除第 i 个元素
ans = merge(pre[i - 1], suf[i + 1]);
```

成立的关键是：

1. **可合并**：两段信息能够从各自摘要中合并出来，不必重新遍历元素。
2. **结合律**：`merge(merge(a,b),c) == merge(a,merge(b,c))`，才能正确复用前后缀摘要。
3. **边界单位元**：用“空段摘要”初始化 `pre[0]` 和 `suf[n+1]`，使首尾位置不需特殊分支。

合并操作不必满足交换律；若顺序影响结果，应保持**左段在前、右段在后**。

---

## 哪些信息适用

| 信息摘要 | 合并方式 | 空段单位元 |
|---|---|---|
| 区间和 | `a + b` | `0` |
| 区间最大值 | `max(a, b)` | `-∞` |
| 区间最小值 | `min(a, b)` | `+∞` |
| 最大公约数 | `gcd(a, b)` | `0` |
| 按位或 | `a \| b` | `0` |
| 区间交集边界 `(L, R)` | `(max(L1,L2), min(R1,R2))` | `(-∞,+∞)` |

不仅运算本身可以合并，**由多个量组成的摘要也可以合并**，如 `(区间和, 元素个数)`。

## 代表题：[CF 1029C — Maximal Intersection](https://codeforces.com/problemset/problem/1029/C)

删除恰好一个区间，使剩余区间的公共交集长度最大。

交集只取决于：

\[
L=\max(l_i),\quad R=\min(r_i),\quad \text{length}=\max(0,R-L)
\]

**方案一：动态维护。** 用两个 `multiset` 分别维护左右端点；枚举每个区间，临时删除一个端点值，取极值，再恢复。总复杂度 `O(n log n)`。

**方案二：前后缀分解。** 所有区间预先给定、每次只排除一个，因而不需要实际删除。预存左右两侧的最大左端点与最小右端点：

```cpp
// 已有 l[1..n]、r[1..n]；题目保证 n >= 2
vector<int> preL(n + 2, INT_MIN), preR(n + 2, INT_MAX);
vector<int> sufL(n + 2, INT_MIN), sufR(n + 2, INT_MAX);

// 前缀摘要：前 i 个区间的最大左端点、最小右端点
for (int i = 1; i <= n; ++i) {
    preL[i] = max(preL[i - 1], l[i]);
    preR[i] = min(preR[i - 1], r[i]);
}

// 后缀摘要：从第 i 个区间到末尾的最大左端点、最小右端点
for (int i = n; i >= 1; --i) {
    sufL[i] = max(l[i], sufL[i + 1]);
    sufR[i] = min(r[i], sufR[i + 1]);
}

int ans = 0;  // 交集长度的合法下界
for (int i = 1; i <= n; ++i) {
    // 排除第 i 个区间：只合并 [1,i-1] 与 [i+1,n]
    int L = max(preL[i - 1], sufL[i + 1]);
    int R = min(preR[i - 1], sufR[i + 1]);
    ans = max(ans, R - L);
}
```

`INT_MIN` / `INT_MAX` 充当空段的合并单位元，首尾删除自然覆盖。

复杂度：**预处理 `O(n)`，每次排除查询 `O(1)`，全部枚举 `O(n)`；辅助空间 `O(n)`**。

---

## 推广：排除连续区间

排除整个 `[l, r]` 后，剩余为 `[1, l-1]` 和 `[r+1, n]`：

\[
\operatorname{ans}(l,r)=\operatorname{pre}[l-1]\oplus\operatorname{suf}[r+1]
\]

**同一套前后缀摘要，即可在 `O(1)` 时间求出任意一个连续区间被排除后的可合并信息。**

注意：如果剩余部分为空，需要根据题意决定答案如何定义，不能机械使用单位元作为最终答案。

---

## 与分治、线段树的关系

共同思想：**分解整体 → 提取局部摘要 → 合并得到答案。**

- **前后缀**：静态数据，特别适合“排除一个元素 / 一段区间”；预处理后合并两侧。
- **分治**：递归拆分子问题，通过合并子问题结果求解。
- **线段树**：分层保存区间摘要，支持一般区间查询和动态修改。

前后缀分解具有分治式的思维，但**不等于递归分治算法**。

## 触发器

> **依次排除一个元素或连续一段，剩余信息可以合并？先想前后缀，而不是反复删除、重算、恢复。**
