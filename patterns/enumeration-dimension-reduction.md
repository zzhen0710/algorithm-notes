# 枚举降维

## 什么时候想到

题目中有多个变量，但它们之间存在：

- 等式
- 比例
- 函数关系
- 固定总和 / 固定乘积
- 某个变量由其余变量唯一确定

此时先不要给每个变量都套一层 `for`。

先问：

> 哪些变量必须主动选择？哪些变量其实可以直接算出来？

---

## 核心思想

只枚举真正的自由变量，其余变量通过约束直接计算。

例如：

```cpp
// x + y + z = S
for (int x = ...; ...; ++x) {
    for (int y = ...; ...; ++y) {
        int z = S - x - y;

        if (valid(x, y, z)) {
            ...
        }
    }
}
```

原本三维枚举，降为二维枚举。

## 常见形式

```cpp
x + y + z = S
→ 枚举 x、y，计算 z

a : b : c = A : B : C
→ 先处理比例，只枚举公共尺度

a² + b² + c² + d² = N
→ 枚举 a、b、c，由余量确定 d
```

------

## 继续优化

降维后还可以继续检查：

```text
约束进入循环边界
→ 缩小枚举范围
→ 消除重复状态
→ 预处理重复计算
→ 数学判断代替循环
→ 利用枚举顺序提前退出
```
