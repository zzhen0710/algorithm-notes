# MEX：从定义域与频率出发

[本章范式索引](README.md) · [全部范式](../README.md)

## 什么时候想到

题目关注“最小缺失值”“从 `0` 开始连续满足条件的前缀”，或者把出现一次推广为出现至少 `k` 次时，先把问题写成频率条件。

## 核心模型

MEX（Minimum Excluded）是最小未出现的非负整数。推广到正整数 `k`：

$$
\mathrm{mex}_k(S)=\min\lbrace x\ge0:cnt_S[x]\lt k\rbrace.
$$

它要求的是：`0...m-1` 的频率全部至少为 `k`，而 `m` 的频率不足 `k`。所以结果由**第一个失败位置**决定，后面的数字再多也不能补上前面的空缺。

| 集合 | `k` | `mex_k` | 原因 |
|---|---|---|---|
| `{1,1,2,2}` | 2 | 0 | `0` 未出现 |
| `{0,0,2,2}` | 2 | 1 | 中间缺少 `1` |
| `{0,0,1,2,2}` | 2 | 1 | `1` 出现了，但只有一次 |
| `{0,0,1,1}` | 2 | 2 | `0、1` 都达标，`2` 未出现 |

**遍历对象应是从 `0` 开始的候选整数，不是已有元素列表。**

## 直接按定义实现

```cpp
int mex_k(const vector<int>& v, int k) {  // 要求 k >= 1
    unordered_map<int, int> cnt;
    for (int x : v) ++cnt[x];
    int m = 0;
    while (cnt[m] >= k) ++m;
    return m;
}
```

`cnt[m]` 对缺失键会插入并返回默认值 `0`。这个写法允许修改局部频率表；若使用只读映射，要用 `find` 并把缺失键解释为 `0`，不能直接对常量映射使用 `operator[]`。

若数值范围小且已知，优先考虑数组统计，使复杂度不依赖哈希表现。

## 扫描上界

设集合大小为 `s`，若 `mex_k(S)=m`，前 `m` 个数各至少出现 `k` 次，所以：

$$
km\le s,\qquad m\le\left\lfloor\frac{s}{k}\right\rfloor.
$$

数组实现可以只统计 `0...floor(s/k)` 的频率，忽略更大的值；该上界也保证扫描必然终止。哈希实现的平均时间为 `O(s)`，最坏时间不由平均结论保证；辅助空间为 `O(s)`。

## 常见错误与适用边界

- **只查出现过的数：**频率为 `0` 的候选值会被遗漏。
- **直接返回最大值加一：**只有从 `0` 到最大值之间每个数都达到 `k` 次时才成立。
- **先去重再统计：**`k>1` 时重复次数就是题目状态，不能丢弃。可以另存频率后再去重。
- **把频率不足理解成未出现：**对于 `k>1`，出现了但不够多，同样会成为答案。
- **把 MEX 当成任意有序值的缺口：**起点是 `0`，候选是连续非负整数；不能擅自改成数组下标或离散化排名。

- **把 MEX 当成不同值数量：**MEX 为 `m` 要求 `0..m-1` 全部出现，任意 `m` 个不同值不足以保证。见 [CF 1628A](../../problems/CF1628A_Meximum_Array.md#踩坑一把-mex-当作任意不同数字的数量) 的前缀收集反例。
