# 9.9 本章总结与选型

覆盖 9.1–9.8。先看数据是否会变，再看要查的是连通、最近位置、窗口最值、任意区间，还是字符串前缀。

## 1. 按查询与修改选结构

| 题目条件 | 方法 | 成本与取舍 |
| --- | --- | --- |
| 集合不断合并，问两点是否同组 | [并查集](01-dsu.md) | 路径压缩加按大小合并，每次均摊 $O(\alpha(n))$。静态图只需一次连通块时，DFS／BFS 可直接遍历 |
| 每个位置找左／右第一个更大或更小的位置 | [单调栈](02-monotonic-stack.md) | 一次扫描 $O(n)$。代码短，先确定扫描方向、结算对象和严格比较 |
| 窗口移动，每步要窗口最值 | [单调队列](03-monotonic-queue.md) | 每个位置至多入队、出队各一次，队列维护总计 $O(n)$。队首去过期，队尾去劣势 |
| 单点加、区间求和；或区间加、单点查询 | [树状数组](04-fenwick-tree.md) | 每次 $O(\log n)$、空间 $O(n)$。前者存原数组的分块和，后者存差分的分块和，写法比线段树短 |
| 数组固定，多次查询任意区间最值 | [ST 表](05-sparse-table.md) | $O(n\log n)$ 时间和空间预处理，单次 $O(1)$。只有滑动窗口时，单调队列省掉整张表 |
| 单点改，查询任意区间的最大值、和或字符集合 | [线段树](06-segment-tree-basics.md) | 建树 $O(n)$，修改和查询各 $O(\log n)$，空间 $O(n)$。节点摘要必须能从孩子合并 |
| 区间改，还要区间查询 | [懒标记线段树](07-lazy-segment-tree.md) | 当前模板建树 $O(n)$，每次操作 $O(\log n)$。整段更新须能直接改摘要，标记须可复合。优先复用对应模板 |
| 多个词共享前缀，要插入、查词或计数 | [Trie](08-trie.md) | 固定字母表数组版每次按词长 $O(L)$；空间取决于节点数和字母表大小。只查完整词时可先考虑哈希表 |

**纯静态区间和用前缀和。** 若所有区间加法完成后才统一读取，用差分即可。查询和修改交错时，再按上表选在线维护。[前缀和](../02-sequence-techniques/01-prefix-sum.md) · [差分](../02-sequence-techniques/02-difference.md)

## 2. 写完最容易漏的边界

| 容易混的地方 | 回查 |
| --- | --- |
| 单调栈与单调队列 | 栈弹出时常在结算最近位置；队列弹出时在删除过期或不会再赢的候选。相等值保留哪边由题目决定 |
| 树状数组的下标 | 更新从 1 开始。差分的区间加落在 `l` 与 `r+1` 两点，查询原值要取差分前缀和 |
| ST 表的重叠 | 两块可能重叠，最大值和最小值重复算也一样，区间求和会重算 |
| 线段树的摘要与标记 | 区间字符种类要先合并集合，再数种类。懒标记整段命中时先更新节点摘要，需进入子区间时才下传；新变换接在旧变换之后 |
| 并查集代表元 | 代表元可随合并改变。比较集合时对两点重新查根 |
| Trie 终点 | 走完整条路径只说明前缀存在，完整词还要看 `end` |

## 3. 用旧题回查

- [CF 514D](05-sparse-table.md) 固定长度后判可行。ST 表适合任意区间查询；同一轮按固定长度滑动时，可改用单调队列。
- [CF 1234D](06-segment-tree-basics.md) 在节点存字符集合，查询时合并集合后再计数。[P3373](07-lazy-segment-tree.md) 则先把区间乘、加统一成一个变换，再推导标记如何复合。
- [P2922](08-trie.md) 沿路累加严格前缀的 `end`，最后只加终点的 `pass`，相等的词就只计一次。
