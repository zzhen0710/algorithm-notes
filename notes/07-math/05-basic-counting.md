# 7.5 基础计数：分类、分步与排列组合

[CF 584B 的复盘](03-binary-exponentiation.md#82-cf-584bkolya-and-tanya)已经用过“总数减去不满足的方案”。本节先建立通用判断：**数的是什么、顺序是否重要、能否重复，再决定分类相加还是分步相乘。**

使用 C++11，沿用[竞赛基础框架](../../templates/cpp-contest-template/README.md)。先掌握基础模型；模意义组合数、逆元、一般容斥等后续再补，不在本节堆公式。

## 1. 先明确：怎样才算不同方案

同样是“选两个”，计数对象可能不同：

- **选人：** 甲和乙组成一组，与乙和甲是同一组。
- **分配职位：** 甲任队长、乙任副队长，与交换职位是不同方案。
- **选下标：** 数组中两个相同数值可能来自不同位置，不能因值相同就去重。

这与[枚举中的值和位置](../01-basic-problem-solving/02-enumeration.md#33-分清值不同和位置不同)一致。公式不会自动判断题目想数哪一种对象。

> **先确认对象、顺序、重复与限制，再选公式。** 不能看到“选”就直接套组合数。

## 2. 加法与乘法：分类相加，分步相乘

### 加法原理：互斥类别覆盖全部方案

若一种方案只能属于某一类，且各类合起来恰好覆盖全部情况，则总数为各类数量之和。

例如任选一种交通方式，公交有 2 条路线、地铁有 3 条路线，一共 $2+3=5$ 种。**这里是在两类方案之间选一种，不是两种交通工具都要使用。**

分类要同时满足：

- **不重：** 一个方案不能被多类重复统计。
- **不漏：** 每个合法方案都落在某一类。

“会 C++ 的人”和“会 Python 的人”可能重叠，直接将两类人数相加就会重复。可改成互斥分类；一般重叠计数留到容斥专题。

### 乘法原理：按步骤形成一个完整方案

若第一步有 $a$ 种选择，且**第一步的每种选择之后，第二步都恰好有 $b$ 种选择**，则完整方案有 $ab$ 种。

例如从 5 个不同的人中，依次选队长、副队长、记录员，不允许一人兼任：

$$
5\times4\times3=60
$$

后一步不能再选前面的人，选择显然有关联；但每个前缀对应的后续选择数相同，所以仍能相乘。

**完全独立是方便相乘的一种情况，不是乘法原理的必要条件。** 真正要检查的是各阶段的可选数量，能否对所有对应前缀统一计算。

若不同前缀的后续数量不同，就不能随意选一个数量相乘；应分类后累加，或进一步保存状态。后续 DP 会处理这类需要记录前缀影响的问题。

分步计数也要满足**一个完整选择过程恰好对应一个方案**。如果同一最终方案能由多个过程产生，还需检查是否重复计数。

## 3. 排列与组合：差一个“顺序是否重要”

以下默认 $n$ 个对象彼此不同，且 $0\le k\le n$。

### 排列：不重复地选 k 个，顺序重要

依次有 $n,n-1,\ldots,n-k+1$ 种选择，因此：

$$
A_n^k=n(n-1)\cdots(n-k+1)=\frac{n!}{(n-k)!}
$$

当 $k=n$，得到全部对象的排列数 $n!$。约定 $0!=1$，选 0 个对象也只有一个空方案。

### 组合：不重复地选 k 个，顺序不重要

同一组 $k$ 个不同对象，在排列计数中会因顺序不同被统计 $k!$ 次。例如选甲、乙时，`甲乙` 和 `乙甲` 是同一组的两种排列。

每组被重复统计的次数**恰好相同**，所以可以除去这份重复：

$$
\binom{n}{k}=C_n^k=\frac{A_n^k}{k!}=\frac{n!}{k!(n-k)!}
$$

例如 5 人选 2 人，排列有 $5\times4=20$ 种，组合则有 $20/2!=10$ 种。

**能除以某个数的依据是“每个最终方案都恰好被重复数这么多次”**，不是觉得结果偏大，就随手除一下。

### 与允许重复的选择对照

| 条件 | 计数 |
| --- | --- |
| 选 $k$ 次，顺序重要，每次可重复选 $n$ 个对象之一 | $n^k$ |
| 选 $k$ 个，顺序重要，不重复 | $A_n^k$ |
| 选 $k$ 个，顺序不重要，不重复 | $\binom{n}{k}$ |

**允许重复时，`k` 可以大于 `n`；不重复时，`k>n` 才表示无法完成选择。**

允许重复而顺序不重要时，**不能直接将 $n^k$ 除以 $k!$**。例如从 `A、B` 中重复选两次，无序结果为 `AA、AB、BB`；`AB` 对应两个有序过程，而 `AA、BB` 各只有一个，重复次数不统一。

## 4. 常用小模型：无序两两配对

从 $t$ 个不同对象中选出一对，先选第一个有 $t$ 种，再选第二个有 $t-1$ 种；此时每对都被正反统计两次，因此：

$$
\binom{t}{2}=\frac{t(t-1)}2
$$

这统计的是**一对不同对象**，不包含自己与自己，也不区分先后。若数有方向的配对，就不能除以 2。

```cpp
using ll = long long;

// 0<=t<=10^9；返回无序对数，t=0 或 1 时自然为 0
ll choose_two(ll t) {
    return t * (t - 1) / 2; // 本范围内，除以 2 之前的乘积也能用 ll 表示
}
```

时间、空间均为 $O(1)$。`t=100000` 时结果已超过 `int`；**输入变量和乘法中间结果都要考虑范围，不能只把最终答案存为 `ll`。**

这只是计数工具。题目若还要求分组后的最小值或最大值，仍需额外分析怎样分组，公式本身不会自动决定最优方案。

## 5. 小范围组合数表：按选或不选递推

阶乘公式便于理解，但**不是任何范围都适合直接算阶乘**。`20!` 可用 `ll` 表示，`21!` 已经超出；有时组合数本身可表示，分子阶乘却早已溢出。

小范围可用只包含加法的递推计算。

### 为什么可以拆成两个较小问题

从 $n$ 个不同对象中选 $k$ 个，固定考察其中一个对象：

- **不选它：** 从其余 $n-1$ 个中选 $k$ 个，有 $\binom{n-1}{k}$ 种。
- **选它：** 它已占一个名额，再从其余 $n-1$ 个中选 $k-1$ 个，有 $\binom{n-1}{k-1}$ 种。

两类互斥且覆盖全部方案，用加法原理得到：

$$
\binom{n}{k}=\binom{n-1}{k-1}+\binom{n-1}{k}
$$

### 变量、容量与初始化

- `N`：需要计算到的最大对象数；**本例限定 `0<=N<=60`**，所有组合数和加法结果均能用 `ll` 表示，不取模。
- `c[n][k]`：从 `n` 个不同对象中选 `k` 个的方案数。两个维度分别记录**可选对象数**和**选取数**；只保留 `n`，无法区分同为 4 个对象时选 1 个与选 2 个的不同问题。
- 容器为 `(N+1)×(N+1)`，两个下标均为 **0-based，范围 `0..N`**。输入对象实际是什么，不影响表的容量。
- `c[n][0]=1`：不选任何对象只有一个空方案，包括 `c[0][0]=1`。
- `k>n` 的表格位置初始化为 0，表示选取不可能；访问表前仍需保证两个下标都在范围内。

本范围的最大值是 $\binom{60}{30}=118264581564861424$，可用 `ll` 表示。更大范围必须重新分析，不能只改大 `N` 就继续沿用数值契约。

### 执行流程与实现

1. 建立全零表，初始化所有 `c[n][0]=1`。
2. 按 `n` 从小到大计算；当前行只依赖上一行，所需值已经算好。
3. 对 `1<=k<=n`，将选与不选两类数量相加。
4. 计算后按 `c[n][k]` 查询，不需要重新枚举具体组合。

```cpp
// 0<=N<=60；返回精确组合数表，无共享状态，每次调用独立
vector<vector<ll>> build_comb(int N) {
    vector<vector<ll>> c(N + 1, vector<ll>(N + 1, 0));

    for (int n = 0; n <= N; ++n)
        c[n][0] = 1;

    for (int n = 1; n <= N; ++n) {
        for (int k = 1; k <= n; ++k) {
            c[n][k] = c[n - 1][k - 1] + c[n - 1][k];
        }
    }

    return c;
}
```

预处理时间和空间均为 $O(N^2)$，之后单次查询 $O(1)$；`N=0` 为常数处理。每次返回新表，多测无需清理；多次查询同一范围时，可在调用处复用表。

例如只看 `k=0、1、2`：

| `n` | `c[n][0]` | `c[n][1]` | `c[n][2]` |
| --- | --- | --- | --- |
| 0 | 1 | 0 | 0 |
| 1 | 1 | 1 | 0 |
| 2 | 1 | 2 | 1 |
| 3 | 1 | 3 | 3 |
| 4 | 1 | 4 | 6 |

其中 `c[4][2]=c[3][1]+c[3][2]=3+3=6`。**把较小问题的答案保存下来，再按依赖顺序计算更大问题**，也是后续 DP 的一个基本思路。

这张表用于理解一般组合数，不代表每道计数题都要建表；能用简单表达式完成的计数，无须增加二维容器。

## 6. 直接计数、补集与数值边界

**直接数合法方案难，而不合法方案容易描述时，可用“总数减去不合法数”。** 前提是反面条件写得准确，并且统计范围一致。

[CF 584B](03-binary-exponentiation.md#82-cf-584bkolya-and-tanya)已经说明：“至少一组不等于 6”的反面是“所有组都等于 6”，不是“至少一组等于 6”。沿用已有完整推导，不重复维护一份题解。

写代码时再检查：

- **空方案：** 选 0 个通常有 1 种；要求非空时，再按题意排除，不能统一初始化成 0。
- **不可能的选择：** 对非负 `n、k`，`k>n` 的不重复选择数为 0；不要继续计算负数阶乘或访问负下标。
- **先溢出再取模无效：** 加乘之前就要保证中间值可表示，不是最后多写 `%p` 就安全。
- **整数除法不能直接搬进模运算：** 例如 $\binom{3}{2}=6/2=3$，但 `(6%5)/2` 得到 0。需要模意义除法时，参考[前文的限制](02-congruence-modulo.md#5-不能照搬的规则除法约分与大小比较)，逆元后续再讲。
