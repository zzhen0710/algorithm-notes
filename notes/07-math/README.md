## 学习衔接

承接[基础构造中的条件与奇偶性](../04-greedy-and-construction/03-basic-construction.md)，从整除与 gcd/lcm 开始，再学习同余、模运算、快速幂、筛法、质因数分解与基础计数。

基础轮先完成常用数学模型及代表题复盘，再衔接 [DP 入门](../05-dynamic-programming/01-dp-basics.md)；组合计数进阶、高精度、矩阵、几何等后续按前置关系补齐，不要求一轮学完整章。树形 DP 基础单元后接入 [7.6 逆元与组合数取模](06-modular-inverse-combinations.md)，先补素数模数下的常用计算条件，接入 [7.7 容斥](07-inclusion-exclusion.md)，用重复计数与二项式展开完成这一段计数知识链；之后再切换其他基础模型。Floyd 两题复盘后接入 [7.8 高精度整数](08-big-integer.md)，补内置整数超限后的精确表示与运算；先完成非负整数基础，再按题目需要扩展。

已有快速幂与 DP 基础后，接入 [7.9 矩阵与矩阵快速幂](09-matrix-exponentiation.md)，先把少量状态的固定线性转移打包，理解维度、初值与重复轮数；随后接入 [7.10 高斯消元](10-gaussian-elimination.md)，从增广矩阵组织方程，通过可还原的行操作求未知数，区分重复转移与方程求解。

已有 gcd 与模运算基础后，接入 [7.11 扩展欧几里得与一般模逆元](11-extended-euclid.md)，补齐 7.6 的一般模数情况；随后接入 [7.12 基础几何](12-basic-geometry.md)，先用整数坐标处理方向、线段与面积；几何两题静态复盘后接 [7.13 概率与期望](13-probability-expectation.md)，再接 [7.14 基础博弈](14-basic-games.md)，用终点反推胜负与异或策略完成基础模型，不因此标记整章或个人掌握完成。

知识范围与典题复盘规范见 [Notes 总览](../README.md)。
