# 7.1 最大公约数与最小公倍数

从奇偶条件进一步走向**整除关系**：哪些数能同时整除多个数，哪些数能同时被多个数整除？本节建立 gcd/lcm 模型，同余运算与快速幂后续再讲。

使用 C++11，沿用[竞赛基础框架](../../templates/cpp-contest-template/README.md)。

## 1. 整除、gcd 与 lcm 分别表示什么

对整数 $a$ 和正整数 $d$，若存在整数 $q$ 使 $a=qd$，称 **$d$ 整除 $a$**，记作 $d\mid a$。代码中用 `a % d == 0` 判断，**除数不能为 0**。

对两个正整数 $a,b$：

| 概念 | 含义 | 例子：12 与 18 |
| --- | --- | --- |
| 最大公约数 gcd | 同时整除两者的最大正整数 | 公约数为 1、2、3、6，gcd 为 6 |
| 最小公倍数 lcm | 同时被两者整除的最小正整数 | 公倍数为 36、72、108……，lcm 为 36 |
| 互质 | gcd 为 1 | 8 与 9 互质，两者不必都是质数 |

> **gcd 不只保留“最大值”，还保留全部共同整除条件：** 对正整数 $d$，

$$
d\mid a\ \text{且}\ d\mid b
\quad\Longleftrightarrow\quad
d\mid\mathrm{gcd}(a,b)
$$

例如同时整除 12、18 的数，恰好就是 6 的正因数。**不能只检查 `d <= gcd(a,b)`**：4 虽然小于 6，却不能整除这两个数。

> **“约数”是用来除原数的，“倍数”是能被原数整除的。** 共同分组单位常对应 gcd，共同周期常对应 lcm。

## 2. 辗转相除：为什么可以换成余数

### 2.1 证明：两组数的公约数集合完全相同

设 $d$ 为任意正整数。

**方向一：证明原公约数也是新公约数。**

若 $d$ 同时整除 $a$ 和 $b$，即：
$$
d\mid a,\qquad d\mid b
$$
由于 $q$ 是整数，因此 $qb$ 也能被 $d$ 整除。两个能被 $d$ 整除的整数相减，结果仍能被 $d$ 整除。

根据带余除法：
$$
a=qb+r
$$
移项可得：
$$
r=a-qb
$$
因此：
$$
d\mid a,\ d\mid b
\Rightarrow d\mid(a-qb)=r
$$
也就是说：
$$
d\mid a,\ d\mid b
\Rightarrow d\mid b,\ d\mid r
$$
因此，$(a,b)$ 的每一个公约数，也是 $(b,r)$ 的公约数。

**方向二：证明新公约数也是原公约数。**

反过来，若 $d$ 同时整除 $b$ 和 $r$，即：
$$
d\mid b,\qquad d\mid r
$$
由于 $q$ 是整数，因此 $qb$ 能被 $d$ 整除。两个能被 $d$ 整除的整数相加，结果仍能被 $d$ 整除。

根据带余除法：
$$
a=qb+r
$$
因此：
$$
d\mid b,\ d\mid r
\Rightarrow d\mid(qb+r)=a
$$
也就是说：
$$
d\mid b,\ d\mid r
\Rightarrow d\mid a,\ d\mid b
$$
因此，$(b,r)$ 的每一个公约数，也是 $(a, b)$ 的公约数。

**综合两个方向：**

- 原公约数集合包含于新公约数集合。
- 新公约数集合也包含于原公约数集合。

因此，两组数的公约数集合完全相同：
$$
\mathrm{Div}(a,b)=\mathrm{Div}(b,r)
$$
既然公约数集合完全相同，其中最大的公约数自然也相同：
$$
\boxed{\gcd(a,b)=\gcd(b,r)}
$$
代入余数的定义，得到：
$$
\boxed{\gcd(a,b)=\gcd(b,a\bmod b)}
$$

### 2.2 为什么可以反复替换，直到余数为 0？

上面的证明说明，每次将 $(a,b)$ 替换为 $(b,r)$，最大公约数都不会改变。

因此，可以连续进行替换。

设每一步产生的余数依次为 $r_1,r_2,r_3,\ldots$，则：
$$
\gcd(a,b)=\gcd(b,r_1)
$$

$$
=\gcd(r_1,r_2)
$$

$$
=\gcd(r_2,r_3)
$$

$$
=\cdots
$$

其中，每一步都用前一次的除数和余数继续计算。

**为什么这个过程一定会结束？**

根据带余除法：
$$
0\le r<b
$$
每次得到的新余数都小于当前除数。因此，余数会不断减小，最终必然出现余数为 $0$ 的情况。

当第二个数为 $0$ 时：
$$
\gcd(a,0)=a\qquad(a>0)
$$
因为任何正整数都能整除 $0$，所以 $(a,0)$ 的公约数就是 $a$ 的约数，最大公约数自然为 $a$。

此时，计算结束，**最后一个非零余数就是原来两个数的最大公约数**。

### 总结

辗转相除法的正确性与终止性，建立在两个关键性质上：

1. **正确性不变：** 每次替换都保持公约数集合不变，因此最大公约数不变。
2. **问题规模缩小：** 每次余数都严格小于当前除数，最终必然变为 $0$。

因此，可以不断将 $(a,b)$ 替换为 $(b,a\bmod b)$，直到余数为 $0$，最后一个非零数就是最大公约数。

### 小例子：48 与 18

| 当前 `a` | 当前 `b` | `a % b` | 下一状态 |
| --- | --- | --- | --- |
| 48 | 18 | 12 | (18, 12) |
| 18 | 12 | 6 | (12, 6) |
| 12 | 6 | 0 | (6, 0) |

**0 可以被任意正整数整除**，所以 $\mathrm{gcd}(a,0)=a$（$a>0$）；到达 `(6,0)` 后答案为 6。

这也解释了上一节的完整整除性质：公约数集合一直不变，终态 $(g,0)$ 的公约数恰好是 $g$ 的正因数。

## 3. 变量、流程与实现

### 状态与数值范围

- `a、b`：当前待求 gcd 的两个数，**按值传参**，内部修改不影响调用处。
- `r`：当前余数，先保存，再更新 `a、b`；不能更新后才用错状态计算。
- 输入范围：本节实现只接收 **`0..LLONG_MAX` 的非负整数**，返回值也在该范围内。不直接处理负数或对 `LLONG_MIN` 取绝对值。
- 只维护两个数和一个余数，**无需按数值大小开数组**；两数 gcd 本身没有下标约定。

### 执行流程

1. 检查 `b` 是否为 0；为 0 时已经到达终态。
2. 计算 `r = a % b`。
3. 将 `(a,b)` 替换为 `(b,r)`，继续处理。
4. 返回最后的 `a`。

```cpp
using ll = long long;

// a、b 非负；约定 gcd(0,0)=0，其他情况返回非负最大公约数
// 按值接收，无外部副作用；每次调用独立，不需要多测清理
ll gcd_ll(ll a, ll b) {
    while (b != 0) { // 先判断，避免对 0 取余
        ll r = a % b;

        a = b;
        b = r; // 新状态与原状态具有相同的公约数集合
    }

    return a;
}
```

> **不需要预先保证 `a>=b`。** 若 `a<b`，第一次余数就是 `a`，下一状态自然变成 `(b,a)`。

对 `(0,0)` 返回 0 是方便程序统一处理的约定，**不是说两者存在最大的正公约数**。

### 不变量、终止与复杂度

- **不变量：** 当前两数的公约数集合与初始两数相同。
- **终止：** 每轮非零的第二个数严格变小，最终变成 0。
- **正确性：** 终态的第一个数就是原问题的 gcd；全零情况按约定返回 0。

> 对正数输入，时间复杂度为 $O(\log\min(a,b))$，零值边界为常数时间，辅助空间为 $O(1)$。

- **变小不一定意味着对数复杂度；这里还需要缩小速度。** 对当前正数 $b$，若余数 $r\le b/2$，已经减半；否则下一次余数为 $b-r<b/2$。因此至多两次取余就使第二个数至少减半。

### 递归短写法：直接照着等式写

已经证明：**`b==0` 时直接返回 `a`；否则，答案等于下一组 `(b,a%b)` 的 gcd。** 这两条规则可以直接翻译为递归。

```cpp
// 与 gcd_ll 的非负输入、零值约定一致；二选一使用即可
ll gcd_rec(ll a, ll b) {
    return b == 0 ? a : gcd_rec(b, a % b);
}
```

- **递归出口：** `b==0`，返回当前 `a`。条件运算符只计算选中的分支，不会再执行 `% 0`。
- **递归推进：** `b!=0`，把求解交给更小的状态；`return` 将结果逐层传回。
- **不需要回溯恢复：** 参数按值传递，没有修改共享容器，也不需要在返回后尝试其他分支。

例如 `(48,18) → (18,12) → (12,6) → (6,0)`，最深一层返回 6，前面各层都直接返回这个结果。

**递归版适合记忆和现场书写，循环版保留作状态更新的对照。** 实际复用时选一种即可，不需要维护两套同功能实现。若改用 `gcd_rec`，后面的聚合与 lcm 调用相应换名即可。

两版的取余次数相同。循环版辅助空间为 $O(1)$；递归版按调用栈计为 $O(1+\log\min(a,b))$（正数输入），零值边界为常数，**不能仅因代码短就认为递归没有额外空间**。

实际复用见 [gcd/lcm 简洁模板](../../templates/gcd-lcm/README.md)，主写法采用递归 gcd，另提供 lcm 与数组聚合；本节保留循环版解释状态更新。

## 4. 多个数：用一个 gcd 汇总共同约数

对已经读入的非负数组，逐个合并：

$$
g\leftarrow\mathrm{gcd}(g,a_i)
$$

**处理完前若干个数后，`g` 就是这些数的 gcd。** 新数加入后，只保留仍能整除所有已处理数的候选。

### 容器与执行流程

- `a`：按**元素个数 `n`** 存储，0-based 下标为 `0..n-1`；值很大不意味着容量很大。
- `g`：已处理部分的 gcd，初始为 0，利用 `gcd(0,x)=x` 接入第一个数。
- 依次读取容器中的 `x`，更新 `g`；全部完成后返回。
- 空数组返回 0 是本函数的聚合约定；全零数组也返回 0。

```cpp
#include <vector>

using namespace std;

// 元素非负，不修改 a；空数组返回 0，每次调用重新初始化 g
ll gcd_all(const vector<ll>& a) {
    ll g = 0;

    for (ll x : a) {
        g = gcd_ll(g, x); // 将新元素的整除要求并入已有状态
    }

    return g;
}
```

例如 `a={18,24,42}`，`g` 依次为 **`0 → 18 → 6 → 6`**。结果不是所有公约数的列表，而是用 6 表示：共同正约数恰好为 6 的正因数。

若 $V=\max(2,\max a_i)$，时间为 $O(n\log V)$ 的上界，辅助空间 $O(1)$；数组自身占 $O(n)$。

### 与区间和的状态对照

**添加元素时，gcd 只能不变或变成原 gcd 的约数**；初始 `g=0` 是聚合起点，不纳入正数大小递减的比较。

但删除旧元素时，**不能像区间和那样直接撤销**。例如 `[6,10]` 和 `[6,14]` 的 gcd 都为 2，删除同一个 6 后，却分别得到 10、14；仅知道旧 gcd 和被删元素无法恢复。

因此这种逐项聚合适合静态汇总，不能直接当作[滑动窗口](../02-sequence-techniques/05-sliding-window.md)的可撤销状态。区间 gcd 查询可在后续 ST 表或线段树章节补充。

## 5. 最小公倍数：先除再乘

### 5.1 先看例子：12 与 18 需要哪些因子

正整数可以分解为质数的乘积；同一个质数重复出现的次数，用指数表示。例如：

$$
12=2\times2\times3=2^2\times3^1
$$

$$
18=2\times3\times3=2^1\times3^2
$$

**公约数要同时能从两边取出，不能超过任意一边已有的数量。** 比如 12 有两个因子 2，18 只有一个，因此 gcd 最多保留一个 2。

**公倍数要同时包含两边所需的因子，必须够两边分别使用。** 比如要被 12 整除，需要至少两个因子 2；要被 18 整除，需要至少两个因子 3。这里是分别检查整除，不是把两边的需求相加。

| 质数 | 在 12 中的指数 | 在 18 中的指数 | gcd：取两者较小值 | lcm：取两者较大值 |
| --- | --- | --- | --- | --- |
| 2 | 2 | 1 | 1 | 2 |
| 3 | 1 | 2 | 1 | 2 |

因此：

$$
\mathrm{gcd}(12,18)=2^1\times3^1=6
$$

$$
\mathrm{lcm}(12,18)=2^2\times3^2=36
$$

### 5.2 推广：为什么分别取较小与较大指数

对任意正整数 $a,b$，固定一个质数 $p$，设它在两数中的指数分别为 $s,t$。**没有这个质因子时，指数记为 0。**

若一个公约数中 $p$ 的指数为 $c$，为了同时整除 $a,b$，必须满足：

$$
c\le s,\qquad c\le t
$$

也就是：

$$
c\le\min(s,t)
$$

**每个质因子都取允许的最大指数，才能得到最大公约数。** 所以 gcd 中 $p$ 的指数为 $\min(s,t)$。

反过来，若一个公倍数中 $p$ 的指数为 $e$，为了同时被 $a,b$ 整除，必须满足：

$$
e\ge s,\qquad e\ge t
$$

也就是：

$$
e\ge\max(s,t)
$$

**每个质因子都取够用的最小指数，才能得到最小公倍数。** 所以 lcm 中 $p$ 的指数为 $\max(s,t)$，也不需要加入两数都没有的新质因子。

这里使用正整数质因数分解的唯一性；分解的具体算法后续再讲，本节无需先写分解代码。

### 5.3 从指数关系得到乘积公式

两个指数中，一个较小、另一个较大，因此：

$$
\min(s,t)+\max(s,t)=s+t
$$

同底数相乘时指数相加。于是，gcd 与 lcm 相乘后，质数 $p$ 的部分为：

$$
p^{\min(s,t)}\times p^{\max(s,t)}
=p^{s+t}
=p^s\times p^t
$$

右边正好也是 $a\times b$ 中质数 $p$ 的部分。

**对每个质数都成立，两边的全部质因子及指数相同，因此两个乘积相等：**

$$
\mathrm{gcd}(a,b)\times\mathrm{lcm}(a,b)=a\times b
$$

例如 $6\times36=12\times18=216$。

### 5.4 从数学公式到安全的计算顺序

令 $g=\mathrm{gcd}(a,b)$。对正整数输入，$g>0$，因此可以将等式两边除以 $g$：

$$
\mathrm{lcm}(a,b)=\frac{a\times b}{g}
$$

又因为 **$g$ 一定整除 $a$**，先算 $a/g$ 不会发生整数截断，所以可以改写为：

$$
\mathrm{lcm}(a,b)=\left(\frac a g\right)\times b
$$

例如 12 与 18，先计算 `12/6=2`，再计算 `2*18=36`。**不需要在代码里先分解质因数；上面的分解只用于解释公式。**

```cpp
// a、b 非负，且非零时的最终 lcm 必须能用 ll 表示
// 任意一个数为 0 时约定返回 0；无外部副作用
ll lcm_ll(ll a, ll b) {
    if (a == 0 || b == 0) return 0; // 也避免 (0,0) 时除以 gcd=0

    return a / gcd_ll(a, b) * b; // 除法与乘法同级，按从左到右先除再乘
}
```

公式推导针对正整数；函数对零值作单独约定，先判断后返回，不把 `(0,0)` 硬套进除法公式。

> **先除再乘，只避免不必要的中间乘积溢出，不保证最终答案一定放得下。** 两个数分别能用 `ll` 表示，并不意味着 lcm 也能。

若输入范围不能保证结果可表示，对正数可先检查 `a / g > LLONG_MAX / b`；成立则乘积超出范围，不能继续直接相乘。`LLONG_MAX` 来自 `<climits>`，后续如何处理超限取决于题意。

时间与一次 gcd 相同；当前 `lcm_ll` 调用循环版，辅助空间 $O(1)$，若换用递归 gcd，则还需计入递归栈。多个数也能逐个合并 lcm，但**增长和溢出风险通常比 gcd 更突出**。

## 6. 边界与适用条件

| 情况 | 需要明确的结论 |
| --- | --- |
| 两数相等 | gcd 与 lcm 都等于该数 |
| 一个正数整除另一个 | gcd 为较小数，lcm 为较大数 |
| 两正数互质 | gcd 为 1，lcm 为两数乘积，仍需检查范围 |
| 一个数为 0 | gcd 为另一个数，lcm 按程序约定为 0 |
| 两数均为 0 | 本节 gcd/lcm 均约定返回 0 |
| 出现负数 | 本节函数的输入前提不成立，需另行规范符号和数值范围 |
| 给定一个候选公约数 | 检查整除关系，不能只比较它与 gcd 的大小 |

`std::gcd`、`std::lcm` 是 C++17 的 `<numeric>` 接口，见 [GCC 标准库支持表](https://gcc.gnu.org/onlinedocs/libstdc++/manual/status.html)。当前笔记沿用 C++11，使用上面的简短函数，不依赖编译器扩展。

### 7.1 P1029：最大公约数和最小公倍数问题

题目：[洛谷 P1029](https://www.luogu.com.cn/problem/P1029)。

- **题意：** 给定正整数 $x_0,y_0$，统计最大公约数为 $x_0$、最小公倍数为 $y_0$ 的正整数对 $(P,Q)$ 的数量。
- **条件：** $2\le x_0,y_0\le10^5$；交换两数后不同的有序对分别计数。
- **练习目的：** 将两个数学条件落实为候选范围和完整核验，注意计数是否重复及中间数值范围。
- **状态：复盘完成（本地核验），平台结果未单独记录。**

#### 原思路：枚举一个数，由乘积确定另一个数

把题目给定的 gcd、lcm 分别记为 $g,l$。对合法正整数对 $(a,b)$：

$$
a\times b=g\times l
$$

因为 $g$ 整除两数，而两数又分别整除 $l$，所以 $a$ 必须是 **`g..l` 中的 `g` 的倍数**。

固定 $a$ 后，另一个数应为：

$$
b=\frac{gl}{a}
$$

这样从枚举两数，缩小为**枚举一个数，再检查另一数**。

```cpp
// 下文两题共用；参数非负，按值传递
ll igcd(ll a, ll b) {
    return b == 0 ? a : igcd(b, a % b);
}

// 本题调用处 a、b 均为正数，且结果能用 ll 表示
ll ilcm(ll a, ll b) {
    return a / igcd(a, b) * b;
}
```

```cpp
// 保留原逻辑，仅调整排版与注释；沿用 using ll = long long
void solve() {
    ll g, l;
    cin >> g >> l;
    ll gl = g * l; // 两个操作数已经是 ll，乘积最大可达 10^10

    int cnt = 0;
    for (ll a = g; a <= l; a += g) {
        ll b = gl / a; // 整数除法；除不尽的伪候选由后续完整条件排除

        if (igcd(a, b) == g && ilcm(a, b) == l)
            ++cnt;
    }

    cout << cnt << '\n';
}
```

**原实现正确。** 每个合法有序对都对应唯一一个被枚举到的 $a$，因此不漏不重。交换后不同的 $(a,b)$、$(b,a)$ 会在不同轮分别计入；相等时只有一轮。

但这里有一个容易误改的地方：**`gl/a` 不一定整除，不能直接把计算出的整数商当成满足乘积关系的 $b$。**

例如 `g=3、l=10`，枚举到 `a=9` 时，整数除法得到 `b=3`。此时 gcd 确实为 3，但 lcm 为 9，不是 10，因此原实现会正确排除。

若两项检查都通过，由数学恒等式可得：

$$
a\times b=\mathrm{gcd}(a,b)\times\mathrm{lcm}(a,b)=gl
$$

所以真正被计入时，乘积关系必然成立。**若想删掉 lcm 检查，就必须先保证 `gl % a == 0`，不能只保留 gcd 检查。**

设 $K=\lfloor l/g\rfloor$，原版最多扫描 $K$ 个候选，时间上界 $O(K(1+\log l))$，除递归栈外辅助空间 $O(1)$。给定范围内规模足够小，不必为了通过本题强行优化。

#### 推荐整理：约去共同基值，再枚举因数对

如果有解，因为 $g\mid a$、$a\mid l$，必有 $g\mid l$。**先检查 `l % g == 0`**，不成立直接无解。

成立时，将两数写成：

$$
a=gx,\qquad b=gy,\qquad x,y\text{ 为正整数}
$$

提出共同因子后，gcd 条件变成：

$$
\mathrm{gcd}(gx,gy)=g\times\mathrm{gcd}(x,y)=g
$$

即：

$$
\mathrm{gcd}(x,y)=1
$$

这里“提出共同因子”也可从质因子指数理解：两数共有的 $g$ 对每个指数增加同样的量，取较小指数时，这个增加量会完整保留。

再将 $a=gx,b=gy$ 代入乘积关系：

$$
g^2xy=gl
\quad\Longrightarrow\quad
xy=\frac lg
$$

令 $k=l/g$，于是问题变成：**统计乘积为 $k$ 的互质正整数对 $(x,y)$。**

- 枚举较小因数 $x$，只需检查 $x\le\sqrt{k}$。
- 先确认 `k % x == 0`，再取 `y=k/x`，此时除法一定精确。
- 若 gcd 为 1，`x!=y` 时计入两个有序对；相等时只计一个。

反过来，满足这些条件的 $(x,y)$ 一定能还原出合法 $(gx,gy)$：gcd 为 $g$，乘积为 $gl$，所以 lcm 为 $l$。因此这个转化既必要也充分。

```cpp
// 整理实现，复用上面的 igcd；不是对原实现的逻辑覆盖
void solve() {
    ll g, l;
    cin >> g >> l;

    if (l % g != 0) {
        cout << 0 << '\n';
        return;
    }

    ll k = l / g;
    int cnt = 0;

    for (ll x = 1; x <= k / x; ++x) { // 等价于 x*x<=k，避免先乘再判断
        if (k % x != 0) continue;

        ll y = k / x;
        if (igcd(x, y) != 1) continue;

        cnt += (x == y ? 1 : 2); // 因数对只枚举一次，有序对按方向分别计数
    }

    cout << cnt << '\n';
}
```

例如 `g=3、l=60`，约去基值后 $k=20$。因数对为 `(1,20)、(2,10)、(4,5)`，其中第一对、第三对互质，分别贡献两个方向，共 4 对。

时间上界 $O(\sqrt{k}(1+\log k))$，空间来自 gcd 的递归栈。**收益是缩小候选范围，并明确处理整除；代价是多一步数学转化和有序对计数。** 暂不展开质因数分解计数，留到后续建立对应基础。

**如何想到：** 已知 gcd 和 lcm → 两数乘积固定 → 一个数决定另一个数 → gcd 又是两数共有的基值 → 约去基值，剩下互质条件与因数配对。

#### 边界与核验

- **`g==l`：** 只有 `(g,g)`，约去后 `k=1`，相等因数对只计一次。
- **`l % g != 0` 或 `g>l`：** 无解；原版靠完整条件排除，整理版提前拒绝。
- **平方数因数对：** 不能重复计数；相等且互质只能是 `(1,1)`。
- **数值类型：** `g、l、gl、a、b` 用 `ll`；若先用两个 `int` 相乘，事后存到 `ll` 也不能补救已发生的溢出。

两版均已完成本地小范围独立枚举与边界核验。未据此标记平台 AC。

### 7.2 CF 1618C：Paint the Array

题目：[Codeforces 1618C](https://codeforces.com/problemset/problem/1618/C)。

- **题意：** 选择正整数 $d$，能被 $d$ 整除的元素染一种颜色，其余染另一种，要求相邻元素颜色不同；输出任意合法 $d$，无解输出 0。
- **条件：** $1\le t\le1000$，$2\le n\le100$，$1\le a_i\le10^{18}$，合法输出满足 $1\le d\le10^{18}$。
- **练习目的：** 把整除判定与整体结构条件联系起来，区分候选的产生和对完整要求的检查；兼顾 64 位数值。
- **状态：复盘完成（本地核验），平台结果未单独记录。**

#### 原思路：先按位置分组，再检查能否用整除关系区分

相邻元素必须异色，因此第一个位置确定后，颜色只能交替。**同一类下标颜色相同，奇数位置与偶数位置颜色相反。**

使用题面的 **1-based 位置** 分组：奇数位置存入 `a`，偶数位置存入 `b`。两个 `vector` 内部仍然是 0-based 容器；位置奇偶在读入时已经确定，不要与容器下标混淆。

先尝试“`a` 全部被整除，`b` 全部不被整除”，不行再交换。代码中的 `judge` 返回合法的正数候选，无解返回 0。

```cpp
// 复用上一题 igcd；元素非负，空容器聚合返回 0
ll agcd(const vector<ll>& a) {
    ll g = 0;

    for (ll x : a) // 循环变量也要保持 ll，不能先窄化再求 gcd
        g = igcd(g, x);

    return g;
}

// 本题两组均非空且全为正数，因此 aa>0，取余除数不会为 0
ll judge(const vector<ll>& a, const vector<ll>& b) {
    ll aa = agcd(a);

    for (ll x : b)
        if (!(x % aa)) // 另一组只要有一个也被整除，这个方向就不可行
            return 0;

    return aa;
}
```

```cpp
// 保留原分组、判断顺序及重复调用，仅整理排版与注释
void solve() {
    int n;
    cin >> n;

    vector<ll> a;
    vector<ll> b;

    for (int i = 1; i <= n; ++i) {
        ll x;
        cin >> x; // 元素可达 10^18，输入变量也必须承接完整值域

        if (i & 1) a.push_back(x);
        else b.push_back(x);
    }

    if (judge(a, b)) {
        cout << judge(a, b) << '\n';
        return;
    }

    if (judge(b, a)) {
        cout << judge(b, a) << '\n';
        return;
    }

    cout << "0\n";
}
```

#### 为什么只检查一组的 gcd 就够了

设希望 `a` 全部能被 $d$ 整除，记：

$$
G=\mathrm{gcd}(a_1,a_2,\ldots)
$$

所有可行的 $d$ 都是该组的公约数，因此：

$$
d\mid G
$$

先取最大的公约数 $G$，它已经保证 `a` 全部能被整除。接着检查 `b`：

1. **若 `b` 中没有元素能被 $G$ 整除，** 直接选择 $d=G$，这个方向成功。
2. **若 `b` 中存在某个元素 $x$ 满足 $G\mid x$，** 对任何其他候选 $d$，都有 $d\mid G$。由整除的传递性：

$$
d\mid G,\qquad G\mid x
\quad\Longrightarrow\quad d\mid x
$$

这个 $x$ 仍然会被染到错误的一组。**换成更小的公约数无法补救，所以该方向整体无解。**

因此不是“gcd 看起来最合适”，而是已经证明：**它通过就能构造答案，它失败就能排除这一方向的全部候选。** 两种交替方式都失败，才能输出 0。

例如 `[6,5,10,15]`：奇数位置 gcd 为 2，另一组的 5、15 都不能被 2 整除，所以可输出 2。若一个方向的 gcd 为 1，由于所有正整数都被 1 整除，这个方向自然失败，无需另加特判。

#### 重点易错：容器是 ll，不代表循环变量自动也是 ll

**数值类型要沿整条数据路径检查：读入变量 → 容器元素 → 遍历变量 → 函数参数与返回值 → 取余运算。**

`vector<ll>` 中的值如果用 `for (int x : b)` 遍历，会在每轮开始先转换为 `int`。值可能已经改变，后面再传给 `ll` 参数也无法恢复。

应使用 **`for (ll x : b)`**；使用 `auto x` 时也会按容器元素推导为 `ll`。求 `agcd` 的循环同样需要注意。

例如：

```text
3 4294967296 3 4294967297
```

正确可选择 3：两个奇数位置能被整除，两个偶数位置分别余 1、2。若在检查偶数位置时窄化为常见 32 位 `int`，原本的大数会失去原值，可能错误拒绝这个方向。**不要依赖超出可表示范围后的转换结果。**

**不是所有变量都必须用 `ll`。** `n、i` 只处理最多 100 个位置，使用 `int` 足够；必须贯穿 64 位的是可能达到 $10^{18}$ 的元素及其 gcd、候选和运算。

#### 最小整理：保存 judge 的结果，避免重复求值

原函数只读数组，同样参数重复调用结果相同，因此原实现正确。但成功分支会再求一次 gcd、再检查另一组。

保留分组与辅助函数，只将原 `solve()` 最后的判断输出部分换成：

```cpp
ll ans = judge(a, b);
if (ans == 0) ans = judge(b, a);

cout << ans << '\n';
```

时间仍为 $O(n(1+\log V))$，$V=\max a_i$，只是避免常数级的重复扫描；分组容器占 $O(n)$，另有 gcd 递归栈。**原方案已经抓住了正确模型，不需要为了缩短代码改掉清晰的分组思路。**

`n>=2` 且全部元素为正数，保证两个位置组均非空且 gcd 为正。若把 `judge` 移用于允许空组或全零组的模型，必须重新处理 gcd 为 0 的情况，不能直接取余。

**如何想到：** 相邻异色限定交替结构 → 只有两种位置分组方向 → 同色条件变成一组共同整除 → 用 gcd 汇总全部候选 → 再验证另一组全部不整除，并用传递性证明失败时无法补救。

原实现与保存结果版均已完成本地样例、小范围独立枚举及 64 位边界核验；平台结果未单独记录。
