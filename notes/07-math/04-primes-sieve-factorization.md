# 7.4 素数、筛法与质因数分解

[gcd/lcm](01-gcd-lcm.md#51-先看例子12-与-18-需要哪些因子)用质因子的指数解释整除关系；本节进一步说明：**怎样判断质数、批量找出质数，以及实际求出一个数的质因子。**

使用 C++11，沿用[竞赛基础框架](../../templates/01-basic-problem-solving/cpp-contest-template/README.md)。可复用的判定、埃氏筛、欧拉筛与分解函数见[素数模板](../../templates/07-math/primes/README.md)；两种筛法分别展开，最小质因子表留到大量分解的场景再补充。

## 1. 因数成对，只需检查到平方根

**质数（素数）**是大于 1、只有 1 和自身两个正因数的整数。大于 1 且不是质数的整数称为合数；**1 既不是质数，也不是合数**。

若 $n$ 是合数，就能写成：

$$
n=a\times b,\qquad 2\le a\le b
$$

由于 $a\le b$，有 $a^2\le ab=n$，因此 $a\le\sqrt n$。

> **合数必有一个不超过平方根的因数。** 若 $2\le d\le\lfloor\sqrt n\rfloor$ 中都找不到因数，就能判定为质数。

例如 $49=7\times7$，必须检查到 7，**循环边界要包含等号**。2、3 的检查区间为空，直接判为质数。

代码使用 `d <= n / d` 表达 $d^2\le n$。在 `n>=2、d>=2` 时两者等价，且不会先计算可能溢出的 `d*d`，也不需要浮点平方根。

## 2. 单个数：试除判定

### 变量与执行流程

- `n`：待判断的整数，不在循环中修改；小于 2 时直接返回 `false`。
- `d`：当前候选因数，从 2 递增到平方根；**不要求候选本身为质数**，枚举全部整数更直接。
- 只用标量，不开数组，也不按 `n` 分配空间。

先排除小于 2 的输入，再依次试除。遇到一个因数就能退出；全部试过仍无因数，才返回 `true`。

```cpp
using ll = long long;

// 接受任意 ll；n<2 时不是质数，不修改调用处输入
bool is_prime(ll n) {
    if (n < 2) return false;

    for (ll d = 2; d <= n / d; ++d) {
        if (n % d == 0)
            return false; // 找到一个非平凡因数，已足够判为合数
    }

    return true;
}
```

对 $n\ge2$，最坏时间 $O(\sqrt n)$，辅助空间 $O(1)$。

**用 `ll` 保证数值能表示，不代表枚举时间足够。** 少量 $10^9$ 量级的数通常可以试除；接近 `LLONG_MAX` 的大质数仍需约数十亿次检查，不能把这个函数当作大整数快速判素算法。

## 3. 范围内多次查询：埃氏筛

如果需要反复判断 `0..N` 中的数，可一次预处理整段范围，之后直接查表。

**试除是“为当前数寻找因数”，筛法是“用已知质数标记它的合数倍数”。** 两者利用相同的整除关系，计算方向不同。

### 变量、容量与下标

- `N`：需要覆盖的**最大数值**，不是询问次数。要求 `0<=N<INT_MAX`，且内存允许分配 `N+1` 个标记。
- `prime[x]`：数值 `x` 是否为质数；容器长度为 `N+1`，**0-based，下标范围 `0..N`**。
- 初始将所有标记置为 `true`，再排除 0、1。筛选过程中，`true` 暂时也可能表示“尚未被排除”，**完成预处理后**才是完整判定结果。
- `p`：当前筛选基数；若未被较小质数标记，则它是质数。
- `j`：当前要排除的倍数，用 `ll` 表示，避免末次加上 `p` 时发生 `int` 溢出。

例如只有 3 次询问，但可能查到 100000，表仍须覆盖 `0..100000`。**记录条数和数值上限不能混为一谈。**

### 为什么从平方开始标记

对质数 $p$，倍数 $2p,3p,\ldots,(p-1)p$ 的另一个因子小于 $p$；这个因子至少有一个更小的质因子，所以这些数此前已经被标记。

因此从 $p^2$ 开始即可。若从 $p$ 开始，就会把质数自身错误标记为合数。

当 $p^2\gt N$ 时停止。任何合数都有不超过平方根的质因子，因此**范围内的合数已经全部被覆盖**，不用再逐个处理更大的质数。

### 执行流程与实现

1. 建立 `0..N` 标记，排除 0、1。
2. 从 2 开始枚举 `p`，只处理 `p*p<=N` 的部分。
3. 若 `prime[p]` 已为 `false`，跳过；它的倍数已有更小质因子负责。
4. 否则，从 `p*p` 起，每次加 `p`，将对应标记改为 `false`。
5. 返回整张表；询问 `x` 时检查 `prime[x]`，前提是 `0<=x<=N`。

```cpp
// 0<=N<INT_MAX，且内存足够；返回覆盖闭区间 [0,N] 的新表
vector<bool> sieve(int N) {
    vector<bool> prime(N + 1, true);
    prime[0] = false;
    if (N >= 1) prime[1] = false;

    for (int p = 2; p <= N / p; ++p) {
        if (!prime[p]) continue;

        for (ll j = 1LL * p * p; j <= N; j += p) {
            prime[j] = false; // 只排除倍数，不改质数本身
        }
    }

    return prime;
}
```

### 小例子：筛出 20 以内的质数

| 当前 `p` | 本轮行为 | 原因 |
| --- | --- | --- |
| 2 | 标记 4、6、8、10、12、14、16、18、20 | 从 $2^2$ 开始，每次加 2 |
| 3 | 标记 9、12、15、18 | 从 $3^2$ 开始；重复标记无害 |
| 4 | 跳过 | 4 已被 2 标记 |
| 5 | 不进入循环 | $5^2\gt 20$，筛选结束 |

剩余为 `true` 的下标是 `2、3、5、7、11、13、17、19`。

筛选只遍历各质数的倍数，标记次数可按 $N/2+N/3+N/5+\cdots$ 估计。对 $N\ge3$，埃氏筛时间为 **$O(N\log\log N)$**，空间为 **$O(N)$**；建表后每次判定为 $O(1)$。0、1 的小范围是常数处理。

**筛表不依赖询问顺序。** 与[离线处理中按阈值排序扫描](../02-sequence-techniques/07-offline-processing.md#35-排序与扫描实现)对照，这里不用对询问排序；值域可覆盖时，直接按输入顺序查表即可。

## 4. 欧拉筛：由最小质因子唯一生成合数

### 4.1 数学起点：为每个合数确定唯一的生成方式

记 $s(x)$ 为整数 $x\ge2$ 的**最小质因子**。例如 $s(6)=2$、$s(9)=3$，质数自身的最小质因子就是它自己。

任意合数 $m$ 都可以写成：

$$
p=s(m),\qquad i=m/p,\qquad m=i\times p
$$

由于最小质因子 $p\le\sqrt m$，所以 $i=m/p\ge p\ge2$。这里的 `i` 是**除去最小质因子后，剩下的另一个因子**，不要求是质数。

对于 18：

- 最小质因子是 2，因此指定生成方式为 $18=9\times2$。
- 虽然也有 $18=6\times3$，但 3 不是 18 的最小质因子，这种生成方式应被排除。

> **乘法分解可以有多种，但“最小质因子 × 对应商”只有一种。** 欧拉筛要做的，就是只枚举这种分解。

接下来需要一个能写进循环的判定条件：固定 `i`，哪些质数 `p` 可以与它相乘？

**核心性质：对质数 p，有**

$$
s(ip)=p\quad\Longleftrightarrow\quad p\le s(i)
$$

分两个方向理解：

1. 若 $p\le s(i)$，则 `i` 的所有质因子都不小于 `p`；乘上 `p` 后，乘积的最小质因子就是 `p`。
2. 若 $p\gt s(i)$，则更小的质数 $s(i)$ 仍能整除 `i*p`，乘积的最小质因子就不是 `p`，这次生成不应发生。

因此规则不是“只用质数相乘”就够了，而是：

$$
\boxed{\text{只用满足 }p\le s(i)\text{ 的质数，生成 }i\times p}
$$

**为什么不会重复？** 对生成的合数 $m$，`p` 必然等于唯一的 $s(m)$，随后 `i=m/p` 也被唯一确定，不可能再由另一对合法的 `i、p` 生成。

**为什么不会漏掉？** 对任意合数 $m$，取 $p=s(m)$、$i=m/p$。若 `i` 含有比 `p` 更小的质因子，它也会整除 `m`，与 `p` 最小矛盾；所以必有 $p\le s(i)$，这对生成因子一定满足规则。

而且 $p\le i\lt m$：质数 `p` 到处理 `i` 时已经能够被发现，合数 `m` 又会在外层轮到自身之前被标记。

按整数从小到大归纳，**质数不会被两个不小于 2 的整数的乘积标记，合数则在自身轮次前已被较小的 `i` 生成**。因此轮到一个整数时，剩下的 `true` 才能确定它是新质数，而不只是未排除的候选。

### 4.2 两种筛法的 i，不是同一个角色

**变量名相同，不代表数学含义相同。** 本节埃氏筛的外层写作 `p`，有些实现把它命名为 `i`；它与欧拉筛外层的 `i` 不能混为一谈。

| 对照 | 埃氏筛 | 欧拉筛 |
| --- | --- | --- |
| 外层实际处理什么 | 选取质数作为筛选基数，合数轮次跳过 | 每个整数 `i` 都作为生成合数的另一因子，包括合数 |
| 外层范围 | 只需处理到平方根 | 遍历 `2..N`，还要识别后面的质数 |
| 内层枚举什么 | 固定质数的倍数，`p*p、p*p+p……` | 已发现的质数 `p`，只生成满足规则的 `i*p` |
| 停止的依据 | 倍数超出范围 | 乘积超范围，或已经处理到 `s(i)` |

例如欧拉筛的 `i=6` 要生成 12，`i=9` 要生成 18。**不能照搬埃氏筛的 `if (!prime[i]) continue`，把这些合数轮次跳过。**

欧拉筛中有两个不同角色：`i` 是当前遍历的整数，`p` 是准备作为乘积最小质因子的质数。`i` 递增，不表示当前的 `i` 必须是质数。

### 4.3 状态、容量与执行流程

- `N`：最大查询值，要求 `0<=N<INT_MAX` 且内存足够。
- `prime[x]`：长度 `N+1` 的真假表，**0-based，覆盖 `0..N`**；0、1 为 `false`，其余先记为候选。
- `primes`：按递增顺序保存**已发现的质数值**，如 `2、3、5、7`。列表长度随质数个数增长，不是通过 `primes[x]` 判断数值 `x` 是否为质数。
- `i`：外层当前整数。**轮到 `i` 时**，若仍未被标记，它就已确定是质数；尚未轮到的 `true` 仍可能只是未排除的候选。
- `p`：从 `primes` 由小到大取出的质数，负责生成 `i*p`。

执行顺序：

1. 初始化真假表与空质数列表。
2. 从 2 起递增扫描 `i`；若 `prime[i]` 为真，将 `i` 加入列表。
3. 依次枚举列表中的质数，先检查乘积范围，再标记 `i*p`。
4. 若 `p` 已经是 `i` 的最小质因子，结束当前内层枚举；外层继续处理下一个整数。
5. 返回真假表，查询方式与埃氏筛相同。

### 4.4 从数学条件推到核心代码

数学规则要求 $p\le s(i)$，但不必另开数组保存 `s(i)`。

**质数列表递增，第一个整除 `i` 的质数就是 `s(i)`。** 在此之前取到的 `p` 都小于 `s(i)`；第一次整除时恰好等于 `s(i)`；后面更大的 `p` 全部不应继续。

所以代码先生成当前乘积，再检查是否到达这个边界：

```cpp
// 0<=N<INT_MAX，且内存足够；返回覆盖 [0,N] 的新表
vector<bool> linear_sieve(int N) {
    vector<bool> prime(N + 1, true);
    vector<int> primes;
    prime[0] = false;
    if (N >= 1) prime[1] = false;

    for (int i = 2; i <= N; ++i) {
        if (prime[i])
            primes.push_back(i); // 先加入新质数，使 i*i 也有机会在本轮生成

        for (int p : primes) {
            if (p > N / i)
                break; // i*p 超范围，后面的质数更大；先检查，避免乘法溢出

            prime[i * p] = false; // 当前 p<=s(i)，乘积的最小质因子就是 p

            if (i % p == 0)
                break; // 已处理 p=s(i)，更大的 p 不再符合生成规则
        }
    }

    return prime;
}
```

**两种 `break` 的职责不同：**

- `p>N/i`：控制**值域与数值安全**。因为 `i、p` 均为正数，它等价于乘积超出 `N`；通过检查后再算 `i*p`，乘积不会超出表，也不会发生 `int` 溢出。
- `i%p==0`：控制**唯一生成规则**。这里不是说 `i` 为合数就停，而是说当前 `p` 已经是 `s(i)`，本轮不能再用更大的质数。

**为什么必须先标记，再判断整除？** 当 $p=s(i)$ 时仍满足允许的等号，`i*p` 必须生成。若先判断就跳出，例如 `i=2、p=2` 会漏掉 4，随后还可能把未标记的 4 错当成新质数。

**为什么缺少这个整除退出会重复？** `i=6` 用 `p=2` 生成 12 后，若继续用 `p=3` 就生成 18；到了 `i=9、p=2` 又生成一次 18。前一种生成的质数 3 不是乘积的最小质因子，恰好应被这条规则排除。

### 4.5 实例：完整走过 N=20 的生成过程

初始列表为空，0、1 为 `false`，`2..20` 暂记为 `true`。表中的“加入”均发生在内层循环之前。

| 外层 `i` | 进入本轮时的判定 | 质数列表变化 | 本轮生成的合数 | 本轮内层为何结束 |
| --- | --- | --- | --- | --- |
| 2 | 未标记，是质数 | 加入 2 | $2\times2=4$ | `2%2==0`，达到最小质因子 |
| 3 | 未标记，是质数 | 加入 3 | $3\times2=6$，$3\times3=9$ | `3%3==0` |
| 4 | 已由 `2×2` 标记 | 不变 | $4\times2=8$ | `4%2==0` |
| 5 | 未标记，是质数 | 加入 5 | $5\times2=10$，$5\times3=15$ | 下一个 `p=5` 会使乘积超范围 |
| 6 | 已由 `3×2` 标记 | 不变 | $6\times2=12$ | `6%2==0`，不再生成 `6×3` |
| 7 | 未标记，是质数 | 加入 7 | $7\times2=14$ | 下一个 `p=3` 超范围 |
| 8 | 已由 `4×2` 标记 | 不变 | $8\times2=16$ | `8%2==0` |
| 9 | 已由 `3×3` 标记 | 不变 | $9\times2=18$ | 下一个 `p=3` 超范围 |
| 10 | 已由 `5×2` 标记 | 不变 | $10\times2=20$ | `10%2==0` |
| 11 | 未标记，是质数 | 加入 11 | 无 | 最小的 `p=2` 已超范围 |
| 12..20 | 按已有标记识别 | 依次加入 13、17、19 | 无 | `i*2>20`，内层直接退出 |

最后质数列表为 `2、3、5、7、11、13、17、19`，与埃氏筛结果相同。**合数 6、9 虽不加入列表，仍承担生成其他合数的工作。**

再单看 18 的来源：它的最小质因子是 2，因此只由 `i=18/2=9、p=2` 生成；`6×3` 被整除退出排除。整个表中没有第二次生成 18 的机会。

### 4.6 为什么两层循环仍是线性时间

每次合法的内层操作都标记一个合数，而每个合数只会被生成一次，因此**所有轮次加起来的标记次数至多为 N**。

外层扫描 `2..N` 是 $O(N)$；每轮最多再发生一次乘积超范围的失败检查。建表、加入质数与标记的总工作量仍为：

$$
O(N)
$$

真假表占 $O(N)$ 空间，质数列表占 $O(\pi(N))$ 空间，其中 $\pi(N)$ 是范围内质数个数，整体空间仍为 $O(N)$。0、1 的小范围为常数处理。

返回的真假表可直接替换埃氏筛表，查询仍是 $O(1)$。所有状态在函数内部初始化，多测无需清理；若查询同一范围，可在调用处保留表并复用。

欧拉筛提供的是**唯一生成与线性复杂度的保证**；实际速度仍受整除运算、容器和内存访问影响，不能仅比较复杂度符号就断言任何范围都更快。

## 5. 一个数的质因数分解：整除后持续缩小剩余量

正整数 $n\ge2$ 可以唯一分解为不同质数的幂之积：

$$
n=p_1^{e_1}p_2^{e_2}\cdots p_k^{e_k},\qquad p_1\lt p_2\lt \cdots\lt p_k
$$

这里要保留的是**质因子及其出现次数**。例如 $360=2^3\times3^2\times5$，只记录 `2、3、5` 就会丢失指数信息。

### 变量与流程

- 输入要求 `n>=1`；函数内的 `n` 会逐步变成**尚未分解的剩余量**，不是始终保持原数。
- `p`：从 2 递增的候选因子；只检查到当前剩余量的平方根。
- `e`：本轮从剩余量中除去多少个 `p`，每轮重新置为 0。
- `factors`：`vector<pair<ll,int>>`，每项为“质因子、指数”，按质因子递增存储。**一个不同质因子占一项，不按原数值开数组。**

依次寻找能整除剩余量的 `p`，用 `while` 除尽它并计数，再继续下一候选。循环结束后，若仍有大于 1 的剩余量，将它作为最后一个质因子加入。

```cpp
// n>=1；按值接收，调用处原数不变；n=1 返回空分解
vector<pair<ll, int>> factorize(ll n) {
    vector<pair<ll, int>> factors;

    for (ll p = 2; p <= n / p; ++p) {
        if (n % p != 0) continue;

        int e = 0;
        while (n % p == 0) {
            n /= p; // 同一个质因子必须除尽
            ++e;
        }

        factors.emplace_back(p, e);
    }

    if (n > 1)
        factors.emplace_back(n, 1); // 剩余量自身是质数，不能漏掉

    return factors;
}
```

### 为什么不用先判定 p 是不是质数

当 `p` 能整除当前剩余量时，它必为质数。否则 `p` 还有更小的质因子，而这个更小的质因子早已被除尽，不可能仍存在于剩余量中。

**判定函数和分解函数不是必须串联调用。** 分解过程中“较小质因子已被除尽”的状态已经足够，不必为每个候选再调用 `is_prime`。

### 为什么末尾剩余量大于 1 时一定是质数

循环结束意味着下一候选已经超过剩余量的平方根。若剩余量仍是合数，它必有一个不超过平方根的质因子；但这样的较小候选都已经检查并除尽，产生矛盾。

例如分解 12，除尽两个 2 后剩下 3，下一候选为 3，条件 `3<=3/3` 不成立。**剩下的 3 没进入循环，必须在末尾单独加入。** 原数本身就是质数时，也由这个分支记录。

### 手推 360：候选递增，剩余量递减

| 步骤 | 连续除法 | 记录项 | 剩余量 |
| --- | --- | --- | --- |
| `p=2` | $360\to180\to90\to45$ | `(2,3)` | 45 |
| `p=3` | $45\to15\to5$ | `(3,2)` | 5 |
| 下一候选 4 | $4\gt 5/4$，结束循环 | 暂不记录 | 5 |
| 末尾检查 | 剩余量大于 1 | `(5,1)` | 分解完成 |

整个过程保持：

$$
\text{原数}=\text{已记录的质数幂之积}\times\text{剩余量}
$$

`while` 每次只把一个因子从剩余量移入已记录部分，因此乘积关系不变。

对原数 $n\ge2$，最坏时间 **$O(\sqrt n)$**；结果最多有 $O(\log n)$ 项，不计返回容器时辅助空间 $O(1)$。所有状态都在函数内初始化，多测可独立调用；不接收 0 或负数。

## 6. 本节三个模型怎样区分

| 需求 | 保留的信息 | 基础方法 |
| --- | --- | --- |
| 判断少量单独整数 | 当前候选因数 | 试除判定 |
| 对可承受的 `0..N` 值域反复判定 | 每个数是否为质数 | 埃氏筛或欧拉筛后查表 |
| 求一个数的乘法结构 | 每个质因子及指数、剩余量 | 试除分解 |

**“是质数吗”只要一个真假值，“有哪些质因子”则需要完整分解信息。** 筛出的真假表也不直接记录某个合数由哪些质数构成。

少量询问不一定值得建整张表；值域很大但记录很少时，更不能按最大值直接开数组。反过来，对同一小范围进行大量询问，逐次试除可能重复很多工作。

本节先识别需求差异；完整数学章节的写法成本与场景推荐仍留到章末，不把这张局部对照表当成全章总结。

### 7.1 P5736：质数筛

题目：[洛谷 P5736](https://www.luogu.com.cn/problem/P5736)。

- **题意：** 将输入的整数存入数组，按原顺序输出其中的质数。
- **条件：** $1\le n\le100$，$1\le a_i\le10^5$。
- **练习目的：** 先核对质数定义与边界，再判断单次判定和范围预处理是否都适用，区分元素个数与数值上限。
- **状态：复盘完成（本地核验），平台结果未单独记录。**

#### 原实现：先建表，再按输入顺序输出

```cpp
vector<bool> sieze(int n) {
    vector<bool> prime(n + 1, true);
    prime[0] = false;
    if (n >= 1) prime[1] = false;

    for (int p = 2; p <= n / p; ++p) {
        if (!prime[p]) continue;

        for (int q = p * p; q <= n; q += p) {
            prime[q] = false;
        }
    }

    return prime;
}
```

```cpp
void solve() {
    vector<bool> prime = sieze(100005);

    int n;
    cin >> n;

    while (n--) {
        int x;
        cin >> x;
        if (prime[x]) cout << x << ' ';
    }

    cout << '\n';
}
```

**按本题数值范围，筛选与输出均正确。** 表覆盖全部输入；每个值只查询一次，不排序、不去重，因此输入顺序与重复的质数都会保留。固定上限 100005 下，原 `int q` 的平方和递增均安全，不是当前代码的错误。

这里的 `n` 在两个函数中职责不同：`sieze` 的参数是**数值上限**，`solve()` 中读入的 `n` 是**输入条数**。按值传参，互不影响。

设筛表上限为 $U=100005$，时间 $O(U\log\log U+n)$、空间 $O(U)$。原稿拼写 `sieze` 保留，通用模板统一使用 `sieve`。

#### 整理版本：先存数组，再按实际最大值建表

题面还明确要求**全部存入数组**。原稿边读边输出符合输出结果，但没有落实这项练习要求；下面补齐，不把它当作判素逻辑修复。

```cpp
// 复用本节 sieve；本题 n>=1，因此数组非空
void solve() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int& x : a) cin >> x;

    int limit = *max_element(a.begin(), a.end());
    auto prime = sieve(limit); // 容量随最大输入值决定，不随输入条数决定

    for (int x : a) {
        if (prime[x]) cout << x << ' ';
    }
    cout << '\n';
}
```

这版满足题面的数组要求，并将筛表限制到实际最大值；代价是保存 $O(n)$ 的输入。原方案本来就足以处理本题，不需要因为加入欧拉筛就强行改用更复杂的预处理。

**如何想到：** 输入值有明确上界，且要逐项判定 → 可以预处理后查表；输入条数仅为 100，逐次试除也适用 → 选用筛法是本次练习目标，不是唯一正确选择。

原实现与整理版均完成本地顺序、重复值、1 和上界核验；平台结果未单独记录。

### 7.2 CF 1294C：Product of Three Numbers

题目：[Codeforces 1294C](https://codeforces.com/problemset/problem/1294/C)。

- **题意：** 找出三个两两不同、均不小于 2 的整数，使乘积为给定的 $n$；有多解可输出任意一个，无解输出 `NO`。
- **条件：** $1\le t\le100$，$2\le n\le10^9$；输出方案时按原题格式先输出 `YES`。
- **练习目的：** 将因数知识用于合法构造，练习区分“数值满足乘积”与“整个输出满足全部条件”。
- **状态：复盘完成（本地核验），平台结果未单独记录。**

#### 原实现：找出两个因数，第三个由剩余量确定

本题要求三个不同的**整数因数**，并没有要求它们都是质数。比如 64 可以输出 `2、4、8`。

```cpp
void solve() {
    ll n;
    cin >> n;

    ll a = -1, b = -1, c = -1;

    for (ll i = 2; i <= n / i; ++i) {
        if (n % i == 0) {
            a = i;
            n /= i;
            break; // 先固定最小因数，n 变成剩余量
        }
    }

    if (a == -1) {
        cout << "NO\n";
        return;
    }

    for (ll i = 2; i <= n / i; ++i) {
        if (n % i == 0 && i != a) {
            b = i;
            n /= i;
            break; // 只要求 b 与 a 不同，b 不必为质数
        }
    }

    if (b == -1) {
        cout << "NO\n";
        return;
    }

    c = n;

    if (c <= 1 || c == a || c == b) {
        cout << "NO\n";
        return;
    }

    cout << "YES\n";
    cout << a << ' ' << b << ' ' << c << '\n';
}
```

每次找到因数就除掉它，始终保留：**原数等于已选因数的乘积，再乘当前剩余量**。两轮结束后无需再找第三个数，它只能是 `c=n`。

| 原数 | 第一轮后 | 第二轮后 | 结论 |
| --- | --- | --- | --- |
| 30 | `a=2`，剩 15 | `b=3`，剩 5 | `2、3、5` 合法 |
| 32 | `a=2`，剩 16 | `b=4`，剩 4 | `b==c`，不能输出 |
| 64 | `a=2`，剩 32 | `b=4`，剩 8 | `2、4、8` 合法 |

#### 为什么这两个最小选择不会漏解

**第一步：若原本有解，总能改造成包含最小质因子 a 的解。** 第一轮找到的最小因数必为质数。

若某个合法方案已经包含 `a`，无需改变。否则三个因数都大于 `a`，其中一个一定能写成 $a\times t$，且 $t\ge2$。将另外两个因数记为 $u\lt v$，就能改成：

$$
a,\quad u,\quad tv
$$

乘积不变，而且 $a\lt u\lt v\lt tv$，三个数仍两两不同。因此**先固定 `a` 不会破坏原本存在的解**。

**第二步：在固定 a 后，最小的可用 b 会给 c 留下最多余量。** 设剩余量为 $R$，上一步保证若有解，就存在 $a\lt u\lt v$ 且 $uv=R$。

由于 $u\lt \sqrt R$，第二轮一定能找到某个 $b\le u$。它排除了 `a`，且原数没有比 `a` 更小的因数，所以 $b\gt a$。于是：

$$
c=R/b\ge R/u=v\gt u\ge b\gt a
$$

这就同时保证了乘积、下界和两两不同。**反过来，若原程序找不到 b，或算出的 c 不合法，就不可能存在这样一个原解。**

因此当前构造已经合适，推荐沿用同一实现，不必先求完整质因数分解再按质因子种数分类。

#### 边界、代价与发现过程

- **剩余量会改变：** 第二轮的平方根边界针对除去 `a` 后的 `n`；不能把它误认为原数不变。
- **第一个因数是质数，第二个不保证是质数。** 64 的第二个因数为 4，若把候选强制限制为质数，会漏掉合法解。
- `-1` 表示尚未找到，先处理失败分支，再使用结果；第三个数还要检查下界与重复。
- 两轮试除的时间上界仍为 $O(\sqrt{\text{原数}})$，空间 $O(1)$。题目只需一个方案，不需要枚举全部拆分。

**三个未知数的乘积固定 → 选两个就能确定第三个 → 优先尝试小因数，为剩余量保留空间 → 用变换论证最小选择不会损失可行解 → 最后核对整个方案。**

原实现通过官方样例与本地小范围独立枚举、边界核验；平台结果未单独记录，不补记 AC。
