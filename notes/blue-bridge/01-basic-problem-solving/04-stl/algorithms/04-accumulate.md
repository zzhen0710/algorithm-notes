# 04 · accumulate 与区间聚合

这一节介绍 STL 中的数值算法 `accumulate`。

它连接：

-   区间遍历；
-   函数对象；
-   自定义聚合；
-   类型安全。

核心思想：

> 将一个区间中的多个元素，通过某种规则压缩成一个结果。

例如：

-   求和；
-   求乘积；
-   统计贡献值；
-   自定义计算。

------------------------------------------------------------------------

# 一、accumulate

## API

``` cpp
template<class InputIt, class T>
T accumulate(
    InputIt first,
    InputIt last,
    T init
);
```

返回类型：

``` cpp
T
```

作用：

> 从左到右遍历区间，将每个元素累积到初始值中。

默认操作：

``` cpp
+
```

数学表示：

$ans = init + a_1 + a_2 + ... + a_n$

------------------------------------------------------------------------

## 示例

``` cpp
vector<int> a = {1, 2, 3, 4, 5};

int sum = accumulate(
    a.begin(),
    a.end(),
    0
);
```

结果：

``` text
15
```

等价于：

``` cpp
int sum = 0;

for (int x : a) {
    sum += x;
}
```

------------------------------------------------------------------------

# 二、第三个参数的重要性

`accumulate` 的第三个参数：

``` cpp
init
```

不仅表示初始值。

它同时决定：

> 整个计算过程的类型以及返回类型。

------------------------------------------------------------------------

例如：

``` cpp
vector<int> a = {
    1000000000,
    1000000000
};

auto sum = accumulate(
    a.begin(),
    a.end(),
    0
);
```

这里：

``` cpp
0
```

类型是：

``` cpp
int
```

因此计算按照：

``` cpp
int
```

进行。

可能发生溢出。

------------------------------------------------------------------------

正确：

``` cpp
long long sum =
    accumulate(
        a.begin(),
        a.end(),
        0LL
    );
```

其中：

``` cpp
0LL
```

使累加类型变为：

``` cpp
long long
```

------------------------------------------------------------------------

记忆：

> `accumulate` 的第三个参数不仅是初始值，也是类型控制点。

------------------------------------------------------------------------

# 三、自定义操作

除了默认加法：

``` cpp
+
```

还可以传入二元操作。

## API

``` cpp
template<class InputIt, class T, class BinaryOperation>
T accumulate(
    InputIt first,
    InputIt last,
    T init,
    BinaryOperation op
);
```

------------------------------------------------------------------------

例如求乘积：

``` cpp
vector<int> a = {1, 2, 3, 4};

int ans =
    accumulate(
        a.begin(),
        a.end(),
        1,
        multiplies<int>()
    );
```

结果：

$1 \times 2 \times 3 \times 4 = 24$

------------------------------------------------------------------------

也可以使用 lambda：

``` cpp
int ans =
    accumulate(
        a.begin(),
        a.end(),
        0,
        [](int sum, int x) {
            return sum + x * x;
        }
    );
```

计算：

$x_1^2+x_2^2+...+x_n^2$

------------------------------------------------------------------------

# 四、常见竞赛应用

## 1. 区间求和

最常见：

``` cpp
long long sum =
    accumulate(
        a.begin(),
        a.end(),
        0LL
    );
```

注意：

数据范围较大时使用：

``` cpp
0LL
```

避免 `int` 溢出。

------------------------------------------------------------------------

## 2. 自定义统计

例如：

统计数组元素经过某种转换后的总贡献：

``` cpp
long long ans =
    accumulate(
        a.begin(),
        a.end(),
        0LL,
        [](long long sum, int x) {
            return sum + f(x);
        }
    );
```

其中：

``` cpp
f(x)
```

表示每个元素贡献。

------------------------------------------------------------------------

# 五、为什么使用 algorithm

手写：

``` cpp
int sum = 0;

for (int x : a) {
    sum += x;
}
```

当然可以。

但是：

``` cpp
accumulate()
```

表达的是：

> 对一个区间进行聚合。

代码语义更加明确。

------------------------------------------------------------------------

不过不要滥用。

如果逻辑复杂：

``` cpp
if(...)
else(...)
```

或者需要维护多个状态：

普通循环通常更加清晰。

# 七、本节总结

## accumulate

作用：

> 将区间元素按照某种规则聚合成一个结果。

模板：

``` cpp
accumulate(
    begin,
    end,
    init
);
```

------------------------------------------------------------------------

重点：

1.  第三个参数决定计算类型：

``` cpp
0
```

可能得到：

``` cpp
int
```

大范围求和使用：

``` cpp
0LL
```

------------------------------------------------------------------------

2.  可以自定义操作：

``` cpp
accumulate(
    begin,
    end,
    init,
    op
);
```

------------------------------------------------------------------------

3.  本质：

> 区间 → 单个结果。

后续：

-   前缀和；
-   差分；
-   动态规划中的状态聚合；

都会继续体现这种思想。
