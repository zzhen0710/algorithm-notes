# 09 · find / count / mismatch 与查找统计算法

这一节介绍 STL 中常用的查找类算法。

共同特点：

> 在一个迭代器区间内，对元素进行查找或比较。

与前面的：

| 算法              | 特点                   |
| ----------------- | ---------------------- |
| `lower_bound()`   | 利用有序性二分查找边界 |
| `binary_search()` | 判断有序序列是否存在   |

不同：

> 本节算法不要求区间有序，通常通过线性扫描完成。

------------------------------------------------------------------------

# 一、find

## API

``` cpp
template<class InputIt, class T>
InputIt find(
    InputIt first,
    InputIt last,
    const T& value
);
```

返回类型：

``` cpp
iterator
```

作用：

> 返回第一个等于 value 的元素位置。

如果不存在：

返回：

``` cpp
end()
```

------------------------------------------------------------------------

例如：

``` cpp
vector<int> a = {
    3,5,1,7,5
};

auto it = find(
    a.begin(),
    a.end(),
    5
);
```

结果：

``` text
3 5 1 7 5
  ↑
```

返回第一个 `5`。

------------------------------------------------------------------------

判断是否找到：

``` cpp
if (it != a.end()) {
    cout << "found";
}
```

获取位置：

``` cpp
int pos = it - a.begin();
```

------------------------------------------------------------------------

# 二、find_if

`find_if()` 是 `find()` 的条件版本。

作用：

> 查找第一个满足条件的元素。

## API

``` cpp
template<class InputIt, class UnaryPredicate>
InputIt find_if(
    InputIt first,
    InputIt last,
    UnaryPredicate pred
);
```

------------------------------------------------------------------------

例如：

寻找第一个偶数：

``` cpp
vector<int> a = {
    3,5,7,8,10
};

auto it =
    find_if(
        a.begin(),
        a.end(),
        [](int x) {
            return x % 2 == 0;
        }
    );
```

结果：

``` text
3 5 7 8 10
      ↑
```

------------------------------------------------------------------------

# 三、count

## API

``` cpp
template<class InputIt, class T>
count(
    InputIt first,
    InputIt last,
    const T& value
);
```

返回：

``` cpp
整数
```

作用：

> 统计区间内等于 value 的元素数量。

------------------------------------------------------------------------

例如：

``` cpp
vector<int> a = {
    1,2,2,3,2
};

int cnt =
    count(
        a.begin(),
        a.end(),
        2
    );
```

结果：

``` text
3
```

------------------------------------------------------------------------

# 四、count_if

条件统计。

作用：

> 统计满足条件的元素数量。

例如：

``` cpp
int cnt =
    count_if(
        a.begin(),
        a.end(),
        [](int x) {
            return x % 2 == 0;
        }
    );
```

------------------------------------------------------------------------

常见用途：

-   统计满足条件数量；
-   替代手写循环。

------------------------------------------------------------------------

# 五、find 与 lower_bound 区别

| 算法          | 要求     | 复杂度      | 用途     |
| ------------- | -------- | ----------- | -------- |
| `find`        | 无要求   | $O(n)$      | 普通查找 |
| `lower_bound` | 必须有序 | $O(\log n)$ | 寻找边界 |

------------------------------------------------------------------------

例如：

无序：

``` text
5 1 7 3
```

使用：

``` cpp
find()
```

------------------------------------------------------------------------

有序：

``` text
1 3 5 7
```

使用：

``` cpp
lower_bound()
```

------------------------------------------------------------------------

核心区别：

> `find()` 查找元素，`lower_bound()` 查找边界。

------------------------------------------------------------------------

# 六、mismatch

`mismatch()` 用于比较两个区间。

作用：

> 找到两个序列第一个不同的位置。

------------------------------------------------------------------------

## API

``` cpp
template<class InputIt1, class InputIt2>
pair<InputIt1, InputIt2>
mismatch(
    InputIt1 first1,
    InputIt1 last1,
    InputIt2 first2
);
```

返回：

``` cpp
pair<iterator, iterator>
```

------------------------------------------------------------------------

例如：

``` cpp
vector<int> a = {
    1,2,3,4
};

vector<int> b = {
    1,2,5,4
};

auto p =
    mismatch(
        a.begin(),
        a.end(),
        b.begin()
    );
```

找到：

``` text
a:
1 2 3 4
    ↑

b:
1 2 5 4
    ↑
```

返回：

``` cpp
p.first
```

指向 `3`。

``` cpp
p.second
```

指向 `5`。

------------------------------------------------------------------------

# 七、equal

`equal()` 与 `mismatch()` 对应。

作用：

> 判断两个区间是否完全相等。

例如：

``` cpp
bool ok =
    equal(
        a.begin(),
        a.end(),
        b.begin()
    );
```

本质：

> 检查是否不存在不同位置。

------------------------------------------------------------------------

# 八、复杂度

| 算法       | 复杂度 |
| ---------- | ------ |
| `find`     | $O(n)$ |
| `find_if`  | $O(n)$ |
| `count`    | $O(n)$ |
| `count_if` | $O(n)$ |
| `mismatch` | $O(n)$ |

------------------------------------------------------------------------

# 九、本节总结

| 算法       | 作用                       | 返回                       |
| ---------- | -------------------------- | -------------------------- |
| `find`     | 查找指定元素               | `iterator`                 |
| `find_if`  | 查找满足条件元素           | `iterator`                 |
| `count`    | 统计元素数量               | 整数                       |
| `count_if` | 统计满足条件数量           | 整数                       |
| `mismatch` | 寻找两个序列第一个不同位置 | `pair<iterator, iterator>` |

------------------------------------------------------------------------

核心：

> STL 查找算法分两类：

| 类型                         | 代表                          |
| ---------------------------- | ----------------------------- |
| 线性扫描查找（不利用有序性） | `find` / `count`              |
| 基于有序性的边界查找         | `lower_bound` / `upper_bound` |

竞赛中：

-   已知有序 → 优先考虑二分；
-   无序或条件复杂 → 使用线性查找。

------------------------------------------------------------------------

本节属于工具型算法：

不强行找题。

重点掌握：

``` cpp
find(begin, end, x);

count(begin, end, x);
```
