# 05 · min_element / max_element 与极值查找

这一节介绍 STL 中的极值查找算法。

前面的算法：

| 算法            | 作用         |
| --------------- | ------------ |
| `sort()`        | 改变元素顺序 |
| `lower_bound()` | 寻找边界位置 |
| `unique()`      | 压缩有效元素 |
| `accumulate()`  | 聚合区间结果 |

而：

> `min_element()` / `max_element()` 负责在一个区间中寻找极值位置。

它们本质上是：

> 线性扫描 + 返回迭代器。

------------------------------------------------------------------------

# 一、min_element

## API

``` cpp
template<class ForwardIt>
ForwardIt min_element(
    ForwardIt first,
    ForwardIt last
);
```

返回类型：

``` cpp
iterator
```

作用：

> 返回区间内最小元素的位置。

注意：

它返回的是：

``` cpp
iterator
```

而不是元素值。

------------------------------------------------------------------------

例如：

``` cpp
vector<int> a = {
    3,1,5,2,4
};

auto it = min_element(
    a.begin(),
    a.end()
);
```

结果：

``` text
3 1 5 2 4
  ↑
```

得到：

``` cpp
*it == 1
```

------------------------------------------------------------------------

如果需要下标：

``` cpp
int pos = it - a.begin();
```

结果：

``` text
1
```

------------------------------------------------------------------------

# 二、max_element

## API

``` cpp
template<class ForwardIt>
ForwardIt max_element(
    ForwardIt first,
    ForwardIt last
);
```

返回类型：

``` cpp
iterator
```

作用：

> 返回区间内最大元素的位置。

------------------------------------------------------------------------

例如：

``` cpp
vector<int> a = {
    3,1,5,2,4
};

auto it = max_element(
    a.begin(),
    a.end()
);
```

结果：

``` text
3 1 5 2 4
    ↑
```

得到：

``` cpp
*it == 5
```

------------------------------------------------------------------------

# 三、为什么返回 iterator？

这是 STL algorithm 的统一设计。

`min_element()` 和 `max_element()` 只是查询，不直接修改数据。

它们无法提前知道用户需要：

-   元素值；
-   元素位置；
-   修改该元素；
-   访问其他关联信息。

因此返回：

``` cpp
iterator
```

让使用者自行决定。

------------------------------------------------------------------------

获取值：

``` cpp
int mx = *max_element(
    a.begin(),
    a.end()
);
```

获取位置：

``` cpp
auto it = max_element(
    a.begin(),
    a.end()
);

int pos = it - a.begin();
```

核心思想：

> STL algorithm 更倾向返回信息所在的位置，而不是直接返回数据。

------------------------------------------------------------------------

# 四、自定义比较器

`min_element()` 和 `max_element()` 也支持自定义比较规则。

## API

``` cpp
template<class ForwardIt, class Compare>
ForwardIt min_element(
    ForwardIt first,
    ForwardIt last,
    Compare comp
);
```

------------------------------------------------------------------------

例如：

寻找绝对值最小的元素：

``` cpp
vector<int> a = {
    -10,3,-2,8
};

auto it =
    min_element(
        a.begin(),
        a.end(),
        [](int a, int b) {
            return abs(a) < abs(b);
        }
    );
```

结果：

``` text
-2
```

------------------------------------------------------------------------

这与之前：

-   `sort`
-   `lower_bound`

中的比较器思想一致：

> 改变比较规则，本质是在改变"什么更小"。

------------------------------------------------------------------------

# 五、minmax_element

C++11 提供：

``` cpp
minmax_element()
```

可以一次寻找：

-   最小值位置；
-   最大值位置。

------------------------------------------------------------------------

## API

``` cpp
template<class ForwardIt>
pair<ForwardIt, ForwardIt>
minmax_element(
    ForwardIt first,
    ForwardIt last
);
```

返回：

``` cpp
pair<iterator, iterator>
```

其中：

``` cpp
first
```

表示最小值。

``` cpp
second
```

表示最大值。

------------------------------------------------------------------------

例如：

``` cpp
vector<int> a = {
    3,1,5,2,4
};

auto p =
    minmax_element(
        a.begin(),
        a.end()
    );
```

得到：

``` cpp
*p.first == 1

*p.second == 5
```

------------------------------------------------------------------------

相比：

``` cpp
min_element()
+
max_element()
```

分别扫描：

约需要：

$2n$

次比较。

而：

``` cpp
minmax_element()
```

可以同时完成：

约：

$1.5n$

次比较。

------------------------------------------------------------------------

# 六、与手写循环比较

传统写法：

``` cpp
int mn = a[0];

for (int x : a) {
    mn = min(mn, x);
}
```

当然可以。

但是：

``` cpp
auto it = min_element(
    a.begin(),
    a.end()
);
```

表达更加明确：

> 在这个区间寻找最小元素。

------------------------------------------------------------------------

## 什么时候不用？

如果需要同时维护多个信息：

例如：

-   最高分；
-   学生姓名；
-   编号；
-   其他状态；

通常手写循环更清晰。

因为这时目标不是单纯寻找极值，而是维护一个完整状态。

------------------------------------------------------------------------

# 七、常见使用场景

## 1. 获取最大最小值

``` cpp
int mx =
    *max_element(
        a.begin(),
        a.end()
    );
```

------------------------------------------------------------------------

## 2. 获取最大最小位置

``` cpp
auto it =
    max_element(
        a.begin(),
        a.end()
    );

cout << it - a.begin();
```

------------------------------------------------------------------------

## 3. 结构体中的最大贡献

例如：

``` cpp
struct Node {
    int value;
    int id;
};
```

寻找最大 `value`：

``` cpp
auto it =
    max_element(
        a.begin(),
        a.end(),
        [](Node a, Node b) {
            return a.value < b.value;
        }
    );
```

------------------------------------------------------------------------

# 八、本节总结

| 算法             | 作用                 | 返回                       |
| ---------------- | -------------------- | -------------------------- |
| `min_element`    | 寻找最小元素位置     | `iterator`                 |
| `max_element`    | 寻找最大元素位置     | `iterator`                 |
| `minmax_element` | 同时寻找最大最小位置 | `pair<iterator, iterator>` |

核心：

> 极值算法不是返回元素，而是返回元素所在位置。

这样可以：

-   获取值；
-   获取下标；
-   修改元素；
-   获取附加信息。
