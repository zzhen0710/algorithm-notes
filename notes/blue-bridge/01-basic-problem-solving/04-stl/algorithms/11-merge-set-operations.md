# 11 · merge / inplace_merge / 集合操作

这一节介绍 STL 中与**有序区间合并**相关的算法。

核心思想：

> 利用两个有序序列的单调性，在线性时间内完成合并或集合运算。

这些算法依赖：

-   区间已经有序；
-   排序规则一致。

对应前面的：

-   `sort()`：建立有序性；
-   `lower_bound()`：利用有序性查找；
-   本节：利用有序性合并。

------------------------------------------------------------------------

# 一、merge

## API

``` cpp
template<class InputIt1, class InputIt2, class OutputIt>
OutputIt merge(
    InputIt1 first1,
    InputIt1 last1,
    InputIt2 first2,
    InputIt2 last2,
    OutputIt d_first
);
```

返回：

``` cpp
iterator
```

作用：

> 合并两个有序区间，生成一个新的有序序列。

------------------------------------------------------------------------

例如：

两个升序数组：

``` text
a:

1 3 5


b:

2 4 6
```

代码：

``` cpp
vector<int> c;

merge(
    a.begin(),
    a.end(),
    b.begin(),
    b.end(),
    back_inserter(c)
);
```

结果：

``` text
1 2 3 4 5 6
```

------------------------------------------------------------------------

## merge 的本质

类似归并排序中的 merge。

维护两个指针：

``` text
a:

1 3 5
↑


b:

2 4 6
↑
```

每次比较两个当前位置：

-   较小元素加入结果；
-   对应指针后移。

最终得到：

``` text
1 2 3 4 5 6
```

复杂度：

\[ O(n+m) \]

------------------------------------------------------------------------

# 二、merge 注意事项

## 1. 输入必须有序

错误：

``` text
a:

3 1 5
```

直接合并结果无意义。

需要先：

``` cpp
sort(a.begin(), a.end());
```

------------------------------------------------------------------------

## 2. 输出不要覆盖输入

错误：

``` cpp
merge(
    a.begin(),
    a.end(),
    b.begin(),
    b.end(),
    a.begin()
);
```

因为输出过程会破坏还未读取的数据。

通常：

``` cpp
vector<int> c;
```

作为目标容器。

------------------------------------------------------------------------

# 三、inplace_merge

`merge()`：

> 合并两个独立有序区间。

`inplace_merge()`：

> 合并同一个数组中的两个相邻有序区间。

------------------------------------------------------------------------

## API

``` cpp
template<class BidirectionalIt>
void inplace_merge(
    BidirectionalIt first,
    BidirectionalIt middle,
    BidirectionalIt last
);
```

------------------------------------------------------------------------

例如：

``` text
1 3 5 | 2 4 6
```

两个部分分别有序。

调用：

``` cpp
inplace_merge(
    a.begin(),
    a.begin()+3,
    a.end()
);
```

结果：

``` text
1 2 3 4 5 6
```

------------------------------------------------------------------------

# 四、merge 与 inplace_merge 区别

| 算法            | 输入形式                     | 是否产生新序列 |
| --------------- | ---------------------------- | -------------- |
| `merge`         | 两个独立有序区间             | 是             |
| `inplace_merge` | 一个数组中的两个相邻有序区间 | 否             |

------------------------------------------------------------------------

# 五、集合操作

STL 还提供基于有序序列的集合运算。

包括：

-   并集；
-   交集；
-   差集。

要求：

> 两个输入序列必须有序。

------------------------------------------------------------------------

# 六、set_union

作用：

> 求两个集合的并集。

例如：

``` text
A:

1 2 3 5


B:

2 3 4 6
```

结果：

``` text
1 2 3 4 5 6
```

------------------------------------------------------------------------

# 七、set_intersection

作用：

> 求两个集合的交集。

例如：

``` text
A:

1 2 3 5


B:

2 3 4 6
```

结果：

``` text
2 3
```

------------------------------------------------------------------------

# 八、set_difference

作用：

> 求两个集合的差集。

例如：

A - B：

``` text
A:

1 2 3 5


B:

2 3 4 6
```

结果：

``` text
1 5
```

------------------------------------------------------------------------

# 九、集合算法总结

| 算法               | 作用 |
| ------------------ | ---- |
| `set_union`        | 并集 |
| `set_intersection` | 交集 |
| `set_difference`   | 差集 |

注意：

这里的：

``` cpp
set_
```

不是：

``` cpp
std::set
```

容器。

它们只是：

> 对有序区间进行集合运算的 algorithm。

------------------------------------------------------------------------

# 十、复杂度总结

| 算法               | 时间复杂度  | 说明                   |
| ------------------ | ----------- | ---------------------- |
| `merge`            | $O(n+m)$    | 双指针合并两个有序区间 |
| `inplace_merge`    | 通常 $O(n)$ | 合并两个相邻有序区间   |
| `set_union`        | $O(n+m)$    | 有序区间求并集         |
| `set_intersection` | $O(n+m)$    | 有序区间求交集         |
| `set_difference`   | $O(n+m)$    | 有序区间求差集         |

其中：

-   $n$、$m$ 表示两个输入区间长度；
-   本质都是利用有序性进行一次线性扫描。

------------------------------------------------------------------------

# 十一、本节总结

| 算法               | 作用                     | 返回       |
| ------------------ | ------------------------ | ---------- |
| `merge`            | 合并两个有序区间         | `iterator` |
| `inplace_merge`    | 原地合并两个相邻有序区间 | `void`     |
| `set_union`        | 集合并集                 | `iterator` |
| `set_intersection` | 集合交集                 | `iterator` |
| `set_difference`   | 集合差集                 | `iterator` |

核心：

> STL 合并算法依赖有序性，本质都是双指针扫描。

重点掌握：

``` cpp
merge(
    a.begin(),
    a.end(),
    b.begin(),
    b.end(),
    back_inserter(c)
);
```

以及：

``` cpp
set_union()
set_intersection()
set_difference()
```

------------------------------------------------------------------------

**理解型工具算法**

重点：

-   知道输入必须有序；
-   理解双指针合并；
-   了解集合操作接口。
