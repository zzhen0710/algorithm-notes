# 07 · next_permutation / prev_permutation 与排列生成

这一节介绍 STL 中的排列生成算法。

`next_permutation()` 的本质：

> 已知当前排列，直接计算字典序中的下一个排列。

它和 DFS 全排列不是同一种思想：

-   DFS：从无到有构造所有状态；
-   `next_permutation()`：在已有状态之间进行字典序转移。

两者都是竞赛中常见的排列枚举方法。

------------------------------------------------------------------------

# 一、next_permutation

## API

``` cpp
template<class BidirectionalIt>
bool next_permutation(
    BidirectionalIt first,
    BidirectionalIt last
);
```

返回类型：

``` cpp
bool
```

作用：

> 将当前排列变为字典序下一个排列。

返回：

-   存在下一个排列：`true`
-   当前已经是最大排列：`false`

当返回 `false` 时，会将序列变为最小排列。

------------------------------------------------------------------------

# 二、字典序

排列按照类似字符串的方式比较。

例如：

```text
123
132
213
231
312
321
```

因此：

`next_permutation()`

寻找的是：

> 当前排列之后，字典序最接近的更大排列。

------------------------------------------------------------------------

# 三、next_permutation 的底层原理

例如当前：

```text
1 2 5 4 3
```

目标：

找到比它大一点的排列。

## 1. 找第一个下降位置

从右向左寻找：

``` cpp
a[i] < a[i + 1]
```

这里：

```text
1 2 5 4 3
    ↑
```

因为：

```text
2 < 5
```

找到 `i`。

为什么？

右侧：

```text
5 4 3
```

已经是降序。

说明右侧已经是当前元素集合中的最大排列。

如果只改变右侧，不可能得到更大的整体排列。

所以必须提升 `a[i]`。

------------------------------------------------------------------------

## 2. 找刚好更大的元素并交换

在右侧寻找：

> 大于 `a[i]` 的最小元素。

这里：

```text
5 4 3
```

比 `2` 大的最小元素：

```text
3
```

交换：

```text
1 3 5 4 2
```

为什么选择最小？

因为：

> 需要增加幅度最小，才能得到字典序中的下一个排列。

------------------------------------------------------------------------

## 3. 反转后缀

交换后：

```text
1 3 5 4 2
```

右侧：

```text
5 4 2
```

仍然是最大排列。

为了让结果尽可能小：

将后缀变为升序：

```text
5 4 2

↓

2 4 5
```

得到：

```text
1 3 2 4 5
```

这就是下一个排列。

------------------------------------------------------------------------

整体过程：

```text
寻找提升位置
        ↓
交换刚好更大的元素
        ↓
后缀变为最小排列
        ↓
得到下一个字典序
```

------------------------------------------------------------------------

# 四、使用模板

枚举全部排列：

``` cpp
vector<int> a = {1, 2, 3};

do {

    // 当前排列就是一个合法状态
    for (int x : a)
        cout << x;

    cout << '\n';

} while (
    next_permutation(
        a.begin(),
        a.end()
    )
);
```

输出：

```text
123
132
213
231
312
321
```

注意使用 `do-while`：

因为第一次进入循环时，初始排列也需要处理。

------------------------------------------------------------------------

# 五、为什么需要先排序？

`next_permutation()` 只保证：

> 从当前状态继续向字典序更大的方向移动。

例如：

从：

```text
1 2 3
```

开始：

可以遍历：

```text
123
132
213
231
312
321
```

覆盖全部排列。

但是从：

```text
2 1 3
```

开始：

只能生成：

```text
213
231
312
321
```

前面的排列无法回到。

所以枚举全部排列：

``` cpp
sort(
    a.begin(),
    a.end()
);
```

初始化为最小字典序。

------------------------------------------------------------------------

# 六、DFS 全排列（经典方法）

`next_permutation()` 不是全排列唯一方法。

竞赛中更经典的方法是：

> DFS 回溯构造排列。

思想：

每一层决定一个位置放哪个数字。

例如：

```text
        []
     /   |   \
    1    2    3
   / \
  12  13
  |
 123
```

代码：

``` cpp
vector<int> a;
vector<int> path;
vector<bool> used;

void dfs(int depth) {

    // 一个排列构造完成
    if (depth == a.size()) {

        for (int x : path)
            cout << x << ' ';

        cout << '\n';
        return;
    }

    for (int i = 0; i < a.size(); i++) {

        // 当前数字已经使用
        if (used[i])
            continue;

        // 选择当前数字
        used[i] = true;
        path.push_back(a[i]);

        // 继续构造下一位
        dfs(depth + 1);

        // 回溯，撤销选择
        path.pop_back();
        used[i] = false;
    }
}
```

复杂度：

排列数量：

$n!$

每个排列输出：

$O(n)$

总复杂度：

$O(n \times n!)$

------------------------------------------------------------------------

# 七、DFS 与 next_permutation 区别

| 方法               | 特点                     |
| ------------------ | ------------------------ |
| DFS 回溯           | 自己构造状态，可以剪枝   |
| `next_permutation` | 直接生成字典序下一个状态 |

| 场景                           | 方法               |
| ------------------------------ | ------------------ |
| 需要限制条件、剪枝             | DFS                |
| 需要自定义搜索顺序             | DFS                |
| 单纯枚举全部排列               | `next_permutation` |
| 需要按字典序逐个生成下一个状态 | `next_permutation` |

------------------------------------------------------------------------

# 八、重复元素

例如：

``` cpp
vector<int> a = {
    1,1,2
};
```

直接使用：

``` cpp
next_permutation(
    a.begin(),
    a.end()
);
```

得到：

```text
112
121
211
```

不会生成重复排列。

------------------------------------------------------------------------

# 九、prev_permutation

与 `next_permutation()` 相反：

> 生成字典序中的上一个排列。

API：

``` cpp
template<class BidirectionalIt>
bool prev_permutation(
    BidirectionalIt first,
    BidirectionalIt last
);
```

例如：

```text
321
312
231
213
132
123
```

------------------------------------------------------------------------

# 十、复杂度

生成一个排列：
$O(n)$

枚举全部排列：
共有 $n!$ 个排列，每次生成和处理一个排列通常需要 $O(n)$：

$O(n \times n!)$

空间：

-   `next_permutation()`：$O(1)$
-   DFS：$O(n)$ 递归栈和状态数组

------------------------------------------------------------------------

# 十一、本节总结

| 算法               | 作用                 | 返回   |
| ------------------ | -------------------- | ------ |
| `next_permutation` | 生成下一个字典序排列 | `bool` |
| `prev_permutation` | 生成上一个字典序排列 | `bool` |

常用模板：

``` cpp
sort(a.begin(), a.end());

do {

    // 处理当前排列

} while (
    next_permutation(
        a.begin(),
        a.end()
    )
);
```

核心理解：

> `next_permutation()`
> 通过提升最低位、交换刚好更大的元素、最小化后缀，得到当前排列之后最近的更大排列。

排列枚举：

-   有约束、需要剪枝 → DFS
-   单纯枚举 → `next_permutation`
