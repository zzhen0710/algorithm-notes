# 03 · unique、erase-remove 与 STL 惯用法

这一节连接：

-   `vector` 的动态数组特性；
-   迭代器；
-   algorithm 算法只操作区间、不直接改变容器大小；
-   后续离散化、去重、压缩状态。

很多竞赛代码中都会出现：

``` cpp
sort();
unique();
erase();
```

这三个组合。

核心思想：

> STL algorithm
> 通常只负责调整元素，不负责管理容器大小；真正改变容器结构由 container
> 完成。

------------------------------------------------------------------------

# 一、unique

## API

``` cpp
template<class ForwardIt>
ForwardIt unique(
    ForwardIt first,
    ForwardIt last
);
```

返回类型：

``` cpp
iterator
```

作用：

> 删除相邻重复元素，并返回新的逻辑结尾位置。

注意：

**`unique()` 不会真正删除元素。**

------------------------------------------------------------------------

例如：

``` cpp
vector<int> a = {
    1,2,2,3,3,3,4
};

auto it = unique(
    a.begin(),
    a.end()
);
```

执行后：

    原数组：
    
    1 2 2 3 3 3 4


    处理：
    
    1 2 3 4 ? ? ?
            ↑
            it

前面的有效区域：

    1 2 3 4

但是：

``` cpp
a.size()
```

仍然：

    7

------------------------------------------------------------------------

所以：

`unique()`

只是：

> 压缩有效元素。

并不会：

> 缩短 vector。

------------------------------------------------------------------------

# 二、为什么需要 erase？

因为：

``` cpp
unique()
```

只移动元素。

如果希望真正删除：

需要：

``` cpp
erase()
```

组合：

``` cpp
a.erase(
    unique(a.begin(), a.end()),
    a.end()
);
```

这就是经典：

## Erase-Remove 惯用法

执行过程：

第一步：

``` cpp
unique()
```

得到新的结束位置。

第二步：

``` cpp
erase()
```

删除后面的无效区域。

------------------------------------------------------------------------

例如：

``` cpp
vector<int> a = {
    1,2,2,3,3,4
};

a.erase(
    unique(a.begin(), a.end()),
    a.end()
);
```

结果：

    1 2 3 4

此时：

``` cpp
a.size()
```

为：

    4

------------------------------------------------------------------------

# 三、unique 的前提：必须相邻

这是非常容易错误理解的地方。

错误：

``` cpp
vector<int> a = {
    1,2,1,3
};

a.erase(
    unique(a.begin(), a.end()),
    a.end()
);
```

不能删除两个 `1`。

原因：

`unique()` 只比较：

    当前元素
    前一个保留元素

它处理的是：

    重复块

而不是：

    所有重复值

------------------------------------------------------------------------

因此通常去重：

``` cpp
sort(a.begin(), a.end());

a.erase(
    unique(a.begin(), a.end()),
    a.end()
);
```

流程：

## 第一步：排序

让相同元素相邻：

    3 1 3 2 1
    
    ↓
    
    1 1 2 3 3

## 第二步：unique

压缩：

    1 2 3

------------------------------------------------------------------------

# 四、返回迭代器的意义

为什么：

``` cpp
unique()
```

返回 iterator？

因为它告诉我们：

> 新序列结束的位置。

例如：

``` cpp
auto it =
    unique(a.begin(), a.end());
```

那么：

有效范围：

``` cpp
[a.begin(), it)
```

无效范围：

``` cpp
[it, a.end())
```

这与：

``` cpp
lower_bound()
```

返回位置的思想类似：

都是：

> 返回边界。

------------------------------------------------------------------------

# 五、remove / remove_if

## remove

API：

``` cpp
template<class ForwardIt, class T>
ForwardIt remove(
    ForwardIt first,
    ForwardIt last,
    const T& value
);
```

返回：

``` cpp
iterator
```

作用：

删除所有等于 `value` 的元素。

但是：

**同样不会改变容器大小。**

------------------------------------------------------------------------

例如：

``` cpp
vector<int> a = {
    1,2,3,2,4
};

auto it =
    remove(
        a.begin(),
        a.end(),
        2
    );
```

逻辑结果：

    1 3 4

但是：

``` cpp
a.size()
```

仍然：

    5

真正删除：

``` cpp
a.erase(
    remove(
        a.begin(),
        a.end(),
        2
    ),
    a.end()
);
```

------------------------------------------------------------------------

## remove_if

API：

``` cpp
template<class ForwardIt, class UnaryPredicate>
ForwardIt remove_if(
    ForwardIt first,
    ForwardIt last,
    UnaryPredicate pred
);
```

根据条件删除。

例如删除偶数：

``` cpp
a.erase(
    remove_if(
        a.begin(),
        a.end(),
        [](int x){
            return x % 2 == 0;
        }
    ),
    a.end()
);
```

------------------------------------------------------------------------

# 六、为什么 STL 不直接删除？

这是 STL 的重要设计思想。

algorithm 不知道具体容器。

例如：

``` cpp
remove(
    begin,
    end,
    x
);
```

它只看到：

    一段迭代器范围

可能来自：

-   `vector`
-   `array`
-   `deque`
-   其他提供迭代器的结构

它没有权限：

-   调整 `size()`；
-   改变容量；
-   删除节点。

因此：

algorithm：

> 负责调整元素排列。

container：

> 负责管理内存和大小。

------------------------------------------------------------------------

| 操作       | 是否改变容器大小 | 返回                |
| ---------- | ---------------- | ------------------- |
| `unique()` | ❌                | 新逻辑结尾 iterator |
| `remove()` | ❌                | 新逻辑结尾 iterator |
| `erase()`  | ✅                | 删除后的 iterator   |
| `sort()`   | ❌                | `void`              |

------------------------------------------------------------------------

# 七、经典应用：离散化

离散化是竞赛中非常高频的技巧。

例如：

    100 500 100 300

需要映射：

    100 -> 1
    300 -> 2
    500 -> 3

步骤：

``` cpp
sort(a.begin(), a.end());

a.erase(
    unique(a.begin(), a.end()),
    a.end()
);
```

得到：

    100 300 500

之后：

``` cpp
lower_bound()
```

找到编号。

完整流程：

    排序
     ↓
    去重
     ↓
    二分定位

这也是之前二分章节的直接应用。

# 九、本节核心总结

## unique

> 删除相邻重复元素，返回新结束位置，不改变 `size()`。

## erase + unique

> 真正删除重复元素。

模板：

``` cpp
v.erase(
    unique(v.begin(), v.end()),
    v.end()
);
```

------------------------------------------------------------------------

## remove + erase

> 删除满足条件的元素。

模板：

``` cpp
v.erase(
    remove(v.begin(), v.end(), x),
    v.end()
);
```

------------------------------------------------------------------------

## 思维

STL algorithm 与 container 分工：

    algorithm
        ↓
    修改元素排列
    
    container
        ↓
    管理大小和内存

因此很多算法：

-   返回 iterator；
-   不直接改变容器。
