# 06 · reverse / rotate 与区间变换

这一节介绍 STL 中两个常用的区间重排算法。

和前面的：

| 算法       | 作用         |
| ---------- | ------------ |
| `sort()`   | 改变元素顺序 |
| `unique()` | 压缩有效元素 |

不同：

> `reverse()` 和 `rotate()`
> 不关心元素大小关系，只改变元素在区间中的位置。

核心：

> 通过迭代器范围，对已有序列进行结构变换。

------------------------------------------------------------------------

# 一、reverse

## API

``` cpp
template<class BidirectionalIt>
void reverse(
    BidirectionalIt first,
    BidirectionalIt last
);
```

返回类型：

``` cpp
void
```

作用：

> 将区间内元素顺序反转。

------------------------------------------------------------------------

例如：

``` cpp
vector<int> a = {
    1,2,3,4,5
};

reverse(
    a.begin(),
    a.end()
);
```

结果：

``` text
5 4 3 2 1
```

------------------------------------------------------------------------

## reverse 的本质

手写：

``` cpp
int l = 0;
int r = n - 1;

while (l < r) {
    swap(a[l], a[r]);
    l++;
    r--;
}
```

本质：

> 双指针交换。

因此：

`reverse()` 是 STL 对这一常见操作的封装。

------------------------------------------------------------------------

# 二、reverse 的常见应用

## 1. 字符串翻转

``` cpp
string s = "abc";

reverse(
    s.begin(),
    s.end()
);
```

结果：

``` text
cba
```

------------------------------------------------------------------------

## 2. 降序模拟

例如：

升序：

``` text
1 2 3 4 5
```

反转：

``` text
5 4 3 2 1
```

简单情况下可以替代：

``` cpp
sort(
    a.begin(),
    a.end(),
    greater<int>()
);
```

但是：

-   `reverse` 只适用于已有顺序相反的情况；
-   `sort` 才负责建立排序关系。

------------------------------------------------------------------------

# 三、rotate

`rotate()` 是稍微更有思想的算法。

作用：

> 将区间循环左移，使某个位置成为新的起点。

------------------------------------------------------------------------

## API

``` cpp
template<class ForwardIt>
void rotate(
    ForwardIt first,
    ForwardIt middle,
    ForwardIt last
);
```

参数：

  参数       含义
---------- ----------
  `first`    区间起点
  `middle`   新的起点
  `last`     区间终点

------------------------------------------------------------------------

例如：

``` cpp
vector<int> a = {
    1,2,3,4,5
};

rotate(
    a.begin(),
    a.begin()+2,
    a.end()
);
```

原：

``` text
1 2 3 4 5
```

以：

``` text
    ↑
  middle
```

为新的开始。

结果：

``` text
3 4 5 1 2
```

------------------------------------------------------------------------

# 四、rotate 的思想

假设区间：

``` text
A B
```

其中：

``` text
A = [first, middle)

B = [middle, last)
```

rotate：

就是：

``` text
A B

↓

B A
```

例如：

``` text
1 2 | 3 4 5

↓

3 4 5 | 1 2
```

------------------------------------------------------------------------

# 五、rotate 的常见应用

## 1. 循环移动数组

左移 k 位：

``` cpp
rotate(
    a.begin(),
    a.begin()+k,
    a.end()
);
```

例如：

``` text
1 2 3 4 5

左移2：

3 4 5 1 2
```

------------------------------------------------------------------------

## 2. 状态转换

某些构造问题中：

需要把某个位置作为新的起点。

例如：

``` text
1 2 3 4

↓

3 4 1 2
```

可以：

``` cpp
rotate(
    a.begin(),
    a.begin()+2,
    a.end()
);
```

------------------------------------------------------------------------

# 六、reverse 与 rotate 区别

| 算法      | 作用     | 是否改变相对方向 |
| --------- | -------- | ---------------- |
| `reverse` | 整体反转 | 改变             |
| `rotate`  | 循环移动 | 保持             |

例如：

原：

``` text
1 2 3 4 5
```

reverse：

``` text
5 4 3 2 1
```

rotate：

``` text
3 4 5 1 2
```

------------------------------------------------------------------------

# 七、复杂度

## reverse

每个元素最多交换一次：

$O(n)$

------------------------------------------------------------------------

## rotate

移动所有元素：

$O(n)$

空间：

$O(1)$

------------------------------------------------------------------------

# 八、本节总结

| 算法      | 作用             | 返回   |
| --------- | ---------------- | ------ |
| `reverse` | 反转区间元素     | `void` |
| `rotate`  | 循环移动区间元素 | `void` |

核心：

> STL 区间算法不仅可以查询数据，也可以直接改变元素排列。

其中：

-   `reverse`：整体翻转；
-   `rotate`：改变起点，实现循环移动。

------------------------------------------------------------------------

本节属于工具型算法：

不强行找题。

重点掌握：

``` cpp
reverse(begin, end);

rotate(begin, middle, end);
```
