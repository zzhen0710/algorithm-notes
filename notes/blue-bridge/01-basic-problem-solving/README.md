# 第一章 基础问题求解能力

这一章用于建立算法竞赛中最基础的问题分析、复杂度判断和代码实现能力。

重点不是学习复杂算法，而是形成看到题目后进行以下判断的能力：

> 数据范围 → 暴力方案 → 复杂度 → 可利用性质 → 合适算法

## 索引

### [1.1 复杂度分析](01-complexity-analysis.md) ★★★★★

根据数据范围判断允许的算法复杂度，并正确分析程序的实际总操作量。

### [1.2 枚举](02-enumeration.md) ★★★★★

通过自由变量、边界和数学约束设计候选解空间，并利用约束降维、缩小枚举范围。

### [1.3 模拟](03-simulation.md) ★★★★★

通过最小状态、更新顺序、边界处理与规则建模实现模拟，
并学习查表、周期跳跃、状态归一化和答案结构构造等优化思想。

### [1.4 STL 与竞赛常用 C++ 工具](04-stl/README.md) ★★★★★

掌握竞赛常用 STL 容器、工具类型与标准算法，
理解其接口、复杂度、迭代器特性和适用场景，
并通过代表题训练数据结构选型与算法实现能力。
