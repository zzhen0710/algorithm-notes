# 5.14 本章总结与选型

覆盖 5.1–5.13。**用于回查模型、读写与成本；完整推导和代码留在原文。** 建模主线仍是[找到状态 → 推导转移 → 写成代码](../../patterns/05-dynamic-programming/dp-modeling-workflow.md)。

## 1. 先看状态需要保留什么

| 模型与入口 | 状态重点 | 常用时间／DP 空间 |
| --- | --- | --- |
| [一维位置](01-dp-basics.md) | 到达哪里，以及影响后续的必要条件 | 固定少量前驱时 O(n)／O(n) |
| [LIS](04-sequence-dp-lis.md) | 以当前位置结尾；二分版改记同长度的最小末尾 | O(n²) 或 O(n log(n+1))／O(n) |
| [双序列](05-two-sequence-dp-lcs.md) | 两个前缀分别处理多长 | O(nm)／整表 O(nm)，两行 O(m) |
| [区间](06-interval-dp.md) | 连续范围 l、r，以及内部最优或到达它的累计值 | 枚举切分 O(n³)，常数来源收缩 O(n²)／O(n²) |
| [树形](07-tree-dp.md) | 当前子树，必要时保留根节点选／不选 | 本章常数状态模型 O(n)／O(n) |
| [集合状压](08-subset-dp.md) | 已选集合＋必要的末尾，不能只看选了几个 | O(n²·2ⁿ)／O(n·2ⁿ) |
| [数位](09-digit-dp.md) | 位置、题目条件、上界限制，必要时区分是否开始 | 条件规模 S、位数 D：约 O(10DS)／O(DS+D) |

同一完整状态下，后续规则必须相同，才能合并历史。**求最值比较全部合法来源；计数累加不同来源。** 这不是只试一个来源的贪心。

数位 Classy 原版保留随位数增长的 cnt，时间 O(10D²)；模板在 cnt 超过 3 时剪枝，状态只有 4 种，成本不同。集合表中的 n 是**实际编码对象数**，P1433 把原点也编码时要多算一位。

## 2. 背包：先问使用次数，再问容量语义

C 为容量；n 为物品数/种数，B 为有效数量拆出的总包数，G 为组数，M 为全部组的候选总数。

| 模型与入口 | 约束与读取来源 | 时间／压缩后空间 |
| --- | --- | --- |
| [0/1](02-zero-one-knapsack.md) | 本件最多一次，读上一物品阶段；容量倒序 | 通常 O(nC)／O(C) |
| [完全](03-complete-knapsack.md) | 本种可重复，允许读本层新值；容量正序 | 通常 O(nC)／O(C) |
| [多重二进制](10-bounded-knapsack.md) | 数量有限，拆包后做 0/1 | O(n+(C+1)(B+1))／O(C) |
| [多重队列](11-monotonic-queue-dp.md) | 同余分组、固定分数，候选全来自旧行 | 通常 O(nC)／O(C)，含 old 与队列 |
| [分组](12-group-knapsack.md) | 整组互斥，全部候选读取上一组 | O((C+1)(G+M+1))／O(C) |
| [两种费用 0/1](13-two-cost-knapsack.md) | 两项资源分别受限，本件一次，两容量倒序 | O((n+1)(C1+1)(C2+1))／O((C1+1)(C2+1)) |

常用 O(nC) 简写之外，仍有初始化与逐项处理；容量为 0、空输入等完整契约见原文。分组的 M 已是总候选数，不再乘一次组大小；非空组时 G≤M，通常简写 O(CM)。

- **不超过容量、允许空方案：** 每个上限下收益 0 都合法，直接查 `dp[C]`，不必用满。
- **恰好占用：** 只初始化真实起点，其余用不可达哨兵。
- **至少达到：** 状态仍可定义为恰好总量，但要比较达标终态，并[证明枚举上界](../../patterns/05-dynamic-programming/optimality-state-bound.md)。

**组号是阶段，不是第二种资源；每组恰好选一，不等于容量恰好用满。** 最大选中数量可令收益为 1，仍取 max；[统计选法数量](13-two-cost-knapsack.md#对照统计合法选法数量)则需计数状态与初值。

## 3. 六组最容易混用的细节

| 检查项 | 必须区分 |
| --- | --- |
| LIS 逐位置与整体 | `p+1` 是当前元素结尾长度，`tail.size()` 是当前前缀最优；tail 不是实际 LIS。P1091 的整体状态写法有[额外论证](04-sequence-dp-lis.md#补充直接记录-tailsize-在本题能否成立) |
| 不可达、零值、未计算 | 路径最大值可能需要 −INF；允许空选的背包可全零；计数缓存的合法 0 不能充当“未算”。见[不可达与零](11-monotonic-queue-dp.md#不可达不是累计为-0) |
| 空间压缩 | 先问读取旧层还是新层。LCS／编辑距离两行交换后答案在 prev，下一行边界重设；见[滚动数组](05-two-sequence-dp-lcs.md#6-滚动数组只保留上一行与当前行) |
| 分组零费用 | 正费用倒序可直接更新；零费用可能读到本格新值，需 best 暂存或 old。P1757 的[费用／组号边界](12-group-knapsack.md#洛谷-p1757通天之分组背包)仍保留待确认 |
| 依赖方向 | 合并依赖短区间，len 递增；到达收缩区间依赖大区间，len 递减；子树依赖孩子，逆 order，不能倒着枚举节点编号替代 |
| 集合与数位 | mask 数值不是集合大小，恰选 m 项看 popcount；数位的前导零是否影响条件、整数 0 是否计入、tight 如何传递，都要按题判断 |

CF580D 的“加分为 0”不等于缺边；dp 为 −INF 才表示状态不存在。P1122 要求非空，全负时答案仍为负，不能与允许空选的独立集初始化混用。

两种费用 0/1 中，即使本件两项费用都为 0，每格仍只处理本件一次；它与“同组多个候选互斥”的读写问题不同。

## 4. 优化要对准瓶颈

| 重复工作或存储 | 已有优化 | 必须证明／回顾入口 |
| --- | --- | --- |
| 不同历史反复求同一后续问题 | 记忆化 | [完整缓存键与精确结果](../../patterns/05-dynamic-programming/memoization-vs-tabulation.md)；预分配整表仍占内存 |
| 保存以后不再使用的层 | 滚动／原地覆盖 | [每次读取的层次](../../patterns/05-dynamic-programming/dp-modeling-workflow.md#空间压缩先标清每次读取属于哪一层)，不自动减少时间 |
| LIS 每格枚举全部前驱 | 最小末尾＋二分 | [同长度较小末尾不限制后续](04-sequence-dp-lis.md#8-二分优化同长度只保留最小结尾) |
| 相同物品重复处理 | 二进制拆包 | [数量不漏、不超](10-bounded-knapsack.md#4-13-件怎样拆为什么所有件数都能选到)；表示可能重复，不能直接用于计数 |
| 相邻窗口重扫相同候选 | 单调队列 | [移项固定分数、按余数分组、窗口单调](11-monotonic-queue-dp.md) |

**状态压缩与空间压缩也不同：** 集合编码没有消除指数多个集合；数位 DP 合并的是未来相同的前缀，不能省略未来仍需要的条件。

| 窗口 DP | 合法前驱 | 本轮顺序 |
| --- | --- | --- |
| P1725 | i−R..i−L | 补入已算好且刚合法的 i−L，再算 dp[i] |
| P2627 | i−K−1..i−1 | 旧来源已在队列，先算 dp[i]，再入队供后续使用 |

不要背固定入队顺序：**来源须已算好、可达且现在合法。** 完整图和实现见[两题对照](11-monotonic-queue-dp.md#两题对照候选算好不等于已经可以入队)。

## 5. 写法成本与现成多解，按需回看

规则循环用短递推；条件选择复杂时比较[记忆化与数组递推](../../patterns/05-dynamic-programming/memoization-vs-tabulation.md)；树很深则用显式 order 避免深递归。多重背包[二进制版代码短，队列版转移少](../../templates/05-dynamic-programming/bounded-knapsack/README.md)，按规模选择。

CF580D 若后续不再依赖具体起点，可[一张表初始化全部单点](08-subset-dp.md#推荐改进一次初始化所有起点不重复运行-n-次)，省去外层重复求解。复用[已有模板](../../templates/05-dynamic-programming/README.md)前，仍需核对题意、初值与返回值。

**先估状态数，再乘转移成本。** 集合 n=18 的 ll 数值表约 36 MiB，另计容器；两资源看容量乘积；P1725 原实现还扫描岸外 R 个位置。一维表未必线性，树形 DP 也未必 O(n)。

只求最优值不等于恢复方案；允许替换的编辑距离不能直接用 n+m−2LCS；改成计数时需重审循环与去重。

## 6. 回顾时只问五件事

**状态完整吗？初值真的可达吗？转移覆盖全部合法选择吗？读取的是所需层吗？答案与时空范围对吗？**

已有十三节的总结到此收束。背包计数进一步应用、带权区间、树上背包/换根、其他状压/数位与优化继续按题补充；P1757 边界、旧题修正、平台记录和个人掌握分别维护。
