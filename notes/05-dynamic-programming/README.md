# 第五章 动态规划

根据目标与约束定义状态，说明保留的信息为何足够，再推导初值、转移与计算顺序。

**DP 三步主线：找到状态 → 推导转移 → 把数学关系写成代码。** 初值、计算顺序与答案位置随状态和转移一起落实，完整方法见[通用范式：DP 三步走](../../patterns/05-dynamic-programming/dp-modeling-workflow.md)。

## 学习衔接

承接 [DFS 与回溯](../03-search/01-dfs-backtracking.md)、[贪心与交换论证](../04-greedy-and-construction/01-sorting-greedy.md)，理解保存子问题结果与直接确定局部选择的区别。

基础轮先建立状态、转移、顺序和可达性认识，再结合一维、路径与背包模型练习；不要求一轮完成动态规划整章，也不建立万能 DP 模板。

基础轮由本章背包模型衔接[并查集](../09-data-structures/01-dsu.md)和常用图算法；当前在[记忆化搜索](../03-search/03-memoized-search.md)后，通过[5.4 序列 DP](04-sequence-dp-lis.md)练习固定结尾、依赖顺序和答案位置，再通过[5.5 双序列 DP](05-two-sequence-dp-lcs.md)认识两个前缀状态与滚动数组，再通过[5.6 区间 DP](06-interval-dp.md)对照最后操作拆分、区间收缩的到达状态与两种长度顺序。结合[6.7 DFS 序](../06-graph-and-tree/07-dfs-order.md)与[6.8 LCA](../06-graph-and-tree/08-lca-binary-lifting.md)的父子依赖认识，接入[5.7 树形 DP](07-tree-dp.md)，学习孩子先算的方向。其余模型继续分轮补充，不以本地核验代替熟练掌握。
