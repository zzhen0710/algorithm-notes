# 1.5 位运算

**其他解与选型：** [CF 467B 的差异位计数写法比较](06-summary-selection.md#2-同题比较cf-467b)，见本章总结。

## 1. 解决什么问题

位运算直接处理整数的二进制位，常用于表示一组开关、维护小集合、统计二进制信息，以及利用异或消去成对贡献。

> **先确定每一位代表什么，再选择对应的操作。**

状态可以用一个整数表示，但这只是存储方式变紧凑，**状态总数并不会因此减少**。

本节使用 C++11，主要处理非负整数。掩码统一使用无符号类型，避免把符号位和数值运算混在一起。

```cpp
#include <iostream>
#include <vector>
#include <limits>

using namespace std;

// 常见竞赛环境中为 64 位，标准保证至少 64 位。
using ull = unsigned long long;

// 查询这个类型实际能使用多少个二进制位。
constexpr int W = numeric_limits<ull>::digits;
```

## 2. 二进制与基本操作

**最右侧是最低位，编号从 0 开始。**

从右向左，第 `0、1、2…` 位的权值分别为 `1、2、4…`。

例如 `13` 的二进制为 `1101`，即 `8+4+1`。

| 操作 | 含义 | 作用 |
| --- | --- | --- |
| `a & b` | 按位与 | 两位都为 `1` 才为 `1` |
| `a ^ b` | 按位异或 | 两位不同为 `1`，相同为 `0` |
| `~a` | 按位取反 | 类型位宽内的所有位翻转 |
| `a << k` | 左移 | 低位补 `0`，超出位宽的高位丢弃 |
| `a >> k` | 右移 | 本节无符号类型高位补 `0` |

**按位或**写作 `a | b`：对应两位中，至少一位为 `1`，结果就为 `1`。

```cpp
ull a = 13, b = 10; // 低四位：a=1101，b=1010

// 只保留两者都为 1 的位：1000。
ull both = a & b; // 8

// 只要其中一个数在该位为 1，就保留：1111。
ull either = a | b; // 15

// 找出不同的位，相同的位变成 0：0111。
ull diff = a ^ b; // 7

ull left = a << 1;  // 1101 -> 11010，即 26；本例没有丢失高位
ull right = a >> 1; // 1101 -> 0110，即 6

// 非负整数的最低位为 1，表示它是奇数。
bool odd = (a & 1) != 0;
```

对于无符号数：

- **左移 `k` 位**：相当于乘 `2^k`，但超出位宽的高位会丢弃，不能无条件当作数学上的乘法。
- **右移 `k` 位**：相当于除以 `2^k`，向下取整。

左移丢弃高位，也可以理解为乘法结果按该类型的范围取模。

> **移位数必须满足 `0 <= k < W`，即使使用无符号类型，也不能移位 `W` 位。**

规则参考：[C++ 移位规则](https://eel.is/c++draft/expr.shift)、[无符号整数规则](https://eel.is/c++draft/basic.fundamental)。

## 3. 单个位的查询与修改

先构造一个**只在第 `i` 位为 `1`** 的数，作为操作目标位的标记。

```cpp
ull mask = 13; // 1101
int i = 1;    // 前提：0 <= i < W

// 先把 1 写成 ull 类型，再左移，得到 0010。
ull bit = ull{1} << i;

// 按位与只留下目标位；结果非零，表示该位原本为 1。
bool has = (mask & bit) != 0; // 本例为 false

// 与 1 做或运算，目标位一定变成 1，其他位不变。
mask |= bit; // 1101 -> 1111；重复执行仍为 1

// ~bit 的目标位为 0、其他位为 1，因此只清除目标位。
mask &= ~bit; // 1111 -> 1101；重复执行仍为 0

// 与 1 异或会翻转目标位，与 0 异或保持其他位不变。
mask ^= bit; // 1101 -> 1111；再次执行会翻回 0
```

> `mask & bit` 的结果是 `0` 或 `bit`，**不一定是数值 `0` 或 `1`**。

若需要直接取得第 `i` 位的数值，可写 `(mask >> i) & 1`。

判断该位为零应写 `(mask & bit) == 0`。

不要写 `mask & bit == 0`：它会先计算 `bit == 0`，再与 `mask` 做按位与，含义已经不同。

## 4. 位掩码：用整数表示小集合

约定元素编号为 `0..n-1`，第 `i` 位为 `1` 表示选择元素 `i`。

- **空集合**：`0`。
- **全集**：低 `n` 位全为 `1`，写作 `(ull{1} << n) - 1`，要求 `0 <= n < W`。

| 集合操作 | 位运算 |
| --- | --- |
| 交集 | `A & B` |
| 恰好属于其中一个集合 | `A ^ B` |
| 判断 `A` 是 `B` 的子集 | `(A & B) == A` |
| 在给定全集 `full` 内取补集 | `full & ~A` |

**并集**写作 `A | B`：属于任意一个集合的元素，都出现在结果中。

> **小集合的补集必须限制在给定全集内。** `~A` 会翻转整个类型位宽，不只是前 `n` 位。

需要整个类型全部位为 `1` 时，可以使用 `~ull{0}`，不能通过左移 `W` 位构造。

```cpp
int n = 4; // 全集为编号 0..3，保证 n < W

// 1 左移四位得到 10000，减 1 得到低四位全为 1 的 1111。
ull full = (ull{1} << n) - 1;

ull A = 5, B = 6; // A=0101，即 {0,2}；B=0110，即 {1,2}

ull common = A & B; // 0100，即 {2}
ull joined = A | B; // 0111，即 {0,1,2}

// 先取反，再用 full 去掉全集之外的位。
ull complement = full & ~A; // 1010，即 {1,3}

// 如果 A 中的每个元素都属于 B，交集就应等于 A。
bool subset = (A & B) == A; // false，元素 0 不属于 B
```

### 枚举全部选择

`n` 个二元选择对应 `2^n` 个掩码。以下演示枚举每个子集的元素和，不依赖某一道练习题。

```cpp
vector<int> a = {2, 4, 7};
// 用二进制位表示选择状态：第 i 位对应 a[i]。

int n = static_cast<int>(a.size());
// 子集枚举要求 n 较小，且 n < W；示例总和不会溢出 long long。

ull total = ull{1} << n;
// 总状态数为 2^n，不是最大 mask。
// 例如 n=3，mask 范围为 0~7。

for (ull mask = 0; mask < total; ++mask) {
    // 枚举所有子集状态，mask=0 表示空集合。
    long long sum = 0;

    for (int i = 0; i < n; ++i) {
        // mask 第 i 位为 1，表示选择 a[i]。
        if (mask & (ull{1} << i)) {
            sum += a[i];
        }
    }

    cout << sum << '\n';
}
```

总时间为 **`O(n × 2^n)`**，辅助空间 `O(1)`，不计输入。

`n≈20` 时仍需估算实际操作量；即使 `n=40` 的状态能存进整数，也不表示能枚举完。

已整理的 [CF 1494B](../../problems/CF1494B_Berland_Crossword.md)使用四位表示角落选择。关键是只枚举少量共享变量，再检查剩余部分，见 [少量耦合变量枚举](../../patterns/small-coupling-enumeration.md)。

> 位掩码只是状态表示，**不能单凭这种表示证明判定或贪心正确**。

## 5. 异或：抵消与差异

异或满足交换律、结合律，以及两个基本性质：

- `x ^ x = 0`：相同的数抵消。
- `x ^ 0 = x`：与 `0` 异或保持原值。

因此，同一个数出现偶数次，其贡献会抵消；出现奇数次则保留一次贡献。

> **只有一个数出现奇数次、其余数均出现偶数次时，全部异或的结果就是该数。**

若有多个数出现奇数次，结果只是这些数的异或，不能据此恢复每个数。异或也不能当作求和使用。

两个掩码异或后，第 `i` 位为 `1`，表示两者在这一位不同。

结果是**差异掩码，不是不同位的数量**。若需要数量，还要统计结果中有多少个 `1`。

## 6. 清除最低位的 1 与计数

> 对 `x>0`，`x-1` 会把最低位的 `1` 变为 `0`，并把它右侧的 `0` 变为 `1`。
>
> 两者再按位与，**恰好清除最低位的一个 `1`**。

```text
x       = 1100
x - 1   = 1011
x&(x-1) = 1000
```

重复这个过程，每次清除一个 `1`，直到归零；执行次数就是原数中 `1` 的数量。

```cpp
int countBits(ull x) { // x=0 时不进入循环，返回 0
    int cnt = 0;

    while (x) {
        x &= x - 1; // 清除最低位的一个 1
        ++cnt;      // 记录已经清除了多少个 1
    }

    return cnt;
}
```

循环次数等于 `1` 的数量，也称 `popcount(x)`。最坏时间 `O(W)`，辅助空间 `O(1)`。

固定机器位宽下 `W` 是常数；分析与二进制位数有关的工作量时，保留 `W` 更清楚。

### GCC 内建函数：`__builtin_popcount`

`popcount` 是 population count，可理解为**置 1 位计数**。`__builtin_popcount(x)` 直接返回整数 `x` 的二进制中有多少个 `1`。

它由 GCC 编译器提供，不需要自行定义，也不是 `bitset` 的成员函数。

| 函数 | 参数类型 | 返回类型 |
| --- | --- | --- |
| `__builtin_popcount(x)` | `unsigned int` | `int` |
| `__builtin_popcountll(x)` | `unsigned long long` | `int` |

```cpp
unsigned int a = 13; // 二进制为 1101
int cnt = __builtin_popcount(a); // 3；输入为 0 时返回 0

// 构造第 40、1、0 位为 1 的数。
ull x = (ull{1} << 40) | 3;
int wideCnt = __builtin_popcountll(x); // 3，使用匹配 ull 的版本
```

> **函数版本要与参数类型匹配。** 将较宽的整数传给 `__builtin_popcount`，会先转成 `unsigned int`，可能丢失高位。

三种写法统计的是同一种信息：

- **`bitset<N>::count()`**：操作位集合对象，属于标准库，返回 `size_t`。
- **`__builtin_popcount` / `__builtin_popcountll`**：直接操作整数，属于 GCC 扩展，返回 `int`。
- **手写 `x &= x-1` 循环**：自行实现计数，便于理解清除最低位 `1` 的原理。

GCC 内建函数不属于 C++11 标准接口，不能假定所有编译器都支持；具体是否使用硬件指令取决于编译目标与优化，不能仅凭名字断言比 `bitset::count()` 更快。接口参考：[GCC 文档](https://gcc.gnu.org/onlinedocs/gcc/Bit-Operation-Builtins.html)。

## 7. lowbit 与 2 的幂

`lowbit(x)` 保留最低位的一个 `1`，其余清零。

> 返回的是这一位的**权值，不是下标**。例如 `lowbit(12)=4`，对应下标为 `2`。

对于无符号类型，`0-x` 按类型范围取模，相当于对 `x` 逐位取反后加一：

- 最低位的 `1` 及其右侧的 `0` 保持不变。
- 更高位与原数相反，按位与后全部变成 `0`。

于是与原数按位与，就只剩最低位的一个 `1`。

这里使用**无符号减法模拟 `-x`**。有符号整数的最小值无法表示其相反数，直接取负可能溢出；无符号计算可以避开这一特殊情况。

```cpp
ull lowbit(ull x) {
    // 取反加一后，最低位的 1 及其右侧 0 保持不变。
    // 更高位与原数相反，按位与后只留下最低位的 1。
    // x=0 时结果也为 0。
    return x & (ull{0} - x);
}

bool isPowerOfTwo(ull x) {
    // 正整数是 2 的幂，当且仅当二进制中只有一个 1。
    // 清除这个 1 后应为 0；还需单独排除 x=0。
    return x != 0 && (x & (x - 1)) == 0;
}
```

两者均为 `O(1)` 时间、`O(1)` 空间。

`lowbit` 常用于逐个取出二进制贡献，后续树状数组也会用到。本节先掌握其含义，不提前展开数据结构实现。

## 8. 易错边界与选型

| 情况 | 检查点 |
| --- | --- |
| `1 << i` 写完再赋给长整数 | 赋值不会改变前面移位表达式的类型，应先使用 `ull{1}` |
| 移位次数为负或达到类型位宽 | 超出合法范围；无符号类型也不能免除此限制 |
| 用 `^` 表示乘方 | C++ 中 `^` 是异或，`2^k` 不表示幂 |
| 把取反当作低几位补集 | 用 `full & ~mask` 限制全集 |
| 负数直接套用位运算直觉 | 先明确数值范围与类型，不把有符号移位当作通用除法 |
| 只检查 `x & (x-1)` | 判断 2 的幂时还要排除 `x=0` |
| 状态数可以表示 | 还要核算 `2^n × 单状态处理量`，不等于可以枚举 |

> **按位操作与逻辑操作不同：**
>
> `&`、`|`、`~` 操作各个位；`&&`、`||`、`!` 判断真假。

少量二元状态可用整数掩码；固定长度的批量位集合可参考 [bitset](04-stl/containers/17-bitset.md)。

按位运算提供表示和操作，真正的算法仍由问题的约束决定。

### 9.1 CF 579A：从变化过程到最终贡献

培养盒初始为空，每天早晨可以加入细菌，夜晚数量翻倍。要求某个时刻恰好有 `x` 个细菌，求最少加入数量。范围：`1 <= x <= 10^9`。

**我的思路：** 用 `bitset<32>` 表示 `x`，通过 `count()` 统计二进制中 `1` 的数量。

#### 为什么成立

一个细菌经过 `k` 次分裂，最终贡献 `2^k` 个细菌。因此，问题可以转化为：

> **用尽可能少的 2 的幂相加，得到 `x`。**

若有两个相同的幂，可以合并为更大的一个幂：`2^k + 2^k = 2^(k+1)`。总数不变，项数减少；不断合并后，得到标准二进制表示。

所以任意方案的项数，都不会少于二进制中 `1` 的数量。按这些不同幂次安排加入时间，又能实现这个数量，故下界可以取到。

例如 `13 = 8+4+1`，二进制为 `1101`，最少加入 `3` 个细菌。

#### 我的实现

```cpp
#include <bits/stdc++.h>

using namespace std;

using ll = long long;
using pii = pair<int, int>;
using pll = pair<ll, ll>;

void solve() {
    int x;
    cin >> x;

    // 每个为 1 的位，对应最终数量中的一个 2 的幂。
    bitset<32> b(x);

    // 统计所需贡献的数量，也就是最少加入数量。
    cout << b.count();
}

int main() {
#ifdef LOCAL
    freopen("input.txt", "r", stdin);
#endif

    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T = 1;
    // cin >> T;

    while (T--) {
        solve();
    }

    return 0;
}
```

`x <= 10^9`，32 位足够。固定 `bitset<32>` 下，时间与额外空间均为 `O(1)`。

#### 手写练习：每次清除一个 1

`x &= x-1` 每次清除最低位的一个 `1`。从原数到 `0` 一共执行几次，原数就有几个 `1`。

```text
13：1101
    1100  -> 清除第一个 1
    1000  -> 清除第二个 1
    0000  -> 清除第三个 1
```

```cpp
void solve() {
    unsigned x;
    cin >> x;

    int cnt = 0;

    while (x) {
        x &= x - 1; // 清除最低位的一个 1
        ++cnt;      // 累计清除了多少个 1
    }

    cout << cnt << '\n';
}
```

循环执行 `popcount(x)` 次，按输入的有效二进制位数分析，最坏为 `O(log x)`，额外空间 `O(1)`。`x=0` 时循环不执行，计数为 `0`；原题输入为正数。

> **手写版用于练习原理，不代表比原方案更优。** `bitset::count()` 和内建函数也可以完成相同统计，实际速度还受编译器与目标平台影响。

原方案已经合适，完善重点是补齐最优性依据。手写版会修改 `x`，后面还需原值时应先复制。

**如何想到：** 不逐天模拟，先观察一次加入对最终数量的贡献，再寻找最少项数。相关展开见 [bitset 代表题](04-stl/containers/17-bitset.md#41-从生长过程到二进制表示)。

### 9.2 CF 467B：把差异关系转成异或

每个玩家用一个整数表示兵种集合，第 `i` 位表示是否拥有第 `i` 种兵种。最后一个玩家是 Fedor，统计与他的兵种差异不超过 `k` 种的玩家数量。

范围：`1 <= k <= n <= 20`，`m <= 1000`，`1 <= x[i] < 2^n`。

**我的思路：** 保存 Fedor 的 `bitset`，依次与其他玩家异或，再用 `count()` 统计差异数量。

#### 为什么成立

两位相同，异或结果为 `0`；两位不同，结果为 `1`。因此，异或结果中的每个 `1`，与一种不同的兵种一一对应。

> **异或标出差异位置，`count()` 统计差异数量，再判断是否不超过 `k`。**

本题只有低 `n` 位表示兵种。使用 32 位时，更高位均为 `0`，不会增加差异数量。

#### 我的实现

```cpp
#include <bits/stdc++.h>

using namespace std;

using ll = long long;
using pii = pair<int, int>;
using pll = pair<ll, ll>;

void solve() {
    unsigned n, m, k;
    cin >> n >> m >> k;

    vector<unsigned> a(m + 1);

    for (auto& v : a) cin >> v;

    // 最后一个输入是 Fedor，先保存他的兵种状态。
    bitset<32> b(a[m]);

    int cnt = 0;

    for (int i = 0; i < m; ++i) {
        bitset<32> c(a[i]);

        // 异或标出不同兵种，再统计不同位置的数量。
        if ((b ^ c).count() <= k)
            ++cnt;
    }

    cout << cnt << '\n';
}

int main() {
#ifdef LOCAL
    freopen("input.txt", "r", stdin);
#endif

    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T = 1;
    // cin >> T;

    while (T--) {
        solve();
    }

    return 0;
}
```

固定 32 位下，总时间 `O(m)`，保存输入的空间为 `O(m)`。输入本身就有 `m+1` 个玩家状态，需要逐个读取，因此时间已经达到线性下界。

Fedor 的状态最后输入，先保存前面的玩家再比较，是自然且合适的组织方式。

#### 改进与边界

- 原算法无需更换。`i` 是 `int`，`m` 是 `unsigned`，会产生符号类型比较警告；在本题范围内不影响正确性，整理版可将循环下标改为 `unsigned i = 0`。
- 异或结果的**数值大小不等于差异数量**，不能直接拿它与 `k` 比较。
- 条件是 `<= k`，不是 `< k`；只检查前 `m` 个玩家，不把 Fedor 自己计入答案。
- 输入给的是十进制整数，应先读整数再构造 `bitset`，不能直接用 `cin >> bitset` 读取，否则读入 "111" 会按 "00...0111" 解释。

若要练习整数写法，可将某次比较的判断写成：

```cpp
// a 的元素类型为 unsigned，异或结果可交给对应的内建函数。
unsigned different = __builtin_popcount(a[i] ^ a[m]);

if (different <= k) {
    ++cnt;
}
```

这仍是同一个算法，只是省去显式构造位集合的写法；实际速度取决于编译器与目标平台。

**如何想到：** 题目比较哪些状态不同 → 每位已代表一种状态 → 异或直接标记差异 → 计数后判断阈值。
