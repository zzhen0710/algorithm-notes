# 1.4.17 `bitset`：定长位集合与二进制表示

## 1. 核心定位

`bitset<N>` 是 C++ 标准库中的**固定长度位集合**（严格来说不是标准容器），用 `N` 个二进制位记录状态，支持位访问、位运算以及快速统计置位数量。`N` 必须是**编译期常量**；下标 `0` 表示最低位，输出时最高位在左侧。

```cpp
bitset<8> b;             // 00000000
b.set(1);                // 00000010
b.set(3);                // 00001010
b.set(5);                // 00101010

cout << b << '\n';         // 00101010
cout << b.count() << '\n'; // 3
cout << b[3] << '\n';      // 1
```

**核心价值**：当一个状态天然可以用二进制表示时，把逐位判断交给 `bitset` 的位操作与 `count()`，能让实现更简洁。

## 2. 创建 `bitset`：整数、字符串与位数截断

### 2.1 直接由整数构造（高频）

```cpp
int x = 13;              // 13 = 8 + 4 + 1
bitset<8> b(x);          // 00001101

cout << b << '\n';         // 00001101
cout << b.count() << '\n'; // 3：二进制中 1 的个数
cout << b.to_ullong();     // 13
```

**位数不足时保留整数的低 `N` 位，高位被截断**：

```cpp
bitset<4> b(19);  // 19 的二进制为 10011
cout << b;        // 0011（仅保留低 4 位）
```

由整数构造时，可以理解为先取其 `unsigned long long` 数值的二进制形式，再保留低 `N` 位。对本节代表题而言，输入是非负整数，无需考虑负数转换规则。

### 2.2 从二进制字符串构造

```cpp
bitset<8> a(string("1101")); // 00001101
bitset<8> b("1101");         // 00001101
```

字符串从左到右表示二进制的高位到低位，不足 `N` 位时自动在左侧补 `0`。

**注意截断规则不同**： 字符串超过 `N` 位时，**保留左边的 `N` 位**；整数超过 `N` 位时，**保留右边的 `N` 位（低位）**。因此，建议使用长度不超过 `N` 的二进制字符串。

## 3. 常用 API、返回类型与复杂度

以下以 `bitset<N>` 为例，列出 C++11 常用接口形式，省略不常用重载。`reference` 是 `bitset<N>` 定义的位代理引用类型，**并不是 `bool&`**。令 `W` 为机器字位数，整个位集合的操作通常按机器字分块执行。

| API 签名 / 写法 | 返回类型 / 作用 | 复杂度（常见实现） |
|---|---|---|
| `explicit bitset(unsigned long long val)` | 以整数初始化低位，构造函数无返回值 | `O(N / W + 1)` |
| `explicit bitset(const string& str, size_t pos = 0, size_t n = string::npos, char zero = '0', char one = '1')` | 用字符串指定区间的二进制字符构造对象；构造函数无返回值 | `O(N)` |
| `reference operator[](size_t pos)` | 非 `const` 对象：访问、修改一位 | `O(1)` |
| `bool operator[](size_t pos) const` | `const` 对象：读取指定位置 | `O(1)` |
| `bool test(size_t pos) const` | 检查指定位置；越界抛 `out_of_range` | `O(1)` |
| `bitset& set(size_t pos, bool value = true)` | 将指定位设为 `value`，返回自身引用 | `O(1)` |
| `bitset& reset(size_t pos)` | 清除指定位，返回自身引用 | `O(1)` |
| `bitset& flip(size_t pos)` | 翻转指定位，返回自身引用 | `O(1)` |
| `bitset& set()` / `bitset& reset()` / `bitset& flip()` | 对所有位执行置位 / 清零 / 翻转 | 通常 `O(N / W + 1)` |
| `size_t count() const` | 返回置 `1` 位的数量 | 通常 `O(N / W + 1)` |
| `bool any() const` / `bool none() const` / `bool all() const` | 是否有 `1` / 全为 `0` / 全为 `1` | 通常 `O(N / W + 1)` |
| `size_t size() const` | 返回编译期确定的位数 `N` | `O(1)` |
| `string to_string() const` | 输出高位在左的二进制字符串 | `O(N)` |
| `unsigned long to_ulong() const` | 转换为无符号整数；超出范围抛 `overflow_error` | 通常 `O(N / W + 1)` |
| `unsigned long long to_ullong() const` | 转为 `unsigned long long`；超范围抛异常 | 通常 `O(N / W + 1)` |
| `bitset& operator<<=(size_t k)` / `bitset& operator>>=(size_t k)` | 整体左移 / 右移，返回自身引用 | 通常 `O(N / W + 1)` |
| `bitset operator&(const bitset& other) const` 等按位运算 | 逐位执行按位与、按位或、按位异或，返回新 `bitset` | 通常 `O(N / W + 1)` |

表中“通常”是对常见机器字实现的分析，并非标准保证的精确机器操作数；`N` 固定时可视为与输入数量无关。整数构造与全体位操作涉及初始化或处理底层存储；字符串构造及 `to_string()` 还需要处理字符。

### 3.1 读取、修改与越界

```cpp
bitset<8> b(13);  // 00001101

cout << b.test(2); // 1
b[2] = 0;         // 00001001
b.flip(0);        // 00001000
b.set(6);         // 01001000
b.reset(3);       // 01000000
```

- `test(pos)` 在下标越界时抛 `out_of_range`；`operator[]` **不执行同样的范围检查**，越界访问是未定义行为。
- `b[2]` 对非 `const bitset` 返回的是代理对象，可用于赋值；在 `const` 对象上读取时返回 `bool`。
- `bitset<N>` 的位数不能在运行时改变，不支持 `push_back()` 或 `resize()`。

### 3.2 按位与、或、异或与移位

```cpp
bitset<8> a("10110010");
bitset<8> b("11001100");

cout << (a & b) << '\n';  // 10000000：同时为 1
cout << (a | b) << '\n';  // 11111110：至少一个为 1
cout << (a ^ b) << '\n';  // 01111110：两位不相同
cout << (a << 2) << '\n'; // 11001000：左移，高位丢弃，低位补零
```

位移属于对**固定长度位模式**的操作，不是无限精度整数计算；移出的高位或低位会被丢弃。

### 3.3 `bitset` 与整数并不完全等价

```cpp
bitset<8> a(13), b(5);

// a + b; // 错误：bitset 没有普通整数加法
cout << a.to_ullong() + b.to_ullong(); // 18
```

`bitset` 适合位状态、位运算和统计，而不是替代 `int` / `long long` 进行普通算术。

## 4. 代表题：[CF 579A — Raising Bacteria](https://codeforces.com/problemset/problem/579/A)

**题型**：二进制拆分 / 2 的幂之和 / `count()` / 最优性证明。

培养盒初始为空。每天早晨可以加入细菌；夜晚每个细菌会分裂成两个。要求在某个时刻得到恰好 `x` 个细菌，求至少要**加入多少个细菌**。

### 4.1 从生长过程到二进制表示

一个细菌经过 `k` 次分裂，最终会贡献 `2^k` 个细菌。于是每次加入的细菌，都可以视作对最终数量贡献一个 **2 的非负整数次幂**。

例如 `x = 13`：

\[
13=8+4+1=2^3+2^2+2^0.
\]

也就是 `1101`（二进制），恰有三个置 `1` 位。因此可以通过恰当的加入时间，用 **3 个初始加入的细菌**达到目标。

### 4.2 为什么置 `1` 位的个数就是最小值？

假设某种方案对应若干个 `2^k` 之和。只要其中有两个相同的 `2^k`，就可以合并：

\[
2^k+2^k=2^{k+1}.
\]

这一合并在**不改变总数量**的同时，把项数减一。反复合并，最终得到没有重复幂次的标准二进制表示。由于任何表示都能这样化简，其项数不可能小于二进制表示中 `1` 的个数。

而标准二进制表示本身可以实现，所以下界可以取到，答案就是：

\[
\boxed{\operatorname{popcount}(x)}.
\]

> **动态分裂过程 → 每次加入贡献一个 2 的幂 → 最少项数 → 二进制置 `1` 位数量。**

### 4.3 C++11 实现

```cpp
void solve() {
    int x;
    cin >> x;

    bitset<32> b(x);      // 整数直接构造：得到 x 的二进制位
    cout << b.count() << '\n';
}
```

本题 `x` 为正整数且不超过 `10^9`，使用 32 位足够；`count()` 返回 `size_t`。`N=32` 为固定常量，故本题整体操作量为常数级；若用手动逐位除以 2，则复杂度为 `O(log x)`。

## 5. 与快速幂的联系：同源，但不混为一题

两者都利用**一个整数可以按二进制拆成若干个 2 的幂**：

\[
13=2^3+2^2+2^0.
\]

- **本题**：要构成数量 `13`，需要多少个 `2^k`？答案是二进制中 `1` 的个数。
- **快速幂**：利用指数的二进制拆分，将 `a^13` 改写为 `a^8 · a^4 · a`，从而只需对数次平方与乘法。

因此，快速幂与本节存在重要的思维联系，但不属于 `bitset` 本身的 API。

**在下一节位运算学习二进制拆位与移位，在后续数论 / 模运算专题正式实现快速幂和模快速幂**，避免提前掺入无关代码。

## 6. 高频错误与选型

| 易错点 | 正确认识 |
|---|---|
| `bitset<N>` 的 `N` 能由运行时变量决定 | `N` 必须是编译期常量；运行时动态位数应考虑其他表示方式 |
| 认为 `b[0]` 对应输出字符串最左侧 | `b[0]` 是最低位，打印时在**最右侧** |
| 用过窄的 `bitset<N>` 保存整数 | 整数构造只保留低 `N` 位，可能丢失高位 |
| 认为 `b[i]` 的类型是 `bool&` | 非 `const` 对象返回代理类型 `reference` |
| 认为 `b[i]` 越界会安全报错 | `test(i)` 才执行越界检查；`operator[]` 越界是未定义行为 |
| 将 `bitset` 直接当普通整数做 `+` / `-` | `bitset` 支持的是位操作；普通算术先做整数转换并注意范围 |
| `to_ulong()` / `to_ullong()` 一定可以转换 | 表示的值超出目标类型时会抛出 `overflow_error` |

**选型触发器**：

> **状态可以自然编码成固定数量的二进制位，需要高效按位操作、统计置位数量或比较状态 → 考虑 `bitset<N>`。**

当题目本质与二进制有关时，先尝试把过程转化为**位表示**，再考虑能否直接利用 `bitset` 的现成接口。
