# 08 · fill / iota / generate 与序列初始化

这一节介绍 STL 中常用的初始化类算法。

共同特点：

> 通过迭代器区间快速构造或修改序列。

主要用于：

-   初始化数组；
-   生成编号；
-   批量赋值；
-   构造状态。

------------------------------------------------------------------------

# 一、fill

## API

``` cpp
template<class ForwardIt, class T>
void fill(
    ForwardIt first,
    ForwardIt last,
    const T& value
);
```

返回：

``` cpp
void
```

作用：

> 将区间内所有元素修改为指定值。

------------------------------------------------------------------------

例如：

``` cpp
vector<int> a(5);

fill(
    a.begin(),
    a.end(),
    10
);
```

结果：

``` text
10 10 10 10 10
```

等价于：

``` cpp
for (int i = 0; i < 5; i++) {
    a[i] = 10;
}
```

------------------------------------------------------------------------

## 常见用途

初始化数组：

``` cpp
int a[100];

fill(
    a,
    a + 100,
    -1
);
```

常用于：

-   DP 初始化；
-   标记数组初始化；
-   多次测试数据清空。

------------------------------------------------------------------------

# 二、iota

`iota()` 用于生成递增序列。

## API

``` cpp
template<class ForwardIt, class T>
void iota(
    ForwardIt first,
    ForwardIt last,
    T value
);
```

返回：

``` cpp
void
```

作用：

> 从指定值开始，用递增序列填充区间。

------------------------------------------------------------------------

例如：

``` cpp
vector<int> a(5);

iota(
    a.begin(),
    a.end(),
    1
);
```

结果：

``` text
1 2 3 4 5
```

等价于：

``` cpp
int x = 1;

for (int i = 0; i < 5; i++) {
    a[i] = x++;
}
```

------------------------------------------------------------------------

# 三、iota 的经典技巧：排序下标

竞赛中经常遇到：

> 数据不能直接改变，但需要按照数据大小排序。

例如：

``` cpp
vector<int> value = {
    80, 95, 70, 90
};
```

对应：

| 下标 | 数据 |
| --- | --- |
| 0 | 80 |
| 1 | 95 |
| 2 | 70 |
| 3 | 90 |

如果直接：

``` cpp
sort(
    value.begin(),
    value.end()
);
```

结果：

``` text
70 80 90 95
```

但是原来的编号关系丢失。

------------------------------------------------------------------------

解决：

创建一个存储编号的数组。

``` cpp
vector<int> id(value.size());

// 初始化:
// id = {0,1,2,3}
iota(
    id.begin(),
    id.end(),
    0
);
```

此时：

``` text
id:

0 1 2 3
```

表示：

``` text
第0个元素
第1个元素
第2个元素
第3个元素
```

------------------------------------------------------------------------

然后排序编号：

``` cpp
sort(
    id.begin(),
    id.end(),
    [&](int a, int b) {

        // 比较两个编号对应的数据
        return value[a] < value[b];
    }
);
```

注意：

排序的是：

``` cpp
id
```

而不是：

``` cpp
value
```

排序过程：

比较：

``` cpp
value[a]
```

和：

``` cpp
value[b]
```

但交换的是：

``` cpp
a
```

和：

``` cpp
b
```

------------------------------------------------------------------------

最终：

``` text
id:

2 0 3 1
```

表示：

``` text
value[2] = 70
value[0] = 80
value[3] = 90
value[1] = 95
```

原数组：

``` text
80 95 70 90
```

没有改变。

------------------------------------------------------------------------

这个技巧常用于：

-   排名；
-   保留原编号；
-   多关键字排序；
-   对下标进行排序。

核心：

> 排序下标，而不是排序数据本身。

------------------------------------------------------------------------

# 四、generate

`generate()` 比 `fill()` 更灵活。

作用：

> 使用一个函数生成区间中的每个元素。

------------------------------------------------------------------------

## API

``` cpp
template<class ForwardIt, class Generator>
void generate(
    ForwardIt first,
    ForwardIt last,
    Generator g
);
```

返回：

``` cpp
void
```

------------------------------------------------------------------------

例如：

``` cpp
vector<int> a(5);

int x = 0;

generate(
    a.begin(),
    a.end(),
    [&]() {

        // 每调用一次生成一个值
        return x++;

    }
);
```

结果：

``` text
0 1 2 3 4
```

------------------------------------------------------------------------

与前两个区别：

| 算法       | 作用         | 特点         |
| ---------- | ------------ | ------------ |
| `fill`     | 填充相同值   | 所有元素相同 |
| `iota`     | 生成递增序列 | 连续编号     |
| `generate` | 自定义生成   | 规则自由     |

------------------------------------------------------------------------

# 五、三个算法总结

| 算法       | 作用             | 特点 |
| ---------- | ---------------- | ---- |
| `fill`     | 填充区间为指定值 | void |
| `iota`     | 生成递增序列     | void |
| `generate` | 根据函数生成元素 | void |

------------------------------------------------------------------------

# 六、注意：algorithm 与 numeric

头文件：

``` cpp
#include <algorithm>
```

包含：

-   `fill`
-   `generate`

而：

``` cpp
#include <numeric>
```

包含：

-   `iota`

竞赛中：

``` cpp
#include <bits/stdc++.h>
```

无需区分。

# 七、本节核心

重点掌握：

## fill

批量初始化：

``` cpp
fill(begin, end, value);
```

------------------------------------------------------------------------

## iota

生成编号：

``` cpp
iota(begin, end, start);
```

尤其注意：

> `iota + 下标排序` 是竞赛中非常常见的技巧。

------------------------------------------------------------------------

## generate

了解：

``` cpp
generate(begin, end, func);
```

用于自定义生成。
