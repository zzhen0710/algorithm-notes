# 2.8 归并计数

## 1. 解决什么问题

在序列中统计满足位置与大小关系的数对，例如：

$$
i<j,\qquad a_i>a_j
$$

这样的数对称为**逆序对**。逐对检查需要 $O(n^2)$；归并计数把序列分成两半，利用两半有序的性质批量统计，将时间降为 $O(n\log n)$。

> **重点不是重新学习归并排序，而是利用归并过程，把逐个判断变成整段计数。** 普通排序仍优先使用 `sort`。

本节使用 C++11、**0 下标、闭区间**，沿用[竞赛基础框架](../../templates/cpp-contest-template/README.md)中的 `using ll = long long;`，不重复通用输入输出框架。

## 2. 分治：先把数对分成三类

将当前区间 $[l,r]$ 分成 $[l,mid]$ 与 $[mid+1,r]$，任意逆序对只属于以下一类：

1. 两个位置都在左半边；
2. 两个位置都在右半边；
3. 左位置在左半边，右位置在右半边。

前两类交给较小区间递归统计；第三类在合并时统计。

$$
\mathrm{ans}(l,r)=\mathrm{ans}(l,mid)+\mathrm{ans}(mid+1,r)+\mathrm{cross}(l,r)
$$

**每次递归同时完成两件事：返回当前区间的逆序对数，并把当前区间排成非降序。** 排序是为了让上一层能够批量统计。

递归区间越来越短，只有一个元素或为空时返回 $0$。这里不是枚举所有切法，而是每次固定从中间分成两半。

## 3. 为什么一次能加上整段长度

递归结束后，两半分别有序。令 `i` 指向左半边未取出的第一项，`j` 指向右半边未取出的第一项。

- 若 `a[i] <= a[j]`，左边当前项不大于右边任何剩余项，先取左边，不产生新的逆序对。
- 若 `a[i] > a[j]`，左边剩余项都不小于 `a[i]`，因此全部大于 `a[j]`：

$$
a_i\le a_{i+1}\le\cdots\le a_{mid},\qquad a_i>a_j
$$

这个右边元素一次贡献：

$$
mid-i+1
$$

随后取出右边元素，让 `j` 右移。

> **右边当前值小于左边最小剩余值，就小于左边整段剩余值。** 增加的是剩余项数，不是只加一次，也不是两半长度相乘。

例如左半边为 $[2,5,7]$，右半边为 $[1,5,6]$：

| 当前比较 | 取出哪项 | 新增跨区间逆序对 |
| --- | --- | --- |
| 2 与 1 | 右边的 1 | 3：左边 2、5、7 都大于 1 |
| 2 与 5 | 左边的 2 | 0 |
| 5 与 5 | 左边的 5 | 0：相等不是逆序 |
| 7 与 5 | 右边的 5 | 1 |
| 7 与 6 | 右边的 6 | 1 |

最后复制剩余的 7，本次合并共新增 $5$ 对。

## 4. 变量、容器与范围

- `a`：当前处理的序列；函数内部逐层改变顺序，值本身不变。下方个人实现与模板统一使用 `ll` 保存元素。
- `tmp`：归并缓冲区，**按元素数量 `n` 分配**，与元素最大值无关；各层复用同一份空间。
- `l、r`：当前闭区间的两端；`mid` 将其分成互不重叠的两半。
- `i、j`：分别扫描两半，边界分别为 `mid` 与 `r`。
- `p`：下一项写入 `tmp` 的位置，从 `l` 开始。
- `ans`：两半内部的答案，加上本轮跨区间贡献；使用 `ll`，与元素类型分开考虑。

## 5. 执行流程

1. 区间不足两个元素，直接返回 $0$。
2. 递归处理左右两半，得到各自答案；两半同时变得有序。
3. 比较两半当前元素，取出较小项；取右项时批量增加跨区间贡献。
4. 一边取完，复制另一边的剩余项。
5. 把缓冲区的当前段复制回 `a`，返回累计答案。

**复制回去不能省略。** 当前层统计完成后，还要为上一层提供有序的整段。

## 6. 通用实现

完整实现维护于[归并计数模板](../../templates/merge-counting/README.md#接口与约定)，直接复用两道题中的计数核心，入口为 `count_inversions(a)`。该入口按引用接收数组，调用后会将其排序。

```cpp
vector<ll> a = {3, 1, 2};

// 保留原数组时，明确复制一份工作数组
vector<ll> work(a);
ll ans = count_inversions(work); // 2，work 变为 {1,2,3}，a 不变
```

逆序对为 $(3,1)$ 与 $(3,2)$。不需要保留原顺序时，直接传入 `a` 即可，省去入口副本；原地排序与复制后计数的渐进复杂度相同。

## 7. 正确性与复杂度

长度不足 $2$ 时没有逆序对。对于更长区间，递归准确统计两半内部，归并又按右边元素统计全部跨区间数对；三类互不重叠，合起来恰好覆盖整个区间。

> 虽然递归中会排序，但元素始终留在当前的左半或右半内，直到它们之间的贡献统计结束。跨两半的原位置先后关系仍然成立，因此不会因内部排序失去本轮需要的位置信息。

每层归并与复制的总工作量为 $O(n)$，区间长度每层减半，共 $O(\log n)$ 层，所以时间为 $O(n\log n)$。缓冲区为 $O(n)$，递归栈为 $O(\log n)$，总额外空间为 $O(n)$；需要保留原数组时另加一份 $O(n)$ 副本。

## 8. 易错边界与适用条件

- **相等不计数。** 严格逆序使用 `a[i] <= a[j]` 先取左项；全相等数组的答案为 $0$。
- **下标约定不能混用。** 本节左右两半分别为 `[l,mid]`、`[mid+1,r]`，左半剩余长度才是 `mid-i+1`。
- **答案可能超过 `int`。** 严格降序时达到 $n(n-1)/2$；$n=5\times10^5$ 时为 $124\,999\,750\,000$。递归返回值和累计变量都要用 `ll`。
- **不能先整体排序再计数。** 那样会丢掉原位置先后；`sort` 的比较次数也不是逆序对数。
- 负数、重复值、大值域都能直接比较，不必为了本算法额外离散化；当前元素类型须能保存实际输入。
- 多测时重新创建入口副本与缓冲区，各组答案独立，不使用未清空的全局累计值。

> 归并计数适合能把跨区间关系转成**有序扫描与成批贡献**的静态问题。

不是任意数对条件都能直接加 `mid-i+1`：换成其他关系时，要重新推导哪些元素能一起贡献，必要时将计数扫描与实际归并分开。

与[双指针](04-two-pointers.md#5-如何判断复杂度)的联系在于合并时两个指针只向前；分治负责提供有序的两半以及原位置先后。若数据会持续修改，当前静态归并不能直接低成本维护所有答案，需另选相应结构。

## 9. 典题与复盘

两题均已完成实现整理与本地核验。P1908 的平台 AC 依据本人说明；CF 1915F 的平台结果未单独记录。两份原代码共用同一套 `merge_count` 与 `get_ans`，下方只展示一次公共辅助函数，各题保留各自完整 `solve()`，不重复通用框架。

### 9.1 洛谷 P1908：逆序对

[题目链接](https://www.luogu.com.cn/problem/P1908)。给定正整数序列，统计逆序对；$n\le5\times10^5$，元素不超过 $10^9$。

#### 我的思路与原 AC

递归同时统计逆序对并排序。两半内部先算完，再利用两半有序，一次统计右边当前元素与左边所有剩余元素的逆序贡献。

原辅助函数与 `solve()` 仅整理排版和注释，保留引用入口、`size_t n` 与原逻辑：

```cpp
ll merge_count(vector<ll>& a, vector<ll>& tmp, int l, int r) {
    if (l >= r) return 0;

    int mid = l + (r - l) / 2;
    ll ans = merge_count(a, tmp, l, mid);
    ans += merge_count(a, tmp, mid + 1, r);

    // i、j 指向两半下一待读取项，p 指向缓冲区下一待写位置
    int i = l, j = mid + 1;
    int p = l;

    while (i <= mid && j <= r) {
        if (a[i] <= a[j]) {
            tmp[p++] = a[i++];
        } else {
            // 左半所有剩余项均大于当前右项
            ans += mid - i + 1;
            tmp[p++] = a[j++];
        }
    }

    while (i <= mid) tmp[p++] = a[i++];
    while (j <= r) tmp[p++] = a[j++];

    // 把当前段排序结果交给上一层继续合并
    for (int pos = l; pos <= r; ++pos)
        a[pos] = tmp[pos];

    return ans;
}

ll get_ans(vector<ll>& a) {
    size_t n = a.size();
    vector<ll> tmp(n);
    return merge_count(a, tmp, 0, n - 1);
}

void solve() {
    int n; cin >> n;
    vector<ll> a(n);
    for (ll& x : a) cin >> x;

    ll ans = get_ans(a);
    cout << ans << '\n';
}
```

#### 完善与边界

原算法已经达到 $O(n\log n)$ 时间、$O(n)$ 额外空间，无需制造第二种“更优算法”。严格逆序的正确性见前文三类数对拆分，单元素、全相等、升序与降序均适用。

本题元素用 `int` 也能保存，原版统一使用 `ll` 没有问题；**计数的返回值与累计量则必须使用 `ll`**。

`get_ans` 会改变原数组顺序。本题只输出答案，原地排序正合适；如果后续还依赖原位置，应先保留副本。

入口的一个通用边界是 `size_t n`：非空时，题目规模保证 `n-1` 可转成 `int`，原实现正确；空数组时，`n-1` 会先发生无符号下溢，不能依赖随后转换成 `int` 的结果。模板入口改为先执行 `int n = static_cast<int>(a.size());`，再计算 `n-1`，从而明确支持空数组。这个接口整理不冒充原提交代码。

### 9.2 CF 1915F：Greetings

[题目链接](https://codeforces.com/problemset/problem/1915/F)。每个人从 $a_i$ 同时向右走到 $b_i$，速度相同，到达终点后停下；相遇时互相问候一次，停下后仍能参与问候，统计问候总数。

约束：$n\le2\times10^5$，多测 $n$ 之和不超过 $2\times10^5$；$-10^9\le a_i<b_i\le10^9$，全部 $2n$ 个端点互不相同。

#### 关键转化：固定起点顺序，统计终点逆序

先按起点升序排列，考虑 $a_i<a_j$ 的两个人：$i$ 在后，$j$ 在前。

- **两人都移动时：** 速度相同，距离始终为 $a_j-a_i>0$，不能相遇。
- **若 $b_i>b_j$：** 前面的人 $j$ 先到 $b_j$ 停下，后面的人 $i$ 还会经过这里，于是在 $b_j$ 相遇。时刻为 $t=b_j-a_i$，它晚于 $j$ 到达的 $b_j-a_j$，早于 $i$ 到达的 $b_i-a_i$。
- **若 $b_i<b_j$：** $j$ 移动时，$i$ 的位置不超过 $a_i+t<a_j+t$；$j$ 停下后，$i$ 的位置又始终不超过 $b_i<b_j$。两种阶段都不可能相遇。

全部端点不同，因此无需处理 $b_i=b_j$。得到等价关系：

$$
a_i<a_j\text{ 时，两人相遇}\iff b_i>b_j
$$

> **按起点排序固定第一维，终点的相反顺序就表示一次相遇。** 时间过程被转成了终点序列的逆序对计数。

例如 $(1,4)$ 与 $(2,3)$ 会在 $3$ 相遇；$(1,3)$ 与 $(2,4)$ 虽然路线有交集，却不会相遇。因此不能只按区间是否相交计数。

#### 我的实现

公共辅助函数与 9.1 完全相同，直接复用其 `merge_count` 和 `get_ans`；本题的完整 `solve()` 如下，仅补充过程注释：

```cpp
void solve() {
    int n; cin >> n;
    vector<pll> a(n);
    for (auto& x : a)
        cin >> x.first >> x.second;

    // pair 默认先比较 first；起点互异，无需另写比较器
    sort(a.begin(), a.end());
    vector<ll> b(n);

    // 按起点顺序取出终点，位置关系已包含在 b 的顺序中
    for (int i = 0; i < n; ++i)
        b[i] = a[i].second;

    ll ans = get_ans(b);
    cout << ans << '\n';
}
```

#### 正确性、完善与收获

每对人只会在前面的人停下后相遇一次。按起点排序后，每个人对恰好对应一个先后位置；上面的双向证明说明相遇与终点逆序一一对应，归并计数既不漏算，也不重复。

排序与归并分别为 $O(n\log n)$，总体仍为 $O(n\log n)$，保存端点、终点序列和缓冲区共 $O(n)$ 空间。原解已经合适，推荐继续使用同一实现；通用入口的空数组整理见 9.1。

**如何想到：** 同速移动不能追上 → 相遇只能利用前面的人已经停下 → 写出一对人的起点、终点关系 → 排序固定起点顺序 → 终点顺序相反恰好是逆序对 → 复用计数核心。

可迁移的收获是：**先证明实际过程对应什么数对关系，再复用算法。** 模板可以省去重复实现，但不能替代从题意到计数条件的推导；端点允许相等、速度不同或停下后不再问候时，都要重新分析。

两题的个人实现均有本地对照核验；CF 题另以直接模拟小规模行走过程核对相遇次数，覆盖负坐标、路线有交集却不相遇、完全嵌套、多测和大规模答案。未记录实际发生过的错误，不虚构踩坑过程。
