# 2.5 滑动窗口

## 1. 解决什么问题

连续区间反复向右移动时，相邻区间通常只差少量元素。每次重新统计整个区间，会重复处理大部分相同内容。

> **保存当前区间的状态：右端加入什么就更新什么，左端移走什么就撤销什么。**

滑动窗口是[同向双指针](04-two-pointers.md)的一类应用。除了移动位置，还要明确当前区间保存了什么、加入和移除后如何保持一致。

本节通用示例采用 C++11、**0 下标、闭区间 `[l,r]`**，长度为 $r-l+1$。序列长度可用 `int` 表示；`l=r+1` 表示空窗口。

典题保留原实现的下标与边界约定，并单独说明。

## 2. 定长与变长

| 形式 | 边界如何移动 | 需要维护什么 |
| --- | --- | --- |
| 定长窗口 | 长度固定为 $k$，整体右移 | 新元素加入、最左元素移除后的状态 |
| 变长窗口 | 右端扩展，左端按条件收缩 | 状态是否满足条件，以及移动是否会漏掉更优区间 |

**状态可更新，不代表移动方向就一定正确。** 变长窗口还需要证明：已经排除的左端，不会在之后重新变成必须考虑的答案。

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

using namespace std;
using ll = long long;
```

## 3. 定长窗口：加入一个，移走一个

给定数组，求所有长度恰好为 $k$ 的连续区间中的最大和。

令 $W_l$ 表示区间 $[l,l+k-1]$ 的和，向右移动一格后：

$$
W_{l+1}=W_l-a_l+a_{l+k}
$$

中间的 $k-1$ 项没有变化，不必重新相加。

```cpp
// 前提：1 <= k <= a.size()，数组长度可用 int 表示
// a 的元素为 int；累计和使用 long long
ll maxFixedSum(const vector<int>& a, int k) {
    int n = static_cast<int>(a.size());
    ll sum = 0;

    // 先构建第一个完整窗口 [0,k-1]
    for (int i = 0; i < k; ++i) {
        sum += a[i];
    }

    // 用真实窗口初始化，避免全负数时错误地保留 0
    ll best = sum;

    for (int r = k; r < n; ++r) {
        // a={2,-1,3,4}、k=2 时，首窗为 {2,-1}
        // r=2：加入 3，移走 2，窗口变为 {-1,3}
        sum += 1LL * a[r] - a[r - k];

        best = max(best, sum);
    }

    return best;
}
```

**不变量：** 更新答案时，`sum` 始终是当前长度为 $k$ 的窗口和。第一个窗口与后续每个窗口都恰好统计一次。

初始化为 $O(k)$，后续移动为 $O(n-k)$，总时间为 $O(n)$，额外空间为 $O(1)$。

定长求和的加减关系不依赖正负，**负数不会破坏这个写法**。`k=1` 与 `k=n` 也无需额外分支。

## 4. 变长窗口：非负数的最长受限区间

给定**非负整数数组**和非负上限 $S$，求区间和不超过 $S$ 的最长连续区间长度，允许答案为 `0`。

右端加入元素后，如果总和过大，就从左端移除，直到恢复合法，再更新长度。

### 4.1 为什么可以丢掉左端

非负数保证两件事：

- 向右扩展，总和不会减小。
- 从左收缩，总和不会增大。

因此当前左端对应的区间一旦超限，保留该左端继续向右扩展也不会恢复合法，可以安全移走它。

> **“超限后收缩”成立，靠的是状态变化的单调性，不是区间和这个名字。**

```cpp
// 前提：a[i]>=0，limit>=0，数组长度可用 int 表示
int longestAtMostSum(const vector<int>& a, ll limit) {
    int n = static_cast<int>(a.size());
    int l = 0, best = 0;
    ll sum = 0;

    for (int r = 0; r < n; ++r) {
        // 加入右端后，sum 对应当前 [l,r]
        sum += a[r];

        while (sum > limit) {
            // 当前左端不能保留，撤销其贡献后继续检查
            sum -= a[l];
            ++l;
        }

        // 已恢复合法；单个元素超限时，窗口可能为空
        best = max(best, r - l + 1);
    }

    return best;
}
```

**不变量：** 更新答案时，窗口合法；此前移走的左端都已经被证明无法与当前或更晚右端组成合法区间。因此保留下来的窗口是当前右端下最长的合法窗口。

右端遍历一遍，左端总共最多前进 $n$ 次。每次加入、移除都是常数操作，总时间为 $O(n)$，额外空间为 $O(1)$。

### 4.2 含负数时的反例

数组 $[5,-4]$，上限 $S=1$：读到 `5` 时，上面的写法会移走它；之后再读 `-4`，无法回头得到原本合法的整段，其和为 `1`、长度为 `2`。

**负数可能让原本超限的区间在扩展后重新合法，排除依据就失效了。** 需要重新分析性质，不能直接套用此窗口；前缀和、二分或其他结构的选型留到具体模型中讨论。

## 5. 频次窗口：出现次数与种类数

区间状态也可以是频次表。例如求“最多包含 $K$ 种值”的最长连续区间。

先约定值已映射为 `1..m`，**原数组顺序保持不变**。值域很大时，可参考[离散化](03-discretization.md)；不能为了分组而直接排序原数组。

- `cnt[x]`：值 `x` 在当前窗口中的出现次数。
- `kinds`：当前出现次数大于 `0` 的值有多少种。

> **加入时只有 `0→1` 才新增一种；移除时只有 `1→0` 才减少一种。**

```cpp
// 前提：a[i] 位于 1..m，m>=0，k>=0，数组长度可用 int 表示
int longestAtMostKinds(const vector<int>& a, int m, int k) {
    int n = static_cast<int>(a.size());
    vector<int> cnt(m + 1, 0);
    int l = 0, kinds = 0, best = 0;

    for (int r = 0; r < n; ++r) {
        int x = a[r];

        // a={1,2,1,3} 时，第二个 1 只增加次数，不增加种类
        ++cnt[x];
        if (cnt[x] == 1) {
            ++kinds;
        }

        while (kinds > k) {
            int y = a[l];
            --cnt[y];

            // 移走一个 1 后若还剩一个 1，这一类仍在窗口中
            if (cnt[y] == 0) {
                --kinds;
            }

            ++l;
        }

        best = max(best, r - l + 1);
    }

    return best;
}
```

> 扩展不会减少种类数，收缩不会增加种类数，移动依据与上一节类似。但这里不要求原值非负，只要求编号合法、频次维护正确。

初始化频次表需要 $O(m)$，指针扫描为 $O(n)$，总时间为 $O(n+m)$，额外空间为 $O(m)$。`k=0` 时每次加入后都会收缩到空窗口，答案为 `0`。

## 6. 最长与最短：什么时候更新答案

移动框架不能只替换条件，**答案更新的位置也取决于目标**：

| 目标 | 常见处理顺序 | 更新时机 |
| --- | --- | --- |
| 最长合法窗口 | 扩展 → 不合法时收缩 → 恢复合法 | 收缩结束后更新 |
| 最短满足要求的窗口 | 扩展 → 满足时记录 → 继续尝试收缩 | 满足要求时、移除左端前更新 |

第二种写法要在**收缩后重新检查：一旦条件不再满足，就继续扩展右端**。是否能这样扫描，仍需证明扩展与收缩对条件的影响。

本节实现要求更新答案时窗口合法，所以**恢复条件使用 `while`**。一次移除不一定够，例如非负数组 `[1,1,1,5]`、上限为 `5`，最后加入 `5` 后需要移走三个 `1`。

## 7. 与前缀和的区别及易错点

| 需求 | 常用处理 |
| --- | --- |
| 静态数组上任意询问区间和 | 前缀和 |
| 连续枚举所有定长区间的和 | 滑动更新或前缀和均可 |
| 根据当前状态调整连续区间 | 有排除依据时使用变长窗口 |
| 窗口最大值、最小值等 | 仅存一个最值无法撤销离开项，需保存候选或借助区间查询结构 |

### 最值为什么需要额外结构

最值也取决于整个区间，区别在于：**只保存一个最大值，会丢掉其余候选；最大值运算不能像求和那样通过减法撤销旧元素。**

例如旧窗口分别为 `[9,8,1]` 与 `[9,4,1]`，旧最大值都是 `9`。同样移走 `9`、加入 `2`，新最大值却分别为 `8` 和 `4`。

所以只凭“旧最大值、离开的值、进入的值”，不能确定新最大值。原数组虽然仍保存所有元素，但若每次重新扫描窗口，单次更新就可能需要 $O(k)$，其中 $k$ 为窗口长度。

> **状态要保存足以决定后续更新的信息。求和可以直接加减；最值需要额外保存候选，或者使用能重新查询区间的结构。**

| 方法 | 保留什么信息 | 后续位置 |
| --- | --- | --- |
| 单调队列 | 可能成为后续最值的候选下标，排除劣势与过期候选；整段扫描可为 $O(n)$ | 第 09 章：单调栈/队列，待整理 |
| `multiset` | 窗口内所有值及重复次数，插入、移除一次出现为 $O(\log k)$ | [已有 STL 笔记](../01-basic-problem-solving/04-stl/containers/09-multiset.md) |
| ST 表 | 对静态数组预处理区间最值，之后查询为 $O(1)$ | 第 09 章：ST 表，待整理 |
| 线段树 | 分层保存区间最值，支持修改与查询 | 第 09 章：线段树，待整理 |

只维护移动窗口的最值时，优先考虑单调队列；需要保留完整有序内容时可考虑 `multiset`。ST 表与线段树面向更一般的区间查询需求，本节不展开实现，后续在第 09 章竞赛数据结构中整理。

窗口状态不能每次重新用 `count` 或遍历整段统计，具体教训见[双指针 P1102 复盘](04-two-pointers.md#71-p1102实际值与所需值匹配)。**总移动次数线性，内部状态维护也要高效。**

其他边界：

- 定长窗口先确认 $1\le k\le n$，不能用不完整窗口初始化答案。
- 变长窗口可能为空，闭区间长度仍按 `r-l+1` 计算。
- 最短区间可能无解，应明确返回约定；有多个等长解时，按题目规则处理起点。
- 累计和与状态更新的中间运算也要检查类型，不能只扩大最终答案。
- 多组数据重新初始化频次表、边界与答案，不保留上一组状态。

### 简单调用

```cpp
vector<int> fixed = {2, -1, 3, 4};
cout << maxFixedSum(fixed, 2) << '\n'; // 输出 7，对应 {3,4}

vector<int> nonnegative = {2, 1, 3, 1};
cout << longestAtMostSum(nonnegative, 4) << '\n'; // 输出 2
```

### 8.1 CF 363B：定长窗口只维护变化量

$n\le1.5\times10^5$，$1\le k\le n$，$1\le h_i\le100$。找总高度最小的连续 $k$ 块木板，输出起点，多解时任意一个即可。

**收录原因：** 从重新计算整段，转向维护相邻候选之间的变化；用真实的第一个候选初始化答案，把状态更新与答案位置联系起来。

#### 我的思路与原实现

采用 1 下标，先计算 `[1,k]` 的和。之后从旧窗口移走左端，加入下一项；窗口和严格变小时，记录新起点。

`dp` 在这里保存的是当前窗口和，不需要另建状态表；为了突出含义，也可以命名为 `sum`。

原代码只调整排版与注释，保留逻辑。

```cpp
void solve() {
    int n, k; cin >> n >> k;

    vector<int> a(n + 1);
    for (int i = 1; i <= n; ++i) {
        cin >> a[i];
    }

    // dp 保存当前窗口和，l 保存最优窗口的起点
    // 先构建第一个完整窗口 [1,k]
    int dp = 0, l = 1;
    for (int i = 1; i <= k; ++i) {
        dp += a[i];
    }

    // 用真实窗口初始化，不漏掉第一个候选
    int minn = dp;
    for (int i = 1; i <= n - k; ++i) {
        // 旧窗口 [i,i+k-1] -> 新窗口 [i+1,i+k]
        // 加入 a[i+k]，移走 a[i]
        dp += a[i + k] - a[i];
        // 只在严格变小时更新，多解时保留更早起点
        if (dp < minn) {
            minn = dp;
            l = i + 1;
        }
    }

    cout << l << '\n';
}
```

#### 正确性、边界与完善

循环第 `i` 轮之前，`dp` 是 `[i,i+k-1]` 的和；加上 `a[i+k]`、减去 `a[i]` 后，恰好得到 `[i+1,i+k]`。首个窗口已单独参与答案初始化，所以所有合法起点都被检查一次。

**严格小于才更新**，因此等和时保留较早起点；题目允许任意最优起点，这个选择成立。

- `k=n` 时没有后续窗口，直接保留起点 `1`。
- `k=1` 时等价于逐个比较元素。
- 窗口和最多为 $100k\le1.5\times10^7$，原实现的 32 位 `int` 足够。

总时间为 $O(n)$；输入数组占 $O(n)$ 空间，除此之外只维护常数个变量。原方案已合适，推荐沿用同一实现，不为比较而重复一份相同代码。

本地核验覆盖原题样例、所有小区间枚举、并列最优及最大规模边界，结果一致；平台结果未记录。

**如何想到：** 连续枚举同样长度的区间 → 相邻窗口只差两个位置 → 去掉离开的值、加入进入的值 → 同时更新最优和与起点。

### 8.2 P1638：右端指向下一个尚未加入的位置

$n\le10^6$，$1\le a_i\le m\le2000$。求包含全部画家作品的最短连续段，保证有解；长度相同时输出起点最小的一组，答案使用 1 下标。

**收录原因：** 同一窗口可以由不同的边界约定表达；先明确哪些元素已经计入，再推导长度与访问条件，避免依赖习惯性的加减一。

#### 我的思路：先补齐种类，再尽量缩短

`cnt[x]` 保存画家 `x` 的出现次数，`cur` 保存当前种类数。种类不足时从右端加入；覆盖全部画家后，先记录答案，再尝试移走左端。

本实现的 `r` 指向**下一个尚未加入**的位置。初始 `l=r=1`，尚未加入任何画：

| 量 | 含义 |
| --- | --- |
| `l` | 当前窗口第一项 |
| `r` | 下一项待加入的位置，不属于当前窗口 |
| `[l,r)` | 当前已加入的半开窗口 |
| `[l,r-1]` | 同一个窗口的闭区间表示 |
| `r-l` | 当前长度 |
| `l、r-1` | 应输出的左右端点 |

> **`++r` 发生在加入 `a[r]` 之后，因此窗口末端始终是 `r-1`。**

#### 原实现

只调整排版与注释，保留逻辑。

```cpp
void solve() {
    int n, m;
    cin >> n >> m;

    vector<int> a(n + 1);
    for (int i = 1; i <= n; ++i)
        cin >> a[i];

    if (n == 1) {
        cout << "1 1\n";
        return;
    }

    // cnt 记录每位画家的出现次数，cur 记录当前种类数
    vector<int> cnt(m + 1);
    int cur = 0;
    // r 指向下一个尚未加入的位置，当前窗口为 [l,r-1]
    // 初始 l=r=1，窗口为空
    int l = 1, r = 1;
    int minn = INT_MAX;
    int ansl = 0, ansr = 0;

    while (r <= n) {
        // 内层会不断 ++r，必须在每次读 a[r] 前检查 r<=n
        while (cur < m && r <= n) {
            int y = a[r];

            ++cnt[y];
            if (cnt[y] == 1) {
                ++cur;
            }
            ++r; // 加入后，r 又指向新的待加入位置
        }

        // 覆盖全部画家时，先记录答案，再尝试移走左端
        while (cur == m) {
            int len = r - l; // [l,r-1] 的长度是 r-l

            // l 只向右移动，等长时不覆盖即可保留最小起点
            if (len < minn) {
                minn = len;
                ansl = l;
                ansr = r - 1;
            }

            int x = a[l];

            // 移走的是一次出现；最后一幅离开时才减少种类
            --cnt[x];
            if (!cnt[x]) {
                --cur;
            }
            ++l;
        }
    }

    cout << ansl << ' ' << ansr << '\n';
}
```

#### 踩坑：外层检查不能代替内层检查

扩展循环中的 **`&& r <= n` 必须保留**：

`while (cur < m && r <= n)` 中，内层每次加入后都会 `++r`，下一次读取前必须重新检查范围。

外层 `while (r<=n)` 只在进入下一轮外层时检查。进入内层之后，`r` 可能多次增加；如果直到末尾也未补齐缺少的种类，就会继续尝试读取 `a[n+1]`。

合法小输入：$n=3,m=2$，数组为 `[1,2,2]`。

| 步骤 | `l` | `r` | `cur` | 状态 |
| --- | --- | --- | --- | --- |
| 加入前两项 | 1 | 3 | 2 | 窗口 `[1,2]` 合法 |
| 移走第一个 `1` | 2 | 3 | 1 | 缺少画家 `1` |
| 加入最后一个 `2` | 2 | 4 | 1 | 仍缺少画家 `1` |
| 再次尝试扩展 | 2 | 4 | 1 | 内层必须停止，不能读取 `a[4]` |

原做题过程曾因缺少该检查而 WA。对上述输入删除内层边界条件后，受检数组访问复现了越界；越界属于未定义行为，并不保证每次都以同一种错误结果出现。

> **谁推进边界，谁就要负责检查推进后的访问条件。外层检查不会自动持续约束内层。**

到达 `r=n+1` 时，如果当前窗口仍覆盖全部画家，后面的收缩循环仍可以正常处理；这里不再读取新的右端元素。

#### 正确性与复杂度

**不变量：** 每次加入或移除后，`cnt` 与 `cur` 都精确描述 `[l,r)`。

加入时仅在次数从 `0` 变为 `1` 时增加种类数；移除时仅在次数降为 `0` 时减少种类数，因此重复作品不会被误当成新种类。

覆盖全部画家后，当前窗口是合法候选，先记录再移除左端。移除过的左端已经有对应的合法答案，之后再扩大右端只会更长，不需要回退重新检查它。

所有候选的左端按递增顺序出现，**仅在长度严格更小时更新**，便能保留等长答案中最小的起点。例如 `[1,2,1]`、`m=2` 应保留 `[1,2]`，而不是被后来的 `[2,3]` 覆盖。

`n=1` 且保证有解时必有 `m=1`，原特判成立。`r` 可以到 `n+1`，但只有 `r<=n` 时才读取新元素；长度与计数都在 `int` 范围内。

两个边界各自最多走一遍，频次表初始化为 $O(m)$，总时间为 $O(n+m)$；输入数组加频次表占 $O(n+m)$ 空间。原实现通过全部合法小区间对照、并列最优、末尾缺种类及百万规模边界核验，平台结果未记录。

#### 等价整理实现：用 `for` 推进右端

也可以每轮固定加入一个右端元素，再收缩左端。此时 `r` 表示**本轮已经加入**的位置，窗口改为闭区间 `[l,r]`。

```cpp
void solve() {
    int n, m;
    cin >> n >> m;

    vector<int> a(n + 1);
    for (int i = 1; i <= n; ++i) cin >> a[i];

    vector<int> cnt(m + 1);
    int cur = 0, l = 1;
    int minn = INT_MAX;
    int ansl = 0, ansr = 0;

    // r 是本轮已加入的位置，窗口统一为闭区间 [l,r]
    for (int r = 1; r <= n; ++r) {
        ++cnt[a[r]];
        if (cnt[a[r]] == 1) {
            ++cur;
        }

        while (cur == m) {
            int len = r - l + 1;

            if (len < minn) {
                minn = len;
                ansl = l;
                ansr = r;
            }

            // 记录合法窗口后，再移走左端并检查是否仍覆盖全部
            --cnt[a[l]];
            if (cnt[a[l]] == 0) {
                --cur;
            }
            ++l;
        }
    }

    cout << ansl << ' ' << ansr << '\n';
}
```

两种写法的扫描方向、频次维护和取最短的依据相同，时间与空间阶数不变。
>这个版本省去单块特判，并让右端访问限制由 `for` 统一负责；它不是性能上的另一种算法。

| 比较项 | 原实现 | `for` 整理实现 |
| --- | --- | --- |
| `r` 的含义 | 下一项待加入的位置 | 本轮已加入的位置 |
| 已加入窗口 | `[l,r)`，即 `[l,r-1]` | `[l,r]` |
| 长度 | `r-l` | `r-l+1` |
| 输出右端 | `r-1` | `r` |
| 右端访问限制 | 内层扩展时检查 `r<=n` | `for` 检查，内层不推进 `r` |

> **不能只替换循环形式而保留旧的长度、输出表达式。边界含义改变时，要一起核对所有相关位置。**

整理实现也已通过独立区间枚举与百万规模边界核验，仅标本地核验，不标平台 AC。

#### 如何想到

需要覆盖全部画家 → 用频次表判断当前窗口含有哪些种类 → 不够时扩展，齐全时尝试收缩 → 每次移除前记录合法候选 → 由边界含义确定长度和输出，并在实际推进的位置检查范围。

本题与前一题都按连续区间增量维护状态，但合法性、边界约定和答案更新时机不同，不能只套用同一组加减一。

## 9. 自查

- 能解释定长窗口为什么只需加入一个、移走一个。
- 能说明非负区间和窗口的排除依据，并用负数反例推翻错误套用。
- 能区分频次与种类数，正确处理 `0→1`、`1→0`。
- 能根据最长或最短目标选择答案更新时机。
- 能解释只存旧最值为何信息不足，并说出单调队列等补充结构。
- 能由 `r` 是否已经加入，推导窗口长度与输出右端。
- 能说明外层范围检查为何不能替代内层扩展的 `r<=n`。
- 能把指针移动和状态维护的成本一起计入复杂度。
