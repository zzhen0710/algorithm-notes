# 6.15 本章总结与选型

覆盖 6.1–6.14，含 Prim、关键路径补充篇。**先明确目标，再检查方向、边权、结构与规模。** 推导、图解和代码通过链接回原文。

## 1. 先问要求什么

n 为点数，m 为实际存储的边记录数；二分图左右点数为 L、R。无向边通常存两条记录，欧拉路径的边 id 则按原边编号。

| 目标／条件 | 已有方法与入口 | 时间成本 |
| --- | --- | --- |
| 可达性、连通块、树的父子关系 | [建图与遍历](01-graph-basics.md)，全图任务遍历所有未访问起点 | O(n+m) |
| 每条边两端必须异组 | [二分图染色](02-bipartite-coloring.md)，逐块传播颜色、检查冲突 | O(n+m) |
| 无向图全部连通，选边总权最小 | [Kruskal](03-kruskal-mst.md) 适合边表；[矩阵 Prim](03a-prim-mst.md) 适合稠密图／矩阵输入 | 前者 O(n+m log(m+1)+mα(n))；后者 O(n²) |
| 依赖顺序、DAG 状态传播 | [拓扑排序](05-topological-sort.md)，入度归零再处理 | O(n+m) |
| DAG、非负工期、资源充足且允许并行 | [关键路径](05a-critical-path.md)，正推最早、反推最迟，求关键活动与余量 | O(n+m) |
| 两侧一一配对，最多配多少 | [DFS 增广匹配](06-bipartite-matching.md)，允许重新安排已有搭档 | O(L(R+m)+n)，含每轮清空标记 |
| 子树变区间、子树第 k 个节点 | [DFS 序](07-dfs-order.md)，固定根后建立位置映射 | 预处理 O(n)，基本位置查询 O(1) |
| 祖先上跳、最近公共祖先、树上距离 | [倍增 LCA](08-lca-binary-lifting.md) | 预处理 O(n log n)，单次 O(log n) |
| 有向图内互相可达、组间依赖 | [SCC 与缩点](12-strongly-connected-components.md)，缩点后得到 DAG | O(n+m)，不含额外去重排序 |
| 无向图删点／删边是否增加连通块 | [割点与桥](13-articulation-points-bridges.md)，DFS 返回时判断能否绕开 | O(n+m)，输出排序另计 |
| 每条原边恰好走一次 | [欧拉路径](14-euler-trail.md)，合法起点＋度数＋完整覆盖 | O(n+m)；有序版上界 O(n+m log(m+1)) |

最小生成树要求**总边权最小**；最短路要求**起点到目标的路径最短**。连通图的 MST 最小总权值与起点无关，具体选边可能不同。

## 2. 最短路与约束，按条件选

| 条件／需求 | 方法 | 时间／主要空间 |
| --- | --- | --- |
| 无权或每步代价相同，单源 | [BFS](../03-search/02-bfs-shortest-path.md) | O(n+m)／O(n+m) |
| 非负边权，单源 | [堆 Dijkstra](04-dijkstra.md) | O(n+m log(m+1))／O(n+m)，堆可有 O(m) 条旧记录 |
| DAG，允许负边 | [拓扑 DP](../../patterns/06-graph-and-tree/dag-dp.md) | O(n+m)／O(n+m) |
| 允许负边，需要松弛与负环检测 | [Bellman–Ford／SPFA](10-negative-shortest-path.md) | 本章实现最坏 O(nm+n)／O(n+m)；SPFA 不保证线性 |
| 点数较少、无负环，需要任意点对距离 | [Floyd](09-floyd.md)，按可用中转点分阶段，k 在最外层 | O(n³)／O(n²) |
| 多个差值上界，求可行赋值 | [差分约束](11-difference-constraints.md)，统一不等式后全图判负环 | 本章 SPFA 实现最坏 O(nm+n)／O(n+m) |

**负边会破坏 Dijkstra 的贪心定值依据；加永久 vis 不能修好。** Floyd 可以处理负边，但负环影响的点对没有有限最短路。检测“从 s 可达的负环”与“全图任意负环”是不同任务。

差分约束 `x[i]−x[j] ≤ c` 建 **j→i、权 c**：对应松弛 `dist[i] ≤ dist[j]+c`。等式需两个方向；无负环得到一组可行解，不自动得到总和最优解。

## 3. 相似变量，含义不能混用

| 对照 | 记住什么 |
| --- | --- |
| Prim 的 best／Dijkstra 的 dist | 前者是接入当前树的最小**边权**，更新不加路径；后者是从源点出发的**路径和** |
| 染色／匹配 | 染色求合法两组；匹配选互不共用端点的边。染色成功不意味着存在完美匹配 |
| DFS 的 parent／最短路的 pre | 前者是遍历树父亲；后者是当前最优路径前驱。仅存父→子边时可不维护 parent；双向树须防走回父边，一般图还需访问状态 |
| tin、tout、order | 子树是闭区间 `[tin[u],tout[u]]`；tin 从节点找位置，order 从位置找节点。只需按原节点输出时，不必强存 order |
| 拓扑序／DFS order | DAG 依赖按拓扑处理；树上父先于子的 order 可正推根路径前缀，逆序可汇总孩子。不能用节点编号顺序替代 |
| SCC 的 low／割点与桥的 low | 目标不同，不能照搬。SCC 需 in 排除已分组节点；无向割点／桥按原边 id 跳来边，保留重边的绕行作用 |

割点／桥的关键差别：孩子 v 返回父亲 u 时，桥判断 `low[v] > dfn[u]`；非根割点判断 `low[v] ≥ dfn[u]`，根另看 DFS 孩子数。图解见[删点与删边](13-articulation-points-bridges.md)。

## 4. 标记什么时候能清、什么时候不能清

- **匹配：** 每轮清 vis，匹配关系跨轮保留；递归成功时调整搭档，不是在枚举后撤销全部配对。
- **负权传播：** inq 只表示当前在队列；出队后仍可能因距离改善再入队。hops 记录当前改善走法的边数，不是入队次数。
- **SCC：** DFS 调用栈返回，不等于已经分组；pending 栈要等整个分量确定后才弹出。
- **欧拉：** used 永久标记原边，next 避免重扫邻接表。点能重复经过；退栈收尾后还要 reverse，并检查路线有原边数＋1 项。

## 5. 写法成本与已有组合

普通遍历、拓扑传播可手写短循环；倍增、Tarjan、欧拉等状态较多，优先复用[本章模板](../../templates/06-graph-and-tree/README.md)，核对方向、编号、范围与返回值。深链用显式栈，仍需容器空间。

**邻接表通常 O(n+m)，矩阵 O(n²)，倍增表 O(n log n)。** 例如 n=10⁵ 时不能直接开距离矩阵；Floyd 的 n=500 已有约 1.25 亿次三重循环。只求可达性不必建全源距离表；一次遍历能处理的固定终点问题，也不必自动套 LCA。

- **子树＋区间工具：** DFS 序只负责映射；静态统计用前缀和，全部修改后输出可用差分，在线修改再配树状数组／线段树。两种遍历与映射见[DFS 序复盘](07-dfs-order.md)。
- **有向环＋DAG：** 先缩 SCC，再分析分量关系；最少起点覆盖数看缩点图的零入度分量，不能只数原图零入度点。组内状态能否合并仍需另证。
- **删除＋离线：** [CF295B](09-floyd.md) 倒序加点，每轮更新全部端点，只在当前恢复点集中统计；通用思路见[逆序离线](../../patterns/06-graph-and-tree/reverse-offline.md)。
- **任务＋关键路径：** [P1113](05a-critical-path.md) 将任务耗时放到入边；虚拟起点为无前置任务补上自身耗时。不同耗时建模不能不加区分地套边权。

回查只问：**点边代表什么？要覆盖哪部分图？算法前提成立吗？每个状态／标记表示什么？时空规模够吗？** P5318 起点、P3385 检测范围等待确认项继续保留；总结不代替个人掌握。
