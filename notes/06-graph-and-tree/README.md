## 学习衔接

前置：[DFS 与回溯](../03-search/01-dfs-backtracking.md)、[BFS 与无权最短路](../03-search/02-bfs-shortest-path.md)。

基础轮先建立建图、遍历、树与二分图模型；后续从[并查集](../09-data-structures/01-dsu.md)衔接 [Kruskal](03-kruskal-mst.md)，再按前置关系推进带权最短路与拓扑排序等知识链；结合 DFS 与二分图染色进入[增广路匹配](06-bipartite-matching.md)。已有区间工具与 Trie 小单元复盘后，进入 [6.7 DFS 序](07-dfs-order.md)，为树上的区间处理、LCA 与树形 DP 建立前置。6.7 实际代码复盘后接入 [6.8 倍增与 LCA](08-lca-binary-lifting.md)，先补祖先跳跃与树上汇合点，再进入树形 DP。数学计数小单元后，通过 [6.9 Floyd](09-floyd.md)补任意点对距离与中转阶段 DP。数位 DP 小单元后，通过 [6.10 负权最短路与负环](10-negative-shortest-path.md)补距离改善的重新传播与负环覆盖范围，为差分约束建立前置；再通过 [6.11 差分约束](11-difference-constraints.md)练习从数量关系建图和读取可行解。差分约束小单元后，进入 [6.12 强连通分量与缩点](12-strongly-connected-components.md)，从有方向的连通性衔接已有拓扑与 DAG DP。主题完整收尾时再维护全章成本与场景推荐。
