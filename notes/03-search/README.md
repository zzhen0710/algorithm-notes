## 学习衔接

基础轮先完成 DFS/回溯及其典题，再学习 BFS，随后衔接[图与树的基本模型](../06-graph-and-tree/01-graph-basics.md)和二分图染色。剪枝进阶、双向 BFS、迭代加深与启发式搜索后续补齐，不要求学完整章才切换主题。

各领域基础模型记录建立后，通过 [3.3 记忆化搜索](03-memoized-search.md)衔接 DFS、DP 与无环依赖；先练习状态与结果复用，再通过 [3.4 搜索剪枝](04-search-pruning.md)练习证明停止条件；随后 [3.5 双向 BFS](05-bidirectional-bfs.md)衔接已有按层最短路，其他专题按前置推进。

图遍历与方案枚举中的访问标记含义需分别说明，不能机械套用同一种恢复规则。主题完整收尾时再维护覆盖全章的成本比较与场景推荐。
