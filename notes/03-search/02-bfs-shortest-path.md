# 3.2 BFS 与无权最短路

## 1. 解决什么问题

当每次操作的代价相同，需要求从起点到某个状态的**最少操作次数**时，可以考虑 BFS。

**BFS（Breadth-First Search，广度优先搜索）按距离逐层扩展：先处理起点，再处理一步可达的状态，然后是两步、三步……**

例如网格移动、棋盘跳跃、某种规则下的状态变化。位置或状态是节点，一次合法操作是边；不必事先存下全部边，可以在处理当前状态时生成下一步。

> **每条边都算一步时，最短路径长度就是经过的边数。** 普通 BFS 的保证依赖等代价转移，一般带权最短路不能直接套用。

沿用 [C++ 竞赛基础框架](../../templates/01-basic-problem-solving/cpp-contest-template/README.md)，使用 C++11。本节先用网格建立模型，邻接表等图的存储后续再系统整理。

**下标约定：四向网格导引采用 0-based，两道典题的棋盘坐标与楼层编号采用 1-based。** 距离从 `0` 开始计数，与数组下标从哪里开始是两回事。

## 2. 从深度优先切换到按层推进

[上一节](01-dfs-backtracking.md#92-洛谷-p1605迷宫)的迷宫统计所有合法路线，需要深入一条路径，再回退尝试其他路径。

求最少步数时，不必枚举全部路线。只需知道每个状态的最短距离，并从较近的状态继续扩展。

假设起点 `S` 到终点 `T` 有两条路线：

```text
S → A → B → T    3 步
S → C → T        2 步
```

DFS 若先走 `A` 分支，第一次遇到 `T` 得到的是 $3$，并不保证最短。BFS 先处理距离 $1$ 的 `A、C`，再处理距离 $2$ 的状态，首次发现 `T` 时距离为 $2$。

**“先找到”是否等于“最优”，取决于搜索顺序及问题性质。** DFS 可以配合其他方法求最短路，但不能把第一次到达直接当成最短。

## 3. 队列与距离数组各做什么

队列 `queue` 先进先出：前面发现的状态先被处理，后面发现的状态排在队尾等待。

距离数组 `dist` 同时承担两项职责：

- `dist == -1`：该状态尚未发现，可以进入队列。
- `dist >= 0`：该状态已经发现，值为起点到它的最少步数。

发现一个未访问的邻居时：

$$
\mathrm{dist}[nx][ny]=\mathrm{dist}[x][y]+1
$$

因此不必再额外建一份相同含义的 `visited`。

> **在入队时就设置距离，表示“已经发现并安排处理”。** 该距离在本轮搜索中一直有效；出队或处理完后，都不再改回表示未发现的 `-1`。下一次独立搜索再重新初始化距离。

若延迟到出队才标记，同一层的多个状态可能把同一个邻居重复加入队列。这样会产生冗余工作，简单的一次访问复杂度分析也不再成立。

## 4. 导引模型：四向网格的最少步数

给定非空矩形地图，`.` 表示空地，`#` 表示障碍，从起点上下左右移动。一次移动算一步，求起点到各格的最少步数。

本模型使用 **0 下标**：合法行号为 $0\ldots n-1$，合法列号为 $0\ldots m-1$。起点坐标保证位于地图内，若起点为障碍，则所有距离保持 $-1$。

### 变量、容器与范围

- `g`：`n` 行字符串，每行长度相同，为 `m`；仅作为地图读取，不在搜索中改写。
- `sx、sy`：起点行、列坐标。
- `dist`：按**行数 `n` 与列数 `m`**分配，不由距离最大值决定。初始全为 `-1`，起点设为 `0`。
- `q`：保存已发现、尚未处理的格子坐标；每格最多入队一次，总容量不超过格子数。
- `dx、dy`：四个方向的行列变化，同一下标配对使用。
- `x、y`：本次出队的位置；`nx、ny` 为候选邻居。

### 执行流程

1. 初始化全部距离为 `-1`，检查起点是否为障碍。
2. 设置起点距离为 `0`，将起点加入队列。
3. 队列非空时，取出队首，检查四个邻居。
4. 排除越界、障碍和已经发现的位置。
5. 为合法新位置设置距离，再将它加入队尾。
6. 队列耗尽后，返回完整距离矩阵；剩余 `-1` 的位置不可达。

## 5. 通用实现

以下是四向网格的教学实现，不是配套题的专属题解。函数读取地图并返回距离，不修改输入；每次调用重新初始化队列和距离，调用之间互不影响。

```cpp
vector<vector<int>> bfs(const vector<string>& g, int sx, int sy) {
    int n = static_cast<int>(g.size());
    int m = static_cast<int>(g[0].size()); // 约定地图非空且每行等长

    vector<vector<int>> dist(n, vector<int>(m, -1));
    if (g[sx][sy] == '#') return dist;

    int dx[] = {1, -1, 0, 0};
    int dy[] = {0, 0, 1, -1};
    queue<pair<int, int>> q;

    dist[sx][sy] = 0; // 起点也要在入队前标记，防止后续重复进入
    q.push({sx, sy});

    while (!q.empty()) {
        auto cur = q.front(); // 复制队首，pop 后仍可使用坐标
        q.pop();

        int x = cur.first;
        int y = cur.second;

        for (int i = 0; i < 4; ++i) {
            int nx = x + dx[i];
            int ny = y + dy[i];

            // 先判断边界，合法坐标才能用于数组访问
            if (nx < 0 || nx >= n || ny < 0 || ny >= m)
                continue;

            if (g[nx][ny] == '#' || dist[nx][ny] != -1)
                continue;

            dist[nx][ny] = dist[x][y] + 1; // 首次发现就确定最少步数
            q.push({nx, ny});
        }
    }

    return dist;
}
```

使用示例：

```cpp
vector<string> g = {"..#.", "...."};

auto dist = bfs(g, 0, 0); // 四向移动，起点为左上角

// 结果：第一行 0 1 -1 5，第二行 1 2 3 4
for (const auto& row : dist) {
    for (int d : row) cout << d << ' ';
    cout << '\n';
}
```

`q.front()` 只读取队首，`q.pop()` 才移除；不能对空队列调用它们。此处复制队首，避免保留队首元素的引用后又将其移除。

## 6. 为什么首次发现就是最短距离

起点距离为 $0$。处理距离为 $d$ 的状态时，新发现的邻居距离设为 $d+1$，并放在队尾。

由于先进先出，距离 $d$ 的状态会在距离 $d+1$ 的状态之前被处理；队列按距离非降序推进。

假设某状态首次被赋值为 $d+1$，却存在更短路线，那么那条路线的前驱应更早被处理，并且已经发现该状态，与“首次发现”矛盾。

因此，首次赋值就是最短距离。其他路线再次到达相同状态时，不需要重复展开。

> **能够合并到同一个格子的前提，是未来可选操作只依赖这个格子。** 若还依赖钥匙、方向或剩余资源，就要把这些信息也纳入状态与距离记录。

本模型有 $nm$ 个格子，每格最多入队一次，检查四个方向，初始化与搜索总时间为 $O(nm)$；距离矩阵和队列空间为 $O(nm)$。

一般图若用邻接表逐条检查边，BFS 的搜索时间为 $O(V+E)$，其中 $V$ 是顶点数、$E$ 是边数；这取决于实际生成邻居的成本，不能无条件套用到所有隐式状态问题。

## 7. 与回溯中访问标记的区别

这里讨论的是**标记变量怎样变化**，不是是否保留地图或输出结果：

- **撤销当前路径的标记**：进入分支前将 `v[x][y]` 设为 `true`，递归返回后改回 `false`，表示这个位置已经退出当前路径。下一条路径仍可使用它。
- **不撤销本轮搜索的标记**：状态首次发现后，`visited` 一直为 `true`，或 `dist` 一直保持已经确定的非负距离；后续不改回 `false` 或 `-1`，所以同一状态不再入队或展开。

| 目标 | 标记含义 | 本轮搜索中的具体操作 |
| --- | --- | --- |
| 上节迷宫：统计全部简单路线 | 位置已被当前路径占用 | 进入前设为 `true`，返回后改回 `false` |
| 本节 BFS：求每个状态的最少步数 | 状态已首次发现并确定距离 | 入队前从 `-1` 改为距离，此后不改回 `-1` |
| DFS：遍历全部可达状态 | 顶点已发现 | 进入前设为 `true`，返回后不改回 `false` |

**是否撤销标记由问题目标和状态含义决定，不由函数名决定。** “本轮不撤销”也不表示多组输入共用旧状态；下一组独立问题仍需重新初始化。

本例只记录距离，不统计所有路线。即使目标是统计最短路线数，也需要另加计数状态，不能将入队次数直接当作方案数。

## 8. 易错边界与选型

- **起点距离为 `0`，入队前就标记。** 起点到自身的最少步数为零。
- 不可达保持 `-1`；不能用默认零同时表示未访问和距离为零。
- 题目使用 1 下标时，需要整体采用 1 下标存储或在输入时转换，不能只改某一处边界。
- 求所有位置的距离时，应处理完整队列；只求一个终点时，可在首次发现它后结束，或在它出队时结束。前者要另处理起点就是终点的情况。
- 本节仅返回距离。需要输出一条最短路径时，可在首次发现时记录前驱，随后从终点逆向追溯并重建路径；这与回溯时撤销访问标记是不同操作。
- BFS 适合等代价转移。边权为 `0/1` 时考虑后续的 0-1 BFS；一般非负权考虑 Dijkstra，不能仅更换容器就继续使用本节的一次访问规则。
- 不必手动逐层计数：`dist[下一状态] = dist[当前状态] + 1` 已记录层数。若按轮处理队列，必须固定本轮开始时的队列长度，避免把新入队项算进同一层。

### 9.1 洛谷 P1443：马的遍历

[题目链接](https://www.luogu.com.cn/problem/P1443)。给定棋盘和马的起点，输出到每个位置的最少步数，不可达输出 $-1$；$1\le x\le n\le400$，$1\le y\le m\le400$。

原题已取消固定场宽要求，**空格分隔或合理场宽均可**，不必照搬旧题解的固定对齐格式。

#### 我的思路与原实现

棋盘坐标使用 **1-based**，行范围为 $1\ldots n$，列范围为 $1\ldots m$；`dist` 分配为 `(n + 1) × (m + 1)`，第 `0` 行、列不使用。

- `dx、dy`：马的八种移动方向，按相同下标配对。
- `dist`：同时记录是否发现与最少步数，初始 `-1`，起点为 `0`。
- `q`：等待处理的坐标，类型为 `queue<pii>`，其中 `pii` 沿用框架的 `pair<int, int>` 别名。

从起点开始，每次取出队首，对八种移动检查边界与是否已经发现；新位置先设置距离，再入队。题目要求到所有格子的距离，因此必须完成整轮搜索。

```cpp
int dx[] = {2, 1, -1, -2, -2, -1, 1, 2};
int dy[] = {1, 2, 2, 1, -1, -2, -2, -1};
int n, m, sx, sy;

void solve() {
    cin >> n >> m >> sx >> sy;
    vector<vector<int>> dist(n + 1, vector<int>(m + 1, -1));
    dist[sx][sy] = 0; // 标记起点已发现，距离为零

    queue<pii> q;
    q.emplace(sx, sy);

    while (!q.empty()) {
        auto cur = q.front();
        q.pop();

        for (int i = 0; i < 8; ++i) {
            int x = cur.first, y = cur.second;
            int nx = cur.first + dx[i];
            int ny = cur.second + dy[i];

            // 1-based：先确认候选坐标属于棋盘
            if (!(nx > 0 && nx <= n && ny > 0 && ny <= m))
                continue;

            if (dist[nx][ny] != -1)
                continue;

            dist[nx][ny] = dist[x][y] + 1; // 入队前赋值，避免重复入队

            q.emplace(nx, ny);
        }
    }

    for (int i = 1; i <= n; ++i) {
        for (int j = 1; j <= m; ++j)
            cout << dist[i][j] << ' ';
        cout << '\n';
    }
}
```

#### 正确性、选型与进步空间

每次马步都只计一步，八种转移完整覆盖合法移动，所以符合 BFS 的等代价条件。每格首次发现即得到最短距离，队列耗尽后未发现的位置保持 `-1`。

每格最多入队一次、检查八个方向，时间与空间均为 $O(nm)$；输出整个棋盘本身也需要 $O(nm)$ 时间。原实现已适合题目，无需额外访问数组或另一套最短路算法。

`x、y` 在八个方向内保持不变，可移到内层 `for` 之前以突出“当前点固定、候选点变化”；这是表达上的简化，不改变算法复杂度，原实现继续原样保留。

思考入口是“最少步数 → 每次跳跃代价相同 → 按距离层次展开”。马步的几何长度不影响这里的代价：题目计的是跳了几次，不是走过的几何距离。

边界重点为单格棋盘、窄棋盘上的不可达位置，以及起点自己的距离为零。状态：复盘完成（本地核验，平台结果未记录）。

### 9.2 洛谷 P1135：奇怪的电梯

[题目链接](https://www.luogu.com.cn/problem/P1135)。第 $i$ 层的上下移动幅度由 $K_i$ 决定，求从 $A$ 到 $B$ 的最少按键次数，无法到达输出 $-1$；$1\le N\le200$，$0\le K_i\le N$。

#### 我的思路与原实现

楼层使用 **1-based**，范围为 $1\ldots n$；`nxt`、`dist` 均分配 `n + 1` 项，第 `0` 项不使用。`nxt[x]` 保存当前楼层的移动幅度，不是下一层的编号。

- `dist[x]`：从 `A` 到楼层 `x` 的最少按键次数，`-1` 表示未发现。
- `q`：只保存楼层编号，不必保存到达它的完整路线。
- `ans`：默认 `-1`；只有取到目标楼层时，才赋为其最短距离。

每次检查当前楼层向上和向下的两个候选位置，先确认合法并且未发现，再赋距离、入队。目标在出队前检查，起点就是终点时也能直接得到 `0`。

```cpp
int n, A, B;

void solve() {
    cin >> n >> A >> B;

    vector<int> nxt(n + 1);
    for (int i = 1; i <= n; ++i)
        cin >> nxt[i];

    vector<int> dist(n + 1, -1);
    dist[A] = 0;

    queue<int> q;
    q.push(A);
    int ans = -1; // 搜索不到目标时，保持题目要求的不可达结果

    while (!q.empty()) {
        auto x = q.front();

        if (x == B) {
            ans = dist[x];
            break; // 只求一个目标，其距离已经确定
        }

        q.pop();

        int nx = x + nxt[x];
        if (nx <= n && dist[nx] == -1) {
            dist[nx] = dist[x] + 1;
            q.push(nx);
        }

        nx = x - nxt[x];
        if (nx > 0 && dist[nx] == -1) {
            dist[nx] = dist[x] + 1;
            q.push(nx);
        }
    }

    cout << ans << '\n';
}
```

#### 踩坑：不能只安排“找到目标”的输出

最初漏看了无法到达时输出 `-1` 的要求。**初始化 `ans = -1`，找到目标再覆盖，能自然处理队列耗尽却没有目标的情况。**

例如 $n=2,A=1,B=2$，两个楼层的移动幅度都为 $0$，无法离开起点，应输出 $-1$；若 $A=B$，即使移动幅度为零，也应输出 $0$。

默认值必须来自题意，不能因为最少次数是非负数，就把默认答案设为 `0`。

#### 正确性、选型与边界

一次向上或向下都只算一次按键，转移符合等代价条件。BFS 首次发现楼层时已经确定最短距离，目标到队首后直接结束是正确的。

- `nxt[x] >= 0` 且 `x` 是合法楼层，因此向上只需补上界检查，向下只需补下界检查；若题目允许负幅度，这个简化就不再成立。
- `nxt[x] == 0` 时，上下候选都是自己，但 `dist[x] != -1`，不会再次入队，也不会死循环。
- 目标检查发生在 `q.pop()` 之前，找到时队列尚有元素也无妨；局部队列结束后销毁，不影响答案。

每层最多入队一次，只检查两个方向，时间与空间均为 $O(n)$。原实现已适合题目，不需要再写等价的完整版本；也可直接输出 `dist[B]` 省去 `ans`，但保留原写法更能体现默认失败结果与成功覆盖。

思考入口是“对象不一定是二维格子 → 楼层也是状态 → 按规则生成相邻状态”。BFS 的模型取决于状态与转移，不取决于题面是否画出地图。
