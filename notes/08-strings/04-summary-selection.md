# 8.4 本章总结与选型

覆盖 8.1–8.3，另列 Trie 作为多字符串前缀查询的入口。

## 1. 先看要匹配什么

| 需求 | 方法 | 成本与取舍 |
| --- | --- | --- |
| 给定一个模式，找它在文本中的所有出现；或找一串的相等前后缀 | [KMP 与前缀函数](01-kmp.md) | 文本长度 $n$、模式长度 $m$ 时，时间 $O(n+m)$，辅助空间 $O(m)$，另计输出。精确匹配，现场重写时重点核对回退 |
| 同一字符串上反复比较子串，或给大量候选去重 | [字符串哈希](02-string-hash.md) | 预处理 $O(n)$ 时间和空间，取单段指纹 $O(1)$，枚举、排序或去重另计。双哈希仍可能碰撞；要求严格正确时，指纹相同还须核对原串或选确定性方法 |
| 最长回文，或反复判断指定区间是否回文 | [Manacher](03-manacher.md) | 预处理 $O(n)$ 时间和空间，取最长再扫描一次，单区间判定 $O(1)$。单次回文判定直接双指针；需整张半径表时复用模板 |
| 多个单词反复插入、精确查询或统计前缀 | [Trie](../09-data-structures/08-trie.md) | 固定字母表数组版逐字符走，一次插入或查找为 $O(L)$，$L$ 是词长；内存看实际节点数与字母表大小 |

## 2. 写完先检查这几个量

| 变量或接口 | 检查点 |
| --- | --- |
| KMP 的 `j` 与 `pi[i]` | `j` 是已匹配长度，`pi[i]` 是前缀 `s[0..i]` 的最长相等真前后缀长度。失配时用 `pi[j-1]`，完整匹配后也回退，才能继续找重叠出现 |
| 哈希的 `h[i]` 与 `get(l,r)` | `i` 表示前缀长度。查询统一用 0-based 半开区间 `[l,r)`，消去左前缀前要乘对应的幂对齐。比较可能不同长度的对象时，先比长度 |
| Manacher 的 `i`、`p[i]` 与 `right` | `i` 和 `right` 都在变换串上。本章 `p[i]` 是不含中心的半径，数值恰好等于原串回文长度。原串起点是 `(i-p[i])/2`，区间 `[l,r)` 的查询是 `p[l+r] >= r-l` |
| Trie 的 `end` 与 `pass` | `end` 数恰好在此结束的词，`pass` 数经过此处的词。完整词也是自己的前缀，合并两类计数时要避免在终点重复统计 |

## 3. 用旧题回查

- [CF 126B](01-kmp.md) 先沿 border 链找候选，再用内部出现长度的上界筛选，避免把整个串末尾那次出现算成中间出现。
- [CF 271D](02-string-hash.md) 先限制坏字符数，再给合法子串取指纹去重。取哈希是 $O(1)$，枚举子串的成本仍在。
- [CF 1326D2](03-manacher.md) 先从两端保留配对相同的字符，剩余部分只比较最长回文前缀和后缀。半径表只用来找这两个候选。
