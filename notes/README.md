# Notes：算法学习与训练

本目录按算法知识章节组织，统一收录系统笔记、经验总结与错误记录。

当前训练以蓝桥杯备赛为主，参考第十七届蓝桥杯软件赛（编程类）竞赛大纲安排学习范围，优先建立大学 B 组能力，并逐步向大学 A 组扩展。比赛目标用于确定训练范围与优先级，目录结构按知识内容组织。

训练过程结合 Codeforces、洛谷与蓝桥杯历年真题，重点提升：

- 算法识别能力
- 问题建模能力
- 复杂度分析能力
- 独立实现能力
- 比赛稳定性

## 学习方式

每个知识条目按照以下流程推进：

1. 从实际问题或朴素方法切入
2. 分阶段理解核心思想
3. 推导算法过程
4. 手算和模拟
5. 独立实现 C++ 代码
6. 完成 CF / 洛谷 / 蓝桥代表题
7. 复盘思路与错误
8. 整理正式笔记
9. 更新仓库并提交
10. 验收后进入下一条

一个条目只有完成：

> 理解 → 实现 → 做题 → 复盘 → 笔记

才视为真正完成。

## 章节

### [第一章 基础问题求解能力](01-basic-problem-solving/README.md)

从复杂度分析、枚举、模拟、STL、位运算和排序开始，建立比赛中最基础的问题分析与实现能力。

### 第二章 序列与区间技巧

前缀和、差分、双指针、滑动窗口、离散化、二分等。

### 第三章 搜索

DFS、BFS、回溯、剪枝、记忆化搜索以及进阶搜索方法。

### 第四章 贪心与构造

贪心思想、区间贪心、交换论证与构造。

### 第五章 动态规划

线性 DP、背包、区间 DP、树形 DP、状压 DP、数位 DP 及常见优化。

### 第六章 基础数据结构

栈、队列、堆、单调结构、并查集等。

### 第七章 区间数据结构

ST 表、树状数组、线段树、Trie 与简单平衡树。

### 第八章 字符串

字符串哈希、KMP、Manacher 以及 A 组高级字符串算法。

### 第九章 图论

最短路、最小生成树、拓扑排序、LCA、连通性、网络流等。

### 第十章 数学与数论

数论、组合数学、模运算、矩阵、高斯消元以及 A 组高级数学。

### 第十一章 其他正式考纲

计算几何、概率论与博弈论。

### 第十二章 A 组高级数据结构

树链剖分、动态开点线段树、可持久化数据结构、树套树、动态树等。
