# 10.3 随机快排与重复值

快排每轮扫描一个区间，再递归处理两侧。若总选首元素，有序数组可能反复只分出一个很小的子区间。若又把等于枢轴的数全赶到同一侧，全相等的数组也可能每轮只排除一个元素。下面用**随机选枢轴**减少连续偏分，用**双向扫描遇等值就停**处理重复值。

```cpp
void qsort(vector<int>& a, int l, int r) {
    if (l >= r) return;

    int p = a[l + rand() % (r - l + 1)];

    int i = l, j = r;
    while (i <= j) {
        while (a[i] < p) ++i;
        while (a[j] > p) --j;
        if (i <= j) {
            swap(a[i], a[j]);
            ++i;
            --j;
        }
    }

    qsort(a, l, j);
    qsort(a, i, r);
}
```

**用途速记。** 原地把闭区间 `[l,r]` 排成升序。`p` 是复制出来的枢轴值，交换数组元素时保持不变。两边扫描找出需要互换的值，交换后两个指针各走一步。指针交错后，递归处理 `[l,j]` 和 `[i,r]`。

## 为什么重复值不会卡住？

左边只跳过严格小于 `p` 的值，右边只跳过严格大于 `p` 的值。两边都遇到 `p` 时，也会交换并推进。这样做保住了划分关系：已处理的左侧不大于 `p`，右侧不小于 `p`。

```text
初始   [7 7 7 7 7]    i=0, j=4
交换   [7 7 7 7 7]    i=1, j=3
交换   [7 7 7 7 7]    i=2, j=2
交换   [7 7 7 7 7]    i=3, j=1
递归   [0,1] 和 [3,4]
```

以五个 `7` 为例，指针下标从 `(0,4)` 走到 `(1,3)`，最后在中间相遇并交错，剩下长度为 $2$ 和 $2$ 的两段。**等值不会全挤到一边，但仍可能留在递归区间里。** 所以全相等时，这版仍做 $\Theta(n\log n)$ 的工作。如果希望一次排除整段等值，可以改用三路划分，只递归严格小于和严格大于枢轴的两段，全相等时只扫一轮。

## 为什么随机选择后通常接近 $O(n\log n)$？

单次划分是 $\Theta(m)$，其中 $m$ 是当前区间长度。关键在于还有多少轮划分。随机选下标后，输入即使原来有序，也不会固定挑到端点值。有常数概率选到按大小排序后中间一半的位置，划分便能把子区间缩小到原来的一定比例。反复缩小后，期望总时间是 $O(n\log n)$。

**最坏仍是 $\Theta(n^2)$。** 互异元素若连续选到极端枢轴，仍可能反复得到近似 $1$ 对 $m-1$ 的划分。普通递归的调用栈最坏是 $O(n)$。附件使用 `rand() % len`，取模可能有偏，区间长度超过 `RAND_MAX + 1` 时还会有下标抽不到。[配套模板](../../templates/10-supplementary/randomized-quicksort/README.md)沿用相同划分，改用 `uniform_int_distribution` 均匀抽取下标。

## 用哪些输入回看？

拿已排序、逆序、全相等和大量重复但混有不同值的数组各走一轮。重点看枢轴从哪里选、两指针遇到相等值是否都会移动，以及递归边界是否排除了已经交错的位置。日常只需排序时用 [STL sort](../01-basic-problem-solving/04-stl/algorithms/01-sort.md)。
