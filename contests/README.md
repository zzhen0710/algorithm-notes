## 内容分工

- 每场一篇，文件名优先用平台比赛编号，保留比赛及官方题解链接。
- 正文按题定位，重点解释关键转化与易漏条件，代码只展示必要函数；已有实现足够合适时不再附等价版本。
- 需要完整展开的精选单题放在 [Problems](../problems/README.md)，整赛文档链接过去；方法提炼复用 [Patterns](../patterns/README.md)，知识与通用实现分别见 [Notes](../notes/README.md) 和 [Templates](../templates/README.md)。
- 代码来源与验证状态按实际记录，个人实现与整理／改进版本区分。
