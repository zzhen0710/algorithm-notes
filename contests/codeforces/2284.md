## A1 / A2. 15K4JR3B

[等权版](https://codeforces.com/contest/2284/problem/A1) · [二的幂权值版](https://codeforces.com/contest/2284/problem/A2)

### A1：等权操作，尽量均分

```cpp
void solve() {
    ll n;
    cin >> n;

    cout << (n / 2) * (n - n / 2) << '\n';
}
```

设横向、纵向位移总量为 $X,Y$，则三点的横向跨度最多为 $X$，纵向跨度最多为 $Y$。矩形内的三角形面积最多为矩形的一半：固定另外两点，面积对当前顶点坐标是仿射函数的绝对值，因此逐个把顶点移到矩形角上，面积可以不减。把横向操作全给一个点、纵向操作全给另一个点，就能让两倍面积达到 $XY$。A1 中 $X+Y=n$，尽量均分即可，时间 $O(1)$。

### A2：权值降序，每次给较轻的一组

```cpp
void solve() {
    int n;
    cin >> n;
    vector<ll> w(n);
    for (ll& x : w) {
        ll a;
        cin >> a;
        x = 1ll << a;
    }
    sort(w.rbegin(), w.rend());

    ll x = 0, y = 0;
    for (ll v : w) {
        if (x <= y) x += v;
        else y += v;
    }

    cout << x * y << '\n';
}
```

总位移 $X+Y$ 固定。由 $4XY=(X+Y)^2-(X-Y)^2$，最大化乘积等价于最小化组间差值。

**降序让当前权值 $w$ 整除此前所有权值。** 设旧两组和为 $P,Q$，总和为 $T$，则 $P-Q=T-2Q\equiv T\pmod{2w}$。余数只有 $0,w$ 两种，取绝对值也不改变余数。所以差值 $D$ 要么都在 $0,2w,4w,\ldots$，要么都在 $w,3w,5w,\ldots$。

对同一个旧划分，把 $w$ 给较轻组得到 $\lvert D-w\rvert$，小于等于给较重组的 $D+w$。而在上述任一种序列中，最小可达 $D$ 都能让 $\lvert D-w\rvert$ 最小（$D=0$ 时，$2w$ 至多打平）。因此按前缀归纳，每轮只需从最小差值继续。升序处理 $1,2,4$ 会得到 $5,2$，降序则得到 $4,3$。时间 $O(n\log n)$。

## B. Introduction to the Niche Internet

[题目](https://codeforces.com/contest/2284/problem/B)

```cpp
void solve() {
    int n, k;
    cin >> n >> k;
    vector<ll> a(n);
    for (ll& x : a) cin >> x;

    if (k == n) {
        sort(a.begin(), a.end());
        cout << "YES\n";
        for (ll x : a)
            cout << x << ' ';
        cout << '\n';
        return;
    }

    sort(a.rbegin(), a.rend());

    ll sum = accumulate(a.begin(), a.begin() + k, 0ll);

    if (a[k] * k < sum) {
        sort(a.begin(), a.begin() + k);
        cout << "YES\n";
        for (ll x : a)
            cout << x << ' ';
        cout << '\n';
    } else {
        cout << "NO\n";
    }
}
```

第一个数自动满足条件，此后当前数至少等于此前平均值才算 pleasant。**每个全局最大值无论摆在哪里都满足**，所以最大值出现次数大于 $k$ 时无解。

取最大的 $k$ 个数升序放在前面，保证前缀都满足。若 $k\lt n$ 且最大值出现次数至多为 $k$，前缀平均值严格大于后缀最大值，对应 `sum > k * a[k]`。随后降序放后缀，每加入一个数，新的平均值仍严格大于它，而下一个数不超过它，所以也低于新的平均值。时间 $O(n\log n)$。

## C1. Disgusting + GCD（构造）

[题目](https://codeforces.com/contest/2284/problem/C1)

```cpp
constexpr int MAXN = 200001;
bool isprime[MAXN];
vector<int> primes;

void init() {
    fill(isprime, isprime + MAXN, true);
    isprime[0] = isprime[1] = false;

    for (int i = 2; i < MAXN; ++i) {
        if (isprime[i]) primes.push_back(i);

        for (int p : primes) {
            if (p > (MAXN - 1) / i) break;
            isprime[i * p] = false;
            if (i % p == 0) break;
        }
    }
}

void solve() {
    int n;
    cin >> n;

    vector<int> a(n);
    for (int& x : a)
        cin >> x;

    for (int i = 0; i < n; ++i) {
        auto it = lower_bound(primes.begin(), primes.end(), a[i]);
        cout << *it << ' ';
    }

    cout << '\n';
}
```

把每个数 $a$ 变成不小于它的最小质数 $p$。不同质数互质，相同质数的 GCD 等于自身，结果没有坏数对。$p=a$ 时跳过，否则 $\gcd(a,p-a)=\gcd(a,p)=1$，一步可达。由 Bertrand 定理，$a\ge2$ 时存在严格介于 $a$ 和 $2a$ 之间的质数，故增量 $p-a\lt a$。最多用 $n$ 次操作，总增量在预算内。

线性筛一次，`lower_bound` 查询目标。表长为 `MAXN` 时，乘积最大只能到 `MAXN - 1`，所以用 `(MAXN - 1) / i` 限制乘法。预处理 $O(M)$，每组查询 $O(n\log M)$，其中 $M$ 是筛表上界。可复用 [线性筛模板](../../templates/07-math/primes/README.md)。

## C2. Disgusting + GCD（最少操作）

[题目](https://codeforces.com/contest/2284/problem/C2)

```cpp
void solve() {
    ll a, b;
    cin >> a >> b;

    if (a == b) {
        cout << 0 << '\n';
        return;
    }

    if (__gcd(a, b) == 1) {
        cout << 1 << '\n';
        cout << b - a << '\n';
        return;
    }

    ll c = -1;
    ll ab = a * b;

    for (ll x = a + 1; x < b && x <= a + 4096; ++x) {
        if (__gcd(ab, x) == 1) {
            c = x;
            break;
        }
    }

    if (c != -1) {
        cout << 2 << '\n';
        cout << c - a << ' ' << b - c << '\n';
        return;
    }

    int d = int(b - a);

    vector<int> par(d + 1, -1);
    queue<int> q;

    par[0] = 0;
    q.push(0);

    while (!q.empty() && par[d] == -1) {
        int u = q.front();
        q.pop();

        for (int v = u + 1; v <= d; ++v) {
            if (par[v] != -1) continue;

            if (__gcd(a + u, a + v) == 1) {
                par[v] = u;
                q.push(v);

                if (v == d) break;
            }
        }
    }

    vector<int> ans;

    for (int v = d; v > 0; v = par[v])
        ans.push_back(v - par[v]);

    reverse(ans.begin(), ans.end());

    cout << ans.size() << '\n';
    for (int x : ans)
        cout << x << ' ';
    cout << '\n';
}
```

**先把合法操作改写成边。** 从 $u$ 加 $v-u$ 到 $v$，只需检查 $u\lt v$ 且 $\gcd(u,v)=1$。排除零步和一步之后，两步只需找 $a\lt c\lt b$ 且 $\gcd(ab,c)=1$，一次检查同时保证两条边合法。

**为什么只试 4096 个？** $ab\le10^{14}$，最小的 13 个不同质数之积已超过它，故 $ab$ 至多含 12 个不同质因子。Kanold 上界保证任意连续 $2^{12}=4096$ 个整数中至少有一个与 $ab$ 互质。若在区间内试完仍未找到两步解，必有 $b-a\le4096$。[Kanold 原文](https://eudml.org/doc/161543)

这才对短区间做 BFS。节点存偏移量，临时枚举合法边，用 `par` 倒推并输出相邻点的差。每次加 1 始终合法，所以终点一定能访问。设 $d=b-a$，两步检查最多做 $\min(4096,d-1)$ 次 GCD，进入 BFS 后最坏另需 $O(d^2\log b)$ 时间和 $O(d)$ 空间。

C1 用质数同时满足所有数对的条件，C2 用互质判定连接两个状态。共同用到的推导见 [GCD 与互质性质](../../notes/10-supplementary/02-gcd-properties.md)。
