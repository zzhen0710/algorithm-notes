## C. Big XOR

[题目](https://codeforces.com/problemset/problem/2283/C)


```cpp
void solve() {
    int n;
    cin >> n;

    int x = 0;
    for (int i = 1; i <= n; ++i)
        x ^= i;

    int p = 1;
    while (p * 2 <= n)
        p <<= 1;

    vector<int> a(n + 1);
    for (; p >= 1; p >>= 1) {
        if ((x & (p << 1)) == 0) {
            a[p] = 1;
            x ^= p;
            x ^= p << 1;
        }
    }

    for (int i = 1; i <= n; ++i)
        cout << a[i] << ' ';
    cout << '\n';
}
```

设 $h$ 为 $n$ 的最高位下标。$1,\dots,n$ 包含从 $2^0$ 到 $2^h$ 的每个二次幂，因此原序列的按位或 $k=2^{h+1}-1$。目标异或值至少为 $2k$，可以让第 $h+1$ 至第 $1$ 位全为 1，最低位任意。

把 $p=2^j$ 翻倍，异或值只翻转 $j$ 和 $j+1$ 两位。于是从最大的 $p$ 向下枚举，若 $2p$ 对应位为 0 就翻倍 $p$。这一轮补好高位，只把影响留给下一轮，已经处理的位不会被改变。每个 $p$ 至多使用一次；题目只要求达标。时间、空间均为 $O(n)$。

## D. Black, Gray and White

[题目](https://codeforces.com/problemset/problem/2283/D)


```cpp
void solve() {
    int n;
    cin >> n;

    vector<vector<int>> g(n + 1);

    for (int i = 1; i < n; ++i) {
        int u, v;
        cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
    }

    if ((n & 1) == 0) {
        cout << n + 1 << '\n';
        return;
    }

    auto check = [&](int k, int m) -> bool {
        vector<int> belong(n + 1);
        queue<int> q;

        belong[m] = -1;
        int id = 0;

        for (int root : g[m]) {
            ++id;
            belong[root] = id;
            q.push(root);

            while (!q.empty()) {
                int u = q.front();
                q.pop();

                for (int v : g[u]) {
                    if (belong[v] != 0)
                        continue;

                    belong[v] = id;
                    q.push(v);
                }
            }
        }

        for (int u = 1; u <= n; ++u) {
            int v = k - u;

            if (v < 1 || v > n || u >= v)
                continue;
            if (u == m || v == m)
                continue;

            if (belong[u] != belong[v])
                return true;
        }

        return false;
    };

    if (check(n, n)) {
        cout << n << '\n';
    } else if (check(n + 1, (n + 1) / 2)) {
        cout << n + 1 << '\n';
    } else {
        cout << n + 2 << '\n';
    }
}
```

**先最大化黑点，再比较灰点。** 最终黑点就是有不同编号搭档 $k-u$ 的点，灰色中间状态不会改变这个集合。偶数 $n$ 取 $k=n+1$ 能配满。奇数 $n$ 最多配出 $n-1$ 个黑点，只有 $k=n,n+1,n+2$ 能达到它：更远的 $k$ 连有效搭档区间的长度都至多为 $n-2$。三个候选唯一剩下的点分别是 $n,(n+1)/2,1$。

删去剩下的点 $w$ 后，从它的所有邻居划分连通块。若有一对搭档分属不同块，其唯一路径经过 $w$，它就能变灰。最多只有一个灰点，因此前两个候选都失败时，直接输出第三个也最优。建图和常数次 BFS 合计 $O(n)$ 时间、$O(n)$ 空间。

## E. Partition of a Binary String

[题目](https://codeforces.com/problemset/problem/2283/E)


```cpp
constexpr ll MOD = 998244353ll;
constexpr int MAXN = 5005;

ll bell[MAXN], dp[MAXN];

void init() {
    vector<ll> C(MAXN);

    C[0] = 1;
    bell[0] = 1;

    for (int i = 1; i < MAXN; ++i) {
        for (int k = 0; k < i; ++k) {
            bell[i] += C[k] * bell[i - k - 1];
            bell[i] %= MOD;
        }

        for (int k = i; k >= 1; --k)
            C[k] = (C[k] + C[k - 1]) % MOD;
    }

    dp[0] = 1;

    for (int i = 1; i < MAXN; ++i) {
        if (i >= 2)
            dp[i] = (dp[i] + dp[i - 2]) % MOD;
        if (i >= 3)
            dp[i] = (dp[i] + dp[i - 3]) % MOD;
    }
}

void solve() {
    int n;
    string s;
    cin >> n >> s;

    vector<int> good(n, 1);

    for (int i = 0; i + 1 < n; ++i) {
        if (s[i] != s[i + 1])
            good[i] = good[i + 1] = 2;
    }

    int zero = 0, one = 0;
    ll ans = 1;

    for (int i = 0; i < n;) {
        if (good[i] == 1) {
            if (s[i] == '0')
                ++zero;
            else
                ++one;
            ++i;
        } else {
            int j = i;
            while (j + 1 < n && s[j] != s[j + 1])
                ++j;
            int len = j - i + 1;
            ans = ans * dp[len] % MOD;
            i = j + 1;
        }
    }

    int val = accumulate(good.begin(), good.end(), 0);
    ans = ans * bell[zero] % MOD * bell[one] % MOD;

    cout << val << ' ' << ans << '\n';
}
```

1. **先求每个位置的贡献上界。** 纯色组中每个位置贡献 1，混色组中贡献 2。混色组的任意异色对都必须相邻。在一条线上，两侧各有至少两个位置会要求一个四边环，因此至少一色只出现一次；另一色只能占据这个位置的至多两个邻居。合法混色组恰好是 `01`、`10`、`010`、`101`。
2. **证明上界能同时达到。** 有异色邻居的位置恰好组成长度至少 2 的极大交替段。偶数长度全用长度 2 铺满，奇数长度先用一个 3，再用 2 铺满。于是这些位置可以全部贡献 2，其他位置只能贡献 1。任何最优划分都必须让每个交替段铺满。
3. **按独立部分乘方案数。** 每段任选长度 2、3 的块，按最后一块分类得 `dp[len] = dp[len-2] + dp[len-3]`，`dp[0] = 1`，越界项为 0。剩余位置按颜色各自自由划分，乘上 `bell[zero] * bell[one]`；位置可区分，即使字符相同。见 [Bell 数](../../notes/10-supplementary/01-bell-numbers.md)。

官方参考实现保存整个组合数表。这里每次算 `bell[i]` 只读第 $i-1$ 行，使用 [杨辉三角滚动数组](../../notes/07-math/05-basic-counting.md#一维滚动只保留当前行)，先求 Bell 数再推进该行。设预处理上限为 $N$，预处理 $O(N^2)$ 时间、$O(N)$ 空间，每组扫描 $O(n)$。
