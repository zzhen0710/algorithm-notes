## 收录原则

这个仓库不会记录做过的每一道题。

当一道题或一次学习产生以下至少一种价值时，才值得沉淀：

- 学习了新的算法或数据结构
- 总结出了可复用的解题范式
- 遇到了具有代表性的题目
- 发现了重要的错误、边界条件或思维盲点
- 得到了更简洁、更通用的实现方式

目标不是积累代码数量，而是在持续训练中逐渐建立一个精炼、可复用的个人算法知识库。
