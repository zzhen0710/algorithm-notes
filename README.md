# Algorithm Notes

个人算法学习与竞赛训练仓库。

当前主要用于蓝桥杯备赛，同时通过系统学习与刷题逐步提高算法与问题解决能力。

## 仓库结构

### [Templates](templates/README.md)

算法与数据结构模板。

用于沉淀已经理解、能够独立实现并具有复用价值的算法与数据结构实现。

### [Patterns](patterns/README.md)

常见解题范式与可复用的思维模型。

重点记录如何识别问题特征、选择方法并完成问题建模，而不仅仅是具体代码实现。

### [Problems](problems/README.md)

具有代表性和长期复习价值的题目与题解。

不记录全部刷题历史，只保留能够体现典型算法、解题思路、重要技巧或思维问题的题目。

### [Notes](notes/README.md)

算法学习过程中的综合笔记、经验总结与错误记录。

用于沉淀不适合单独归入某个算法、解题范式或题目的知识与经验。

## 收录原则

这个仓库不会记录做过的每一道题。

当一道题或一次学习产生以下至少一种价值时，才值得沉淀：

- 学习了新的算法或数据结构
- 总结出了可复用的解题范式
- 遇到了具有代表性的题目
- 发现了重要的错误、边界条件或思维盲点
- 得到了更简洁、更通用的实现方式

目标不是积累代码数量，而是在持续训练中逐渐建立一个精炼、可复用的个人算法知识库。
