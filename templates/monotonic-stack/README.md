# 单调栈：右侧第一个严格更大位置

实现：[monotonic_stack.hpp](monotonic_stack.hpp)。来源：[9.2 单调栈](../../notes/09-data-structures/02-monotonic-stack.md)，保留一份 STL 栈主写法，自行整理。

## 接口与边界

- `next_greater_right(a)`：输入为 **0-based `vector<ll>`**，返回等长的答案下标数组；不存在记为 **`-1`**，不是 `0`。
- 元素数量可用 int 表示，值可覆盖 ll 范围；只比较，不相减。输入不变，每次调用独立，空输入返回空。
- 默认找**严格大于**，相等值不能互相结算；栈中存下标，答案也是下标。若需要数值，先确认非 `-1` 再访问原数组。

| 要找的右侧第一个值 | 弹栈比较 |
| --- | --- |
| 严格更大 | `a[st.top()] < a[i]` |
| 大于等于 | `a[st.top()] <= a[i]` |
| 严格更小 | `a[st.top()] > a[i]` |
| 小于等于 | `a[st.top()] >= a[i]` |

反向扫描可处理左侧关系；改变方向时仍返回原下标，不能忘记“最近”与严格性。这里只保留一份主实现，不维护四个几乎相同的函数。时间 `O(n)`，辅助空间 `O(n)`。
