# C++ Contest Template

用于算法竞赛的基础 C++ 程序框架与相关工程习惯。

当前主要面向：

- Codeforces
- 洛谷
- 蓝桥杯

目标不是构建一个庞大的万能模板，而是维护一套简单、稳定、容易现场复现的竞赛基础环境。

## 设计原则

- 总模板保持最小
- 只保留高频且稳定的内容
- 算法专属内容放入对应专题模板
- 避免为了缩短代码而大量使用宏
- 优先保证可读性、正确性和现场复现速度
- 随着真实比赛和刷题实践逐步扩展

## 使用约定

**执行顺序：** 本地输入设置 → 快速输入输出 → `init()` 一次 → 读取 T → 每组调用 `solve()`。

- `init()` 放与本组输入无关、各组可共用的预处理，例如固定上限的筛表、阶乘表；依赖输入规模时，先读到所需范围再预处理。
- `solve()` 读取本组输入并求解。局部容器自然重建；使用全局数组时，在本组内清理需要重置的状态。
- 默认读取测试组数。单组题保留 `T = 1`，注释 `cin >> T;`；读到 EOF 等格式按题意调整。
- `MOD = 998244353`、`MAXN = 5005` 是常用起始值，按题目模数、下标和数据范围修改。`INF`、`DINF` 是有限哨兵，运算前仍须检查可达性与数值范围。
- 使用 C++11；`bits/stdc++.h` 面向支持它的 GNU C++ 环境。空的 `init()`／`solve()` 是填题位置。

## 按需取用的类型转换

原框架中的转换速记移到这里，主文件保持精简：

```cpp
int n = (int)a.size();           // 容器长度转 int
int pos = (int)(it - a.begin()); // 迭代器差值转下标
ll product = (ll)x * y;          // 先扩大类型，再乘法
double avg = (double)sum / cnt;  // cnt 非零，使用小数除法
int code = (unsigned char)c + 1; // 字节按非负值编码
```

转换前确认目标类型能容纳原值；浮点转整数向 0 截断，事后转换不能补救已经发生的溢出。
