# 数位 DP：余数、非零位计数与相邻位约束

[知识笔记与图解](../../../notes/05-dynamic-programming/09-digit-dp.md) · [实现](digit_dp.hpp)

三个具体模型复用相同的上界框架，各自保留不同条件。**这些函数不是不改状态就能套所有题的万能接口。**

## 接口与约定

以下函数位于 `digit_dp` 命名空间，ll 为 long long；D 是上界的十进制位数，D≤19。

| 接口 | 条件与返回范围 | 是否包含整数 0 | 单次时间／辅助空间 |
| --- | --- | --- | --- |
| `count_digit_sum(x,m)` | [0,x] 中数位和模 m 为 0 的数量，1≤m≤100 | 包含 | O(10Dm)／O(Dm+D) |
| `count_digit_sum_range(l,r,m)` | 0≤l≤r≤10¹⁸ 的闭区间计数 | 按区间包含 | 两次前缀调用，同阶 |
| `count_classy(x)` | [0,x] 中非零数位不超过 3 个的数量 | 包含 | O(10D×4)／O(D×4+D) |
| `count_windy(x)` | [1,x] 中相邻真实数位差至少为 2 的数量 | 排除 | O(10D×11)／O(D×11+D) |

- **范围与类型：** x≤10¹⁸，x<0 均返回 0；返回及缓存统一 ll，计数最多 x+1，不得直接把上界放宽到 LLONG_MAX。
- **下标与上界：** 高位到低位，0-based；`dfs(0,初始条件,true)`，空前缀相同使最高位自然受限。`up=tight?bound:9`，下一位 `tight && d==bound`。
- **缓存：** 初值 −1，只存 tight=false；每次调用重建。不跨位数、条件参数或状态定义沿用旧表。合法答案可以为 0。
- **Classy 剪枝：** cnt 超过 3 时先返回 0，再检查结束和缓存；只开 4 列。笔记个人原版没有这项剪枝，按 O(10D²) 分析，不能混用复杂度。
- **Windy 前导零：** last=10 表示尚未开始，不是上一位为 0；开始后选到 0 仍须检查相邻差。末尾 last=10 的全零分支不计入。
- **零与区间：** Classy 包含 0，原题正区间通过 F(r)−F(l−1) 抵消；若 [0,r] 只统计正整数，要额外减掉 0。Windy 已排除 0，不重复扣减。
- **副作用与多测：** 无外部状态或输入修改；每个区间两次前缀调用，条件与边界需保持一致。
- **依赖：** C++11 标准头文件，无仓库外部依赖；所有数字选择与差值只在 0..10 的小范围内计算。

## 使用示例

```cpp
#include "digit_dp.hpp"
#include <iostream>

int main() {
    std::cout << digit_dp::count_digit_sum(243, 3) << '\n'; // 82，含 0
    std::cout << digit_dp::count_digit_sum_range(1, 243, 3) << '\n'; // 81
    std::cout << digit_dp::count_classy(1000) - digit_dp::count_classy(0) << '\n';
    std::cout << digit_dp::count_windy(10) - digit_dp::count_windy(0) << '\n';
}
```

**用途速记：** 上界框架决定当前数位最多取多少；条件状态决定哪些分支可选，缓存复用同类自由后缀的计数。需要换题时，优先对照下面的改动点，而不是只改函数名。

## 固定骨架与按题修改

| 通常保留 | 必须审查 |
| --- | --- |
| 负上界返回 0；从高位到低位逐位填写 | 是否计入整数 0、如何从初始状态识别全零 |
| up 与 next_tight 的公式 | 状态、缓存维度、当前数字是否合法、条件怎样传递 |
| 计数分支相加；同一状态不重复展开 | 是否需区分前导零，剪枝是否安全，数值范围是否变大 |
