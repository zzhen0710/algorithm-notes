# C++ Contest Template

用于算法竞赛的基础 C++ 程序框架与相关工程习惯。

当前主要面向：

- Codeforces
- 洛谷
- 蓝桥杯

目标不是构建一个庞大的万能模板，而是维护一套简单、稳定、容易现场复现的竞赛基础环境。

## 设计原则

- 总模板保持最小
- 只保留高频且稳定的内容
- 算法专属内容放入对应专题模板
- 避免为了缩短代码而大量使用宏
- 优先保证可读性、正确性和现场复现速度
- 随着真实比赛和刷题实践逐步扩展
