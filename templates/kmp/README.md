# KMP：前缀函数与全部匹配位置

使用 C++11。实现：[kmp.hpp](kmp.hpp)。

原理、图解与两道典题复盘见 [8.1 KMP 与前缀函数](../../notes/08-strings/01-kmp.md)。模板采用同一种 **0-based pi** 约定，保留两个短函数。

## 接口与约定

- `prefix_function(s)`：返回长度为 `s.size()` 的数组。`pi[i]` 是 `s[0..i]` 的**最长相等真前后缀长度**，不是最后一个字符的下标。

- `kmp_find_all(text, pattern)`：返回全部匹配起点，**0-based、递增、允许重叠**。参数顺序为文本在前、模式在后。

- 字符串长度均须可用 `int` 表示，且内存足够。按 `std::string` 的字节序列比较，不把 UTF-8 的一个汉字视为一个字符；也支持字符串内部的零字节。

- 两个函数都不修改输入。所有数组和匹配长度都是局部状态，**多次调用和多测无需清理**。

### 空输入与输出编号

- 空串的前缀函数为空数组。

- **本接口规定：空模式串返回空匹配结果。** 这是接口选择，不表示空串在数学上没有匹配位置。

- 文本为空而模式非空、模式比文本长、没有出现，均返回空结果。

- 若题目要求 1-based 位置，只在输出匹配起点时加 1；**pi 保存长度，不能跟着加 1**。

### 关键回退

失配时只改变 j，当前文本位置 i 不后退：

```cpp
while (j > 0 && text[i] != pattern[j]) j = pi[j - 1];
```

**完整匹配后同样回退**，保留最长 border。否则清零会漏掉重叠匹配，不回退则下一次可能访问 `pattern[m]`。

## 使用示例

```cpp
#include "kmp.hpp"
#include <iostream>

int main() {
    auto pi = prefix_function("ababaca");
    for (int x : pi) std::cout << x << ' ';
    std::cout << '\n'; // 0 0 1 2 3 0 1

    auto pos = kmp_find_all("aaaaa", "aaa");
    for (int x : pos) std::cout << x << ' ';
    std::cout << '\n'; // 0 1 2，三个匹配可以重叠

    std::cout << kmp_find_all("abc", "").size() << '\n'; // 0
}
```

头文件自行包含 `<string>` 与 `<vector>`，不依赖 `using namespace std;`。函数使用 `inline`，可以从多个翻译单元包含。

## 复杂度

设文本长 n、模式长 m、匹配数 z。

- 前缀函数：时间 O(m)，额外空间 O(m)。

- 全部匹配：时间 O(n+m)，**工作空间 O(m)，返回结果另占 O(z)**。

空模式在入口直接返回。若只需是否存在或出现次数，可以按具体需求改匹配成功时的处理，不额外维护一套平行模板。
