# 欧拉路径与回路：Hierholzer

[知识笔记与执行图](../../../notes/06-graph-and-tree/14-euler-trail.md) · [实现](euler_trail.hpp)

```cpp
#include "euler_trail.hpp"

std::vector<std::pair<int, int>> edges;
edges.push_back({u, v}); // 每条原边加入一次；无向图也不再补一条反向输入

bool directed = false; // false：无向图；true：有向图
bool ordered = false;  // true：节点编号序列按字典序取最小
auto path = euler_trail(n, edges, directed, ordered);
if (path.empty()) {
    // 没有覆盖全部原边的欧拉路径
} else {
    // path 是依次经过的节点，已经反转为行走方向
}
```

**用途速记：** 输入点数、原边端点表与图的方向，返回每条原边恰好使用一次的节点路线。检查度数和起点，按原边 id 消耗边，退栈时记录、最后反转；覆盖不足也返回失败。

| 接口／结果 | 约定 |
| --- | --- |
| n | n≥1；真实点编号 1..n，0 不使用 |
| edges | 每条原边一对端点；边 id 为表下标 0..m−1 |
| directed | false 自动双向存储；true 只使用输入方向 |
| ordered | false 求任意一条；true 求字典序最小的**节点序列** |
| 空结果 | 度数条件不符，或有边部分无法在一条路线中全部覆盖 |
| 无边 | 返回 `{1}`，表示约定的零边走法 |
| 非空结果 | m+1 个节点位置，可重复节点，不重复使用原边 |

- **无向端点：** 两个奇度点时从较小者出发；没有奇度点时从最小有边点出发；其他奇度点数量失败。
- **有向端点：** 唯一出度减入度为 1 的点必须作为开放路径起点；终点差为 −1，其余差为 0。全部平衡时从最小有出边点出发。
- **连通性：** 忽略孤立点。用最终 path 大小是否等于 m+1 检查覆盖，不能只检查度数；长度检查也不能绕过度数和起点判断。
- **重边／自环：** 支持。两条无向邻接记录共享 id；自环在无向度数中计 2。每条原边永久使用一次，不恢复 used。
- **副作用／多测：** 输入为 const 引用，函数不修改原边表；每次调用重建工作状态。
- **容量：** C++11；n+1、m+1、度数和邻接列表长度须能用 int 表示，内存足够；不检查越界输入端点。
- **开销：** 默认 O(n+m) 时间；有序版本 O(n+m log(m+1)) 上界；总空间 O(n+m)。显式栈最多 m+1 项，不能按不同节点数估计。
- **返回范围：** 仅节点序列，不返回具体边 id、最短总路程或所有方案；平行边不能仅由端点对恢复唯一身份。
- **字典序：** 排序各点的邻接候选，保持退栈写入与最终反转；不对最终 path 进行 sort。有序与无序模式只共用这一份实现。

## 配套典题调用对照

| 场景 | directed | ordered | 输出约定 |
| --- | --- | --- | --- |
| P7771 有向欧拉路径 | true | true | 无解输出 No，有解一行输出全部点 |
| P2731 骑马修栅栏 | false | true | 点号上界为 500，保证有解，每行一个点 |

P2731 的“500 进制最小”按原题解释就是**节点编号序列的字典序最小**，无需计算任何大整数。个人两题函数名为 euler，模板名为 euler_trail，参数含义一致；两段原 solve 和题意翻译见[典题复盘](../../../notes/06-graph-and-tree/14-euler-trail.md#10-典题与复盘)。通用实现无须为两题各存一份。
