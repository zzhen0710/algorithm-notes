# 倍增 LCA：祖先跳跃与无权距离

实现：[lca.hpp](lca.hpp)。原理、图解与待做配题见 [6.8 倍增与 LCA](../../../notes/06-graph-and-tree/08-lca-binary-lifting.md)。

**先拉齐深度，再从大到小同步跳；祖先不同时才跳，最后返回共同父亲。**

## 接口与依赖

| 接口 | 行为 |
| --- | --- |
| `LCA(g,root=1)` | 按指定根建立快照，内部复用 tree_order |
| `jump(u,k) const` | 向上走 k 条父边；k=0 返回自己，k<0 或越根返回 0 |
| `lca(u,v) const` | 最近公共祖先的原节点编号，包含自身 |
| `distance(u,v) const` | 无权唯一路径的边数，返回 ll |
| `up[j][u]` | u 的第 2^j 级祖先；不存在为 0 |
| `depth[u]` | 距根边数，根为 0 |

依赖同章 [dfs_order.hpp](../dfs-order/dfs_order.hpp)，头文件已用相对路径包含，不再复制一份树遍历。**复制为单文件时展开 DFSOrder/tree_order，删除对应本地 include，再放 LCA。**

- 输入为非空连通无向树，点 1..n，g 长度 n+1、g[0] 留空，每条边双向存储；没有自环、重边和环。根与查询节点合法。
- n+1、列表长度可用 int 表示且内存足够；构造不校验树，不支持森林或一般图。根父亲为 0，所有 up[j][0]=0；不要混用根父亲为自己的约定。
- lg 是行数，合法行号 0..lg-1；行数动态按 n 确定，不依赖固定的 20 或 30。
- 每组新建独立对象即可。查询只读，图不会被修改；改变原图、根或连边后，旧对象不会自动更新，需重新构造。
- 无权距离用 ll 计算中间表达式。需要点权／边权总和时另按题意维护，不将边数接口冒充有权距离。
- 多个孩子的遍历顺序不会改变同一根下的 LCA，无需为了 LCA 特意排序。

## 最小使用

```cpp
#include "lca.hpp"

std::vector<std::vector<int>> g(5);
g[1] = {2};
g[2] = {1, 3, 4};
g[3] = {2};
g[4] = {2};

LCA tree(g, 1);
int ancestor = tree.lca(3, 4); // 2
int higher = tree.jump(3, 2);  // 1
int missing = tree.jump(3, 3); // 0
ll edges = tree.distance(3, 4); // 2
```

## 复杂度与边界

建立父亲／深度 O(n)，建立跳跃表 **O(n log n)**，表空间 **O(n log n)**，另有 O(n) 的临时遍历结果。jump、lca 与 distance 最坏 **O(log n)**；n=1 时按常数处理，可用 log(n+1) 统一边界。

初始化只移动临时 DFS 结果里的 parent／depth；未使用的 tin／tout／order 随临时结果释放。无需长期保存全部 DFSOrder；预处理期间仍需考虑这部分峰值内存。

u=v 时返回自己；根参与 LCA 时返回根。jump 的节点必须合法，非法步数才返回 0；**不能因为接口返回 0，就把任意非法节点也当成可传参数。**
