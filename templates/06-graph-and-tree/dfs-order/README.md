# DFS 序：固定根与子树区间

实现：[dfs_order.hpp](dfs_order.hpp)。原理与图解见 [6.7 DFS 序](../../../notes/06-graph-and-tree/07-dfs-order.md)。

**节点按首次进入顺序记录一次，子树对应 [tin[u],tout[u]]。** 显式栈保存返回位置，长链不依赖递归栈。

## 接口与前提

| 接口／字段 | 含义 |
| --- | --- |
| `tree_order(g,root=1)` | 返回独立的 DFSOrder；不修改、不排序 g |
| `tin[u]` | 原节点 u 的序列位置 |
| `order[i]` | 序列位置 i 上的原节点 |
| `tout[u]` | u 的子树最后一个序列位置，不是退出动作的递增编号 |
| `parent[u]`、`depth[u]` | 父亲与距根边数；根父亲为 0、深度为 0 |
| `subtree_size(u)` | tout-tin+1，包含自身 |
| `kth_in_subtree(u,k)` | 子树内第 k 个访问的原节点；k<1 或超过子树大小返回 -1 |
| `is_ancestor(u,v)` | u 是否为 v 的祖先或自身；严格祖先另要求 u!=v |

- g 为长度 n+1 的**非空连通无向树**，g[0] 留空，无自环／重边／环；每条边两个方向都已存入。根和查询节点合法，编号为 1..n。
- 节点数与列表长度可用 int 表示，n+1 不溢出且内存足够。序号均为 int；权值及统计另按需要使用 ll。
- 只跳父亲，不校验树结构，不兼容一般有环图。输入若仅存父到子的孩子列表，在同一根、所有节点恰好可达的前提下也能使用；不能据此随意更换根。
- 孩子顺序沿用邻接表；要求按编号等规则遍历时，在调用前保证顺序。任意顺序都有子树连续性，但具体 order 可能不同。
- 每次调用独立初始化。修改节点值不必重建顺序；更换根或改变树结构后须重建，不支持动态树接口。
- DFSOrder(n) 只是分配结果数组，尚无有效遍历结果；通常直接用 tree_order 返回值，再调用查询方法。

## 最小使用

```cpp
#include "dfs_order.hpp"

std::vector<std::vector<int>> g(4);
g[1] = {2, 3};
g[2] = {1};
g[3] = {1};

auto t = tree_order(g, 1);
int position = t.tin[2];       // 2
int vertex = t.order[position]; // 2
int size = t.subtree_size(1);  // 3
int kth = t.kth_in_subtree(1, 3); // 3；若 k=4 则为 -1
bool yes = t.is_ancestor(1, 3); // true
```

**三者协作：tin 从节点找到左端位置，tout 限定右端，order 从有效位置取回节点。** `order[tin[u]]==u`、`tin[order[i]]==i`；kth_in_subtree 先按子树大小检查 k，再偏移 k-1，不会因任意大 k 先加法而溢出。

按原节点编号存的 a[u]，应放到数组 b[tin[u]]；子树操作传入 [tin[u],tout[u]]。本组只维护位置，权值结构复用 [BIT](../../09-data-structures/fenwick/README.md)或[线段树](../../09-data-structures/segment-tree/README.md)，不复制第二套实现。

## 将 order 用作计算顺序

**order 正序保证父亲先于孩子；逆序保证所有孩子先于父亲。** 根路径前缀可用正序，孩子子树的结果汇总可用逆序。

逆前序未必与递归后序完全相同，但都满足后一种依赖；孩子之间顺序不受约束时，可以直接复用。本组仍只提供遍历信息，具体状态与合并规则见 [5.7 树形 DP](../../../notes/05-dynamic-programming/07-tree-dp.md)，不把某题转移固定进通用遍历。

## 复杂度与边界

预处理时间、额外空间均为 **O(n)**；构造结果数组同为 O(n)。每个节点入栈／出栈一次，检查两端邻接记录；子树大小、祖先判断与子树第 k 个节点查询均为 **O(1)**。不包含调用前的排序成本。

n=1 时根区间 [1,1]；叶子 tin=tout；根区间 [1,n]。order[0] 不使用。与 0-based 半开区间、往返欧拉序不同，不混用端点与长度公式。

## 来源与核验

延续本仓库显式 DFS 的 next 游标写法，独立整理，不移植外部库代码。教学实现另给递归对照与静态求和；模板保留一种非递归主写法。

**C++11 本地核验通过，编译无警告。** 用独立父链与后代枚举核对顺序、区间、大小和祖先关系，检查不同根／邻接顺序、单点、长链、星形与多次独立构造；图中结果和静态求和同步核对。CF1006E／P10722实际代码已本地核验并复盘，平台结果未单独提供；第 k 个节点查询额外检查首尾、越界与极大 k。验证不代表个人已经掌握。
