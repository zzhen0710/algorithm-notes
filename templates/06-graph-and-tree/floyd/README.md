# Floyd：全源最短距离

[知识笔记与证明](../../../notes/06-graph-and-tree/09-floyd.md) · [实现](floyd.hpp)

## 接口与用途

`void floyd(std::vector<std::vector<ll>>& d)`：传入直接距离矩阵，**原地改成所有点对的最短距离矩阵**。按可用中转点逐阶段松弛，k 必须在最外层。

## 契约与边界

- **编号：** n≥1，传入 (n+1)×(n+1) 方阵；有效点 1..n，第 0 行、列不读取、不修改。
- **初始化：** d[i][i]=0；没有直接边的位置填 FLOYD_INF；重边先取 min，无向边由调用者填正反两项。零权边是合法边。
- **边权：** 可含负边，要求没有负环。此接口不返回负环判定，也不标记受负环影响的点对。
- **范围：** 所有有限状态和候选和必须在 (−FLOYD_INF,FLOYD_INF) 内，ll 保存距离。可按最大边权绝对值 W 检查 `nW < FLOYD_INF / 2` 这一充分条件，比较时同样须防乘法溢出。
- **哨兵：** FLOYD_INF 为 ll 最大值的四分之一；只有前后两段都可达才相加。不可达结果仍等于 FLOYD_INF，不自动转换成 −1。
- **返回与副作用：** 返回 void，直接覆盖 d；要保留原权重时先复制。没有外部状态，多测为每张图重新构造矩阵。
- **依赖：** 仅标准头文件，C++11；无需本仓库其他模板。只计算距离，不恢复具体路线。
- **复杂度：** O(n³) 时间，原矩阵 O(n²) 空间，函数额外 O(1)；后续查询单个点对 O(1)。

## 使用示例

```cpp
#include "floyd.hpp"

int n = 3;
std::vector<std::vector<ll>> d(n + 1, std::vector<ll>(n + 1, FLOYD_INF));
for (int i = 1; i <= n; ++i) d[i][i] = 0;
d[1][2] = 4;
d[2][3] = 2;
d[1][3] = 10;

floyd(d);
// d[1][3] == 6，d[3][1] == FLOYD_INF。
```
