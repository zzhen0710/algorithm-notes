# 拓扑排序：Kahn 顺序与有向环判定

实现：[topological_sort.hpp](topological_sort.hpp)。来源：[6.5 拓扑排序](../../../notes/06-graph-and-tree/05-topological-sort.md)，按已有通用实现自行收敛。

## 接口与边界

- `topo_sort(g,order)`：**1-based 有向图**，g 至少有占位项 `g[0]`，所有端点合法；点数和各点入度均可用 int 表示。
- 每次先清空 order；返回 `true` 时，order 包含全部点的合法顺序。**返回 `false` 时，order 只是部分前缀，不能当作完整拓扑序。**
- 不修改输入图；入度由全部边重新统计，多次调用相互独立。重边必须在统计和删除时保持同样的记录数。
- 孤立点也入队；自环或任意连通部分的有向环都会导致失败。`g.size()==1` 表示零个点，返回成功且顺序为空。
- 普通队列给出任意合法顺序，**不保证字典序最小**；若题目要求，需要改为小根堆。

时间与辅助空间分别为 `O(n+m)`、`O(n)`。模板只安排计算顺序；最长路、计数等 DAG DP 的状态、初值与更新仍由题目决定，不塞进排序函数。

## 核验状态

C++11 独立编译与组合编译通过，未出现警告。小图用排列枚举核对有环与否，成功时检查每条边的先后关系；另核对自环、重边、孤立点、多连通部分、重复调用和输入不变。不新增平台结果或熟练记录。
