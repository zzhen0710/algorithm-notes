# 强连通分量与缩点：显式栈 Tarjan

[知识笔记](../../../notes/06-graph-and-tree/12-strongly-connected-components.md) · [实现](scc.hpp)

```cpp
#include "scc.hpp"

auto scc = tarjan_scc(g);
// scc.id[u]：原点 u 所在的分量编号
// scc.size[c]：分量 c 的点数
auto dag = condensation(g, scc);
```

**用途速记：** 输入有向邻接表，将互相可达的点分组；同组由相同 id 表示。condensation 把跨组的边映射到新图，返回 DAG；不会自动替题目选择点权合并或 DP 转移。

| 接口／结果 | 含义 | 时间／空间 |
| --- | --- | --- |
| tarjan_scc(g) | 全图分解，返回分量数、所属编号和点数 | O(n+m) 时间，O(n) 辅助空间 |
| id[u] | 原节点 u → 分量编号 | O(1) 查询 |
| size[c] | 分量 c 的节点数量 | O(1) 查询 |
| condensation(g,scc) | 跳过组内边，保留跨组边 | O(n+m) 时间，O(count+m) 结果空间 |

- **图与下标：** C++11；g 大小为 n+1，节点 1..n，g[0] 不使用。允许 n=0、自环、重边和不连通；所有端点必须合法，n+1、边表长度、时间戳和容器尺寸须可由 int 表示，内存足够。
- **初始化／多测：** 每次调用重建全部状态，不修改 g；结果拥有自己的数组。新图重新调用，不复用旧 id；缩点必须使用同一张图对应的完整结果。
- **返回值：** count 为分量数；id 大小 n+1，真实编号 1..count；size 大小 count+1，size[0]=0。无点时 count=0。
- **两栈：** dfs 保存尚未返回的调用，pending 保存尚未确定分量的节点；in 只表示后者。单点弹出 DFS 栈，不代表能立刻确定其分量。
- **深链：** 显式栈模拟回溯，不依赖系统递归深度。next 记住每点的下一条边；返回时向 parent 合并 low，每边只检查一次。
- **重边：** 缩点保留跨组重边。拓扑排序若按每条实际边加减入度，仍然正确；统计不同后继／不同分量路径时需明确重边是否应计多次，必要时自行去重，排序去重另计开销。
- **顺序：** id 用于分组，不是原节点编号；本实现按弹出顺序编号。使用 DAG DP 时建议显式拓扑排序，避免把代码的编号习惯误认为状态转移依据。
- **聚合限制：** 不直接输出一条原图简单路径或组内最优值。组内点权能否相加、原边权如何合并，由题目目标另证。

**只需要统计分量入度时，不必调用 condensation 建新图。** 扫描原边，跳过两端 id 相等的边，对 indeg[id[v]] 加 1 即可；仅判断零／非零时可以保留重边。完整用途与证明见 [P2002 复盘](../../../notes/06-graph-and-tree/12-strongly-connected-components.md#92-p2002最少选几个起点才能让消息覆盖全图)。这属于使用结果的方式，通用模板继续保留现有接口。

算法依据可对照 [OI Wiki：强连通分量](https://oi-wiki.org/graph/scc/)。本实现自行按显式 DFS 的进入／返回时机整理，没有复制参考代码。
