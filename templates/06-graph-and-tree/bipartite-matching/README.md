# 二分图最大匹配：DFS 增广

实现：[bipartite_matching.hpp](bipartite_matching.hpp)。来源：[6.6 最大匹配及两题复盘](../../../notes/06-graph-and-tree/06-bipartite-matching.md)，按已有实现自行收敛。

## 接口与边界

- `max_matching(g,m)`：左侧点数为 `g.size()-1`，右侧有 m 个点；左右**分别 1-based**，只在 `g[u]` 中存右点编号，不能按普通无向图再加反向邻接。
- 两侧点数非负、规模及容器长度可用 int 表示；g 至少保留一项，右点编号合法。两侧划分已知，边只表示跨侧兼容关系。
- 返回 `count` 与 `match_r`；`match_r[v]` 为右点 v 的左侧搭档，`0` 表示未匹配。教学接口中的 `match_right` 在模板里简写为 `match_r`。
- **每轮只清 vis，不清已有配对；一轮成功只增加一对。** 支持重边、孤立点、空边集及某侧为空；输入图不变，多次调用独立。
- `count==n` 只表示覆盖所有左点；**还需 n=m，才能据此称为完美匹配。** 不支持带权、一对多或一般图匹配。

时间上界计入每轮清标记，为 `O(n(m+e+1))`，正规模时常写 `O(n(m+e))`；图外辅助空间 `O(n+m)`，递归深度最坏 `O(n)`。保留基础 DFS 增广，不引入额外算法或全局状态。

## 核验状态

C++11 独立编译与组合编译通过，未出现警告。小图穷举与独立配对枚举对照，同时检查配对边存在、两侧不重复、返回数量一致及重边、多次调用等边界。不新增平台 AC 或个人熟练记录。
