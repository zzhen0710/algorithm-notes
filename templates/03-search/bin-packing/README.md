# 小规模一维装箱：最少同容量箱子

实现：[bin_packing.hpp](bin_packing.hpp)，C++11。由[小猫爬山复盘](../../../notes/03-search/04-search-pruning.md#92-p10483小猫爬山与一维装箱)的搜索结构整理为独立通用接口。

```cpp
#include "bin_packing.hpp"

int answer = min_bins({6, 4, 4}, 10); // 2
```

**用途：** 全部物品不可拆分、箱子容量相同且无其他身份约束，返回最少箱数。按对象递归，试放已有箱子并恢复载重，再尝试唯一的新箱编号；以已经找到的可行箱数剪枝。

| 契约 | 说明 |
| --- | --- |
| 输入 | 正整数重量，容量 cap 为正；cap 与单件重量不超过 $10^{18}$ |
| 规模 | 建议 $n\le18$；搜索仍可能很慢，不能只依赖“有剪枝” |
| 返回 | 最少箱数；空输入为 0，任一物品大于 cap 为 −1；不返回具体分组 |
| 下标／状态 | `load[0..used-1]` 为有效箱子；其余槽位不读，新开时覆盖 |
| 初始化／副作用 | 输入按值接收，内部排序；局部 best/load，多测无需额外清理 |
| 类型 | 单箱载重用 long long；比较写成重量不超过剩余容量，未计算全部重量和 |
| 复杂度 | 粗略阶乘级上界 $O(n!)$，额外空间 $O(n)$，含输入副本、载重与调用栈 |

与个人原实现的差别仅在通用接口约定：显式检查单件超容量、载重提升为 `long long`、数据改为局部变量并按值排序；个人原代码仍在笔记保留，不以本函数替换其记录。

未合并同层相同载重箱子；新箱只开一个已排除空箱编号的重复表示。加其他约束或需要按编号计数时，需重新证明等价性与剪枝。

识别、状态与回溯检查见[逐个对象分配容器](../../../patterns/03-search/object-to-container-search.md)。这是具体模型，不能代替多种容量、固定身份容器或任意分组约束的完整建模。
