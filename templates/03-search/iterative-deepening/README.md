# 迭代加深 IDDFS：有限深度内的最短状态路径

实现：[iddfs.hpp](iddfs.hpp)。C++11；对完整状态图，逐次尝试深度 0、1、2……，每轮重新开始限深 DFS。

```cpp
#include "iddfs.hpp"

std::vector<std::vector<int>> g = {{1, 2}, {3}, {3}, {}};
auto goal = [](int u) { return u == 3; };
auto next = [&](int u) { return g[u]; };
auto path = iddfs_path(0, goal, next, 2); // {0,1,3}，共两步
```

**用途：** 从起点出发，每条转移代价为 1，给定目标判断和合法后继，在最大深度以内返回一条步数最少的状态路径。找到任一最少步数方案就结束，不比较同样步数下的第二目标。

| 接口／约定 | 说明 |
| --- | --- |
| `State` | 可复制、支持 `std::hash` 与 `==`，编码包含决定后续所需的全部信息；碰巧同一位置不一定是同一状态 |
| `is_goal(u)`、`next(u)` | 固定状态图上的目标判断与完整有限候选；调用方不靠未记录的历史改变规则 |
| `max_depth` | 允许的最多边数；0 到 INT_MAX−1，实际深度须适合调用栈，不自动猜测一个无限上界 |
| 返回 | 路径包含起点和终点，步数为 size−1；空 vector 表示限内无解；起点为目标时返回单元素路径 |
| 标记 | `in_path` 仅标当前路径，失败后移除；每轮提高上限重新初始化，不是一张 BFS 的永久 visited |
| 生命周期 | 数据局部创建，重复调用无需清理；算法不改调用方图，回调的副作用由调用方负责 |
| 边界 | 深度耗尽前先判断目标；空字符串可作合法状态；有向/无向、自环/重边均可，默认排除当前路径内的重复状态 |

**复杂度：** 分支上界为 b、尝试到 D 层，固定 $b\gt1$ 时最坏 $O(b^D)$；b=1 时反复重搜可达 $O(D^2)$。路径与递归占 $O(D)$ 个状态，逐层生成并暂存的邻居列表还可能占 $O(bD)$；计入状态复制、哈希和生成成本。输入图的内存另计。

不求一般带权最小费用；不保证同深度的其他最优标准；不替代题目特定候选上下界与剪枝。若直接维护定制递归状态更清晰，复用外层逐深思想即可，不强制套入本函数。

**P1763 的返回策略不同：** 同项数还要比较末分母，因此定制 DFS 找到一条方案后继续比较；只有固定前缀的两项求解，在证明参数与末分母单调后才首解即停。它复用迭代加深思想，不直接套本模板的首个目标即返回；[完整复盘](../../../notes/03-search/06-iterative-deepening.md#81-p1763埃及分数限项数再化简搜索末端)保留专属求根与剪枝，不另建题目专用通用板子。

教学版固定 string，模板接受 int/string 等，目标与转移接口一致。完整过程、访问标记反例与配题入口见 [3.6 迭代加深](../../../notes/03-search/06-iterative-deepening.md)。
