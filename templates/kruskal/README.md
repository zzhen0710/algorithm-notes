# Kruskal：最小生成树与指定块数的最小生成森林

实现：[kruskal.hpp](kruskal.hpp)。推导及 P3366、P1195 复盘见 [6.3 Kruskal](../../notes/06-graph-and-tree/03-kruskal-mst.md#8-典题与复盘)。

## 接口与状态

`MSTResult kruskal(int n, vector<Edge>& edges, int k = 1)`：

- 点为 **1-based**，边表容器为 **0-based**。无向边存一次。
- `n` 在 `1..10^6`，`1<=k<=n`，边数可用 `int` 表示，端点均合法。
- **会改变调用者边表顺序**；需要原顺序时先复制。
- 返回 `weight` 和 `used`。合并成功才更新，两者初始均为 0。
- 每次成功合并减少一块，所以 **`used == n-k` 才完成目标**。
- 每次调用重新构造 DSU；重复调用仍会排序和重新扫描，不沿用上一组状态。

```cpp
#include "kruskal.hpp"

// n、k 与 edges 已输入；先保证 1<=k<=n
auto res = kruskal(n, edges, k);
if (res.used != n - k) {
    // 不存在满足目标块数的生成森林，按题意输出失败
} else {
    // res.weight 是最小代价；k=1 时即最小生成树
}
```

若输入可能出现 `k>n` 等非法目标，先在调用处处理；不能让负的所需选边数参与模型解释。

## 边界与复杂度

- `n=1,k=1` 或 `k=n`：选 0 条边，代价为 0。
- 原图有 `c` 块：`c>k` 时无法实现；`c<=k<=n` 时可以选择部分候选边形成目标森林。
- 自环、重边、同权边可直接保留；自环和已同块边不会选入。
- 允许负权，要求每步累加都能用 `ll` 表示；**不用权重 `-1` 作为失败标记**。
- 求的是**森林**。若题意允许成环且负边还能额外降低费用，就不是这个优化目标。
- 只返回权重和数量；要输出具体边，在成功合并处保存原图边，不能输出 DSU 父指针代替。

时间 $O(n+m\log(m+1)+m\alpha(n))$，包括初始化、排序、合并。并查集空间 $O(n)$，排序递归栈通常为 $O(\log(m+1))$，另有调用者保存边表的 $O(m)$ 空间。
