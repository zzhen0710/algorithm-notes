# LIS：二分长度与逐位置长度

实现：[lis.hpp](lis.hpp)。来源：[5.4 序列 DP 与二分优化](../../notes/05-dynamic-programming/04-sequence-dp-lis.md)，自行整理为一个算法和一个短包装函数。

## 接口与边界

- 输入为 **0-based `vector<ll>`**，元素个数可用 int 表示；支持任意 ll 值，不做元素加减。笔记中的 int 元素在这里统一扩大为 ll。
- `lis_ending(a)`：返回每个位置**必须以 a[i] 结尾**的严格上升子序列长度。
- `lis_length(a)`：返回整段数组的严格 LIS 长度，由逐位置长度取最大；空数组返回 `0`，逐位置结果为空。
- 两个接口都可传 `strict=false`，通过 `upper_bound` 改求**非下降**；默认严格模式使用 `lower_bound`。不要把相等值能否延长混在一起。
- 不修改输入，每次调用独立。只返回长度，**tail 不是实际 LIS，不提供路径还原。** 逐位置数组的最后一项也不一定是全局最长长度。

总时间 `O(n log(n+1))`，辅助空间 `O(n)`。若要从右向左扫描，反转输入副本后调用，再反转长度结果；其语义是原位置开始、向右下降的长度，详见合唱队形复盘。

这是目标明确的固定算法，适合模板化；不据此把所有 DP 都封装为万能模板。
