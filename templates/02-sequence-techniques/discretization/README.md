# 离散化：建表与编号查找

适用：所有需要编号的值可以提前收集，元素总量与不同值个数均能用 `int` 表示。使用 C++11，统一保存为 `long long`，编号从 `1` 开始。

实现见 [discretization.hpp](discretization.hpp)，原理与来源见[2.3 离散化](../../../notes/02-sequence-techniques/03-discretization.md)。

## 接口与约定

| 接口 | 输入与返回 | 复杂度 |
| --- | --- | --- |
| `buildCoordinates(values)` | 复制、排序去重，返回升序原值表；不改变调用方数组 | `O(k log k)` 时间、`O(k)` 空间 |
| `getId(xs,x)` | `xs` 必须升序无重复；找到返回 `1..m`，未找到返回 `-1` | 单次 `O(log m)`，额外空间 `O(1)` |

其中 `k` 是收集总量，`m` 是不同值个数。空输入得到空表，空表查找返回 `-1`。

> **编号 `id` 对应的原值是 `xs[id-1]`。先确认 `id!=-1`，再访问原值或其他数组。**

## 最小使用示例

```cpp
#include "discretization.hpp"
#include <iostream>

int main() {
    std::vector<long long> a = {100, -5, 100, 7};
    auto xs = buildCoordinates(a); // xs = {-5,7,100}；a 的顺序不变

    for (long long x : a) {
        int id = getId(xs, x);
        std::cout << id << ' '; // 3 1 3 2
    }
    std::cout << '\n';

    int id = getId(xs, 8); // 第一个 >=8 的值是 100，但 8 本身未收录
    if (id != -1) {
        std::cout << xs[id - 1] << '\n';
    }
}
```

需要频率数组时，按编号访问可开 `m+1` 项；需要配合一基坐标差分时，再按具体边界要求预留位置。

**只查原数组值时的简化：** 若 `xs` 由完整原数组排序去重生成，且所有查询都来自该原数组，查询值必然存在，可以省略 `getId` 中检查 `it==xs.end() || *it!=x` 的一行。通用模板还支持未收录值和空表，因此保留检查及返回 `-1` 的接口约定；不能将这一简化无条件用于其他查询。

## 初始化与边界

- 每组数据重新收集并调用 `buildCoordinates`，不沿用上一组的坐标表。
- 左右端点必须放在同一张表中；不能分别编号后混用。
- 未收录的查询阈值应按 `lower_bound/upper_bound` 定位范围，不把 `-1` 当数组下标。
- 建表后不要插入新坐标而继续沿用旧编号；必要时重新建表或换用合适的数据结构。
- 编号保留相等与大小关系，不保留距离；差分和长度计算的类型、半开/闭区间由调用方明确。
