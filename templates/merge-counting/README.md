# 归并计数：严格逆序对

统计序列中 $i<j$ 且 $a_i>a_j$ 的数对，使用 C++11。来源与两题个人实现复盘见 [2.8 归并计数](../../notes/02-sequence-techniques/08-merge-counting.md#9-典题与复盘)。

实现：[merge_counting.hpp](merge_counting.hpp)。

## 接口与约定

- `ll count_inversions(vector<ll>& a)`：返回严格逆序对数，**同时把传入数组排成非降序**。
- 输入使用 `ll` 保存元素；算法只比较元素，不做元素加减，支持重复值、负数及有符号 64 位两端值。
- 0 下标、闭区间；元素数量必须能用 `int` 表示，先转换长度，再计算 `n-1`。
- 空数组、单元素与全相等数组返回 `0`；答案使用 `ll`。
- 辅助函数 `merge_count` 递归复用同一份缓冲区，通常只调用外层入口。

## 使用示例

```cpp
#include "merge_counting.hpp"
#include <iostream>

int main() {
    std::vector<ll> a = {3, 1, 2};

    // 需要保留原序列时，复制后再计数
    std::vector<ll> work(a);
    std::cout << count_inversions(work) << '\n'; // 2，work 变为 {1,2,3}
    std::cout << a[0] << '\n'; // 3，原序列不变
}
```

## 边界与维护

> **相等先取左边，右项较小时才增加 `mid-i+1`。** 改成非严格关系或其他数对条件时，应重新推导计数与归并规则。

每次调用重新创建缓冲区和递归局部答案，多测无需清理全局计数。对同一个已经排序的数组再次调用，结果为 `0`；需要重新统计原输入时须保留副本。

时间 $O(n\log n)$，缓冲区 $O(n)$，递归栈 $O(\log n)$，总额外空间 $O(n)$。复制原数组是可选的额外 $O(n)$ 成本。
