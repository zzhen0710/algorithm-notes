# Trie：完整字符串、前缀计数与双方前缀关系

实现：[trie.hpp](trie.hpp)。原理、图解与两题复盘见 [9.8 Trie](../../../notes/09-data-structures/08-trie.md)。

**节点是前缀，pass 数经过，end 数结束。** 一份插入与计数主实现；增加双方前缀关系查询，不混入点名状态或删除逻辑。

## 接口与状态

| 接口 | 含义 |
| --- | --- |
| `Trie<> dict` | 26 个小写字母，根编号 0，初始为空词典 |
| `Trie<2,'0'> dict` | 相同实现，字符表换成 0/1；不是整数最大异或接口 |
| `insert(s)` | 插入一次，重复字符串累计计数 |
| `find_node(s) const` | 返回 s 对应的前缀节点；路径不存在为 -1 |
| `count(s) const` | 恰好等于 s 的插入次数 |
| `prefix_count(s) const` | 以 s 为前缀的插入次数，包括等于 s 的字符串 |
| `prefix_related_count(s) const` | 任意一方为另一方前缀的插入次数；相等只算一次 |
| `clear()` | 恢复一个干净根，旧非根编号作废；容量可能保留 |

`tr[u].next[c]` 保存孩子编号，缺边为 -1；`pass/end` 是次数，不是布尔标记。路径存在且 end=0，表示只是已有单词的前缀。

## 字符、容量与副作用

- 模板参数 Sigma 与 Base 是编译期常量；字符映射为 `ch-Base`，调用者保证落在 `0..Sigma-1`。默认仅小写，二值版本仅 `'0'/'1'`，不支持任意大小写／数字混排或 Unicode；其他字符表需另外设计映射。
- 根和边编号均为 int，节点数及累计插入次数必须可用 int 表示，内存足够。若插入总长度为 S，节点数不超过 `S+1`，不是单词个数上界。
- 查询不建节点、不修改输入或词典；插入也不改传入字符串。节点编号在连续插入期间稳定，底层地址可能因 vector 扩容改变，不能保留跨扩容的引用或指针。
- 空词典可以查询，计数为 0。允许程序直接插入空串，计数留在根；空前缀统计全部插入次数。普通 `cin >> s` 的输入题不读取空串。
- 每组重建对象即可清空并在销毁时释放存储；clear 重置内容但不保证释放容量。不提供删除、动态字符表或对非法字符的防御分支。

## 复杂度

L 为本次字符串长度，V 为已建节点数，S 为所有插入字符总数，N 为插入次数。

| 操作 | 固定字符表下的时间 | 原因 |
| --- | --- | --- |
| 构造 | `O(1)` | 只建根 |
| insert | 摊还 `O(L+1)` | 沿路计数与追加节点；一次扩容可能搬迁 V 个节点 |
| find_node / count / prefix_count | 最坏 `O(L+1)` | 走一条路径后读取字段 |
| prefix_related_count | 最坏 `O(L+1)` | 严格前缀累加 end，终点加 pass |
| clear | `O(V)` 上界 | 重置节点池，不保证释放容量 |

空串操作仍为常数，因此保留 `+1`。从空树插入全部消息共 `O(S+N)`，空间 `O(Sigma×V)`；单次插入若扩容，最坏 `O(V+L+1)`。若 Sigma 当变量，非空串插入摊还 `O(Sigma×L)`，查询 `O(L+1)`，总建树 `O(S+N+Sigma×V)`。

**prefix_related_count 的两组互斥：沿途 end 只统计严格更短者，终点 pass 包括相等和更长者。** 缺边只排除后续消息，不清空已累计的更短消息；空查询返回根 pass，若有空串插入，也只计一次。

`vector` 实际容量可能大于节点数。已知可靠上界且内存允许时，可用 `dict.tr.reserve(S+1)` 减少扩容；它只预留容量，不创建节点。二值模型采用 Sigma=2，可避免为每个节点分配 26 条边。

## 简短使用

```cpp
#include "trie.hpp"

Trie<> dict;
dict.insert("app");
dict.insert("apple");
dict.insert("app");

int exact = dict.count("app");       // 2
int prefix = dict.prefix_count("ap"); // 3
int only_prefix = dict.count("ap");  // 0；路径存在，但没有完整单词。

Trie<2, '0'> bits;
bits.insert("001"); // 前导0也是路径的一部分。
int zero_prefix = bits.prefix_count("00"); // 1
int related = bits.prefix_related_count("0"); // 1；0 是消息 001 的前缀。
```

## 来源与核验

从本篇教学模型独立整理，不移植外部库代码。笔记使用固定 26 的展开类，模板用两个编译期常量复用同一实现；根、-1 哨兵、重复计数与只读查询语义一致。

**C++11 本地核验通过，编译无警告。** 对照独立单词频次与前缀扫描，检查共享路径、重复词、单词互为前缀、空串、未命中与查询不建节点、扩容、多对象及清空重用；字母与 01 两种字符表分别核对，并与既有模板共同包含。前缀关系查询另与逐条比较核对，包含等长、缺边、重复消息和空串。P2580/P2922原实现已本地核验并复盘，平台结果未单独记录；详细执行记录留在本地计划。
