# 单调队列：定长窗口最大值位置

实现：[monotonic_queue.hpp](monotonic_queue.hpp)。来源：[9.3 单调队列](../../../notes/09-data-structures/03-monotonic-queue.md)，按已有通用函数自行收敛。

## 接口与边界

- `window_max_positions(a,k)`：**0-based `vector<ll>`**，第 t 项返回窗口 `[t,t+k-1]` 的最大值下标，共 `n-k+1` 项；相等时选择**最右侧**位置。
- `k<=0` 或 `k>n` 返回空，空数组也没有完整窗口。元素数量可用 int 表示，元素可取任意 ll；只比较数值，不做相减。
- 使用 `a[pos[t]]` 取对应最值。队列保存候选，**不是窗口全部元素，也不代替窗口左右边界**。
- 先按左端点去过期，再从队尾删除不优于新值的候选；相等时删旧留新，因而返回最右位置。
- 求最小值时，只将队尾的 `a[q.back()] <= a[i]` 改为 `>=`，并相应修改函数名与结果含义；过期条件保持不变。

时间 `O(n)`；队列至多保存 `k` 个下标，返回结果至多 `n-k+1` 项，总辅助空间 `O(n)`。不修改输入，每次调用独立。变长窗口收缩条件依赖题意，继续留在笔记复盘中，不放进这个定长函数。

## 核验状态

C++11 独立编译与组合编译通过，未出现警告。最大值与上述最小值改法均与朴素窗口扫描对照，核对最右同值规则、k=1/n、非法 k、空数组、ll 边界和重复调用。不新增平台结果或个人熟练记录。
