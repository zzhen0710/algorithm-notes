# ST 表：静态闭区间最大值

实现：[sparse_table.hpp](sparse_table.hpp)。原理与复盘见 [9.5 ST 表](../../../notes/09-data-structures/05-sparse-table.md)。

**只记两件事：相邻两半建表，左右贴边查询。** 一份最大值主实现，不混入 CF 514D 的二分、预算和输出。

## 接口与前提

| 接口或状态 | 含义 |
| --- | --- |
| `SparseMax(a)` | 从 `a[1..n]` 建表，`a[0]` 为占位 |
| `query(l,r) const` | 返回非空闭区间 `[l,r]` 的最大值 |
| `st[k][i]` | 起点 i、长度 `1<<k` 的最大值，不是前缀最大值 |
| `lg[d]` | 不超过正长度 d 的最大二次幂的指数 |

要求 `1≤n<2³⁰`、内存足够、元素可用 ll 表示，查询满足 `1≤l≤r≤n`。不接受空数组、空区间和越界查询。

构造不修改输入，后续原数组变化也不会改变已建表的快照；不支持增量更新。每组数据重新构造，各对象独立，查询不改变状态。

```cpp
#include "sparse_table.hpp"

std::vector<ll> a = {0, -5, 8, 3}; // 下标 0 占位
SparseMax st(a);
ll x = st.query(1, 3); // 8
ll y = st.query(3, 3); // 3；单点同样合法
```

**预处理和空间 O(n log n)，每次查询 O(1)。** 查询长度恰好为 `1、2、4、8、…` 时两块重合，统一取 max 即可，不另加分支。

## 改法与限制

- 求最小值：建表、查询两处 `std::max` 都改为 `std::min`，不需要改成用 0 初始化答案。
- gcd、按位与／或也可按对应运算建表和查询；需保证合并满足结合律、重复覆盖不改变结果。
- **不能把 max 换成加法就求和**：两块可能重叠，重复部分会多算。静态区间和用前缀和。
- 只顺序扫描定长窗口时可用[单调队列模板](../monotonic-queue/README.md)，不一定需要 ST 的任意区间信息。
