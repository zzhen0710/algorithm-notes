# 实数线性方程组：高斯消元

实现：[gauss.hpp](gauss.hpp)。C++11，部分选主元、前向消元、回代；不依赖上一组矩阵快速幂模板。

```cpp
#include "gauss.hpp"

std::vector<std::vector<double>> a = {
    {0, 1, 1, 5},
    {1, 1, 1, 6},
    {2, 1, -1, 1}
};
GaussRes r = gauss(a);
// r.status==1，r.x 为按原未知数顺序排列的 (1,2,3)。
```

**输入：** n 个方程、m 个未知数的增广矩阵，n 行、m+1 列。0 基；前 m 列是系数，列 m 是右侧常数。n,m 均至少为 1，各行等长且元素有限，`eps>0`；函数不做非法输入检查。按值传参，不改原矩阵；多次调用无需额外清理。

| 返回成员 | 含义 |
| --- | --- |
| `status == 0` | 无解，`x` 为空 |
| `status == 1` | 唯一解，`x` 为完整解向量 |
| `status == 2` | 无穷多实数解，`x` 给出自由变量取 0 后的一组解 |
| `rank` | 系数部分的主元数，按 eps 数值判定 |

状态码只是接口约定，**不要直接当成题目要求的输出**。答案 `x[j]` 对应输入的第 j 个未知数；仅交换行，不打乱变量列。

**换行后的映射：** `swap(a[sel], a[row])` 后，主元行已在 `row`，必须记 `where[col]=row`；`sel` 的值不会自动变化。详见[交换前后示意图](../../../notes/07-math/10-gaussian-elimination.md#swap-之后where-记录主元现在的位置)。

**数值：** 使用 `double`，默认绝对阈值 `1e-9`。适用于输入量级与误差要求相称的竞赛实数方程组；极端量级或接近相关的方程需另评估判零与精度。输入为整数也可能得到小数解，不能替换为整数除法；本模板不处理取模方程组。输出舍入与负零按题意处理。

**复杂度：** 时间 $O(nm\min(n,m))$，n=m 时为 $O(n^3)$；额外空间 $O(nm)$，包括按值复制的工作矩阵。
