# DAG 期望：按条件概率汇总剩余代价

实现：[dag_expectation.hpp](dag_expectation.hpp)。来源：[7.13 基础概率与期望](../../../notes/07-math/13-probability-expectation.md#2-先给代码dag-上的期望剩余代价)；复用[拓扑排序](../../06-graph-and-tree/topological-sort/README.md)。

```cpp
#include "dag_expectation.hpp"

std::vector<std::vector<ProbEdge>> g(4);
g[1].push_back({2, 2.0, 0.25}); // {后继, 本步代价, 条件概率}
g[1].push_back({3, 6.0, 0.75});
g[2].push_back({3, 4.0, 1.0});
auto ex = dag_expected_cost(g); // ex[3]=0，ex[2]=4，ex[1]=6。
if (!ex.empty()) {
    double answer = ex[1];
}
```

**用途速记：** 输入每个状态的所有下一步、概率与代价，返回从各点直到某个无出边终点的期望剩余代价；通过逆拓扑序计算概率加权的 `cost + ex[v]`，不枚举全部完整路径。

| 输入／返回 | 约定 |
| --- | --- |
| `g` | 1-based，至少一个有效点，g[0] 不使用；端点均在 1..n |
| `ProbEdge {v,cost,p}` | v 为后继编号，cost 为本步非负有限代价，p 为当前状态下选择本边的概率 |
| 一轮概率 | 每个有出边点的 p 均在 0..1，全部出边总和为 1；由调用者保证，不自动归一／验证 |
| 状态完整性 | 同一点的后续规律不依赖未记录历史；否则先扩充状态 |
| 终点 | 所有无出边点停止，期望为 0；可有多个终点 |
| 返回值 | 有效 DAG 返回 n+1 个 double，ex[0] 不使用；有环或没有有效点返回空数组 |
| 副作用 | 不修改 g，无全局状态，无多测清理 |
| 时间／额外空间 | O(n+m)／O(n+m)；额外保存终点邻接表与拓扑数组，输入另计 |

**p 先由题目的随机规则确定，再交给本函数。** 等概率选择出边才用出度倒数；直接给出概率就读取，其他规则则先推导。选择权重与 cost 不可混为一谈，例子见[概率从哪里来](../../../notes/07-math/13-probability-expectation.md#p-从哪里来先读随机规则再填入边)。

完整图（包括概率为 0 的边）仍须是 DAG；函数不尝试忽略部分环。无出边的 0 是合法终值，不能当作未计算标记。需指定唯一终点时，调用者保证可达过程不会在其他点提前结束。

若 n≤200000、边代价≤$10^9$，路线至多 n−1 条边，期望量级不超过约 $2\times10^{14}$；double 仍是近似值，须按题目的绝对／相对误差要求选择输出精度。概率输入写实数除法，不能用整数除法或模逆元代替。

实数输出通常采用 `fixed << setprecision(10)`，明确指定小数位数时服从题意；输出位数不等于计算精度。[P4316](../../../notes/07-math/13-probability-expectation.md#91-p4316直接把等概率出边接到模板)就是按出度填概率后直接调用，依题意保留两位；[CF621C](../../../notes/07-math/13-probability-expectation.md#92-cf621c拆成相邻对的奖金贡献)只需逐项累加期望，不必调用 DAG 模板或再造包装函数。

教学例子使用不同分支概率；不是“所有完整路线等概率”。有环过程不套此模板，也不保证一定存在有限期望。基础概率公式与线性性留在知识笔记，不另做低价值包装函数。

通用代码独立核对完整小图路径加权，覆盖顺逆编号、合流、不同概率、多终点、零代价、单点、判环与长链；本轮提供的两题 solve 仅静态复盘，未编译／运行／对拍；这不代表平台通过或个人已经掌握。
