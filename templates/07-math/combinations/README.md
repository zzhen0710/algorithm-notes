# 组合数：精确计算与素数模数

使用 C++11。实现：[combinations.hpp](combinations.hpp)；推导与 CF 478B 复盘见 [7.5 基础计数](../../../notes/07-math/05-basic-counting.md#单次查询乘除递推)。

## 接口与约定

- `ll C(ll n, ll m)`：从 `n` 个不同对象中不重复选 `m` 个，返回**不计顺序的精确组合数**，不取模。
- 要求 **`n>=0`**；`m<0` 或 `m>n` 返回 0，`m=0` 或 `m=n` 返回 1，包括 `C(0,0)=1`。
- `ll` 为 `long long`。对合法参数，**每轮 `ans*(n-m+i)` 都必须不超过 `LLONG_MAX`**；函数不检测溢出，仅最终结果能表示并不足够。
- 便于使用的两个充分范围：**`0<=n<=60` 的任意合法 `m`**；或 **`n<=10^9` 且 `min(m,n-m)<=2`**。这些不是全部可用参数，只是方便记忆的安全范围。
- 无容器、下标或区间。参数按值传入，局部 `m` 会改为两边较小者；不修改调用处输入，无共享状态，多测无需清理。

设 $k=\min(m,n-m)$，合法参数的时间为 $O(k+1)$、辅助空间为 $O(1)$；非法 `m` 为常数处理。**小选取数可以配较大的 n，不必按 n 建表。**

## 使用示例

```cpp
#include "combinations.hpp"
#include <iostream>

int main() {
    std::cout << C(5, 2) << '\n';          // 10
    std::cout << C(0, 0) << '\n';          // 1
    std::cout << C(3, 4) << '\n';          // 0
    std::cout << C(1000000000LL, 2) << '\n'; // 499999999500000000
}
```

## 来源与边界

由 CF 478B 原稿的 `C` 提炼，**只加 `inline`、标准头文件与范围说明，不改计算逻辑**。具体分组最值公式留在题目复盘中，不放入组合数模板。

例如 $\binom{62}{31}=465428353255261088$ 本身可以用 `ll` 表示，但最后一轮乘完、尚未除以 31 时为 14428278950913093728，已经超限，**这个调用不在当前函数契约内**。

超出范围需要约分、更大的整数或其他算法，不能盲目复制本函数；模意义组合数也不能直接在这里追加 `%p`，改用下面符合条件的逆元写法。小范围多次查询还可用[组合数表](../../../notes/07-math/05-basic-counting.md#5-小范围组合数表按选或不选递推)，避免为每次查询重新计算。

模板已完成本地编译与有效范围内的数值核验；平台 AC 和个人熟练程度仍按实际记录。

## 素数模数：阶乘与阶乘逆元

实现：[mod_combinations.hpp](mod_combinations.hpp)。推导与条件见 [7.6 模逆元与组合数取模](../../../notes/07-math/06-modular-inverse-combinations.md)。原有 combinations.hpp 的精确 C 接口不变。

- **构造：** ModComb(N,p)，要求 `0 ≤ N < p < 2³¹`、p 为素数且内存足够；不在构造时检测这些条件。
- **存储：** fact、ifact 各 N+1 项，下标 0..N，保存 i! 的余数及其逆元；N 是最大查询上限，不是模数大小。
- **查询：** 对 0≤n≤N，C(n,k) 返回组合数的规范余数；k<0 或 k>n 返回 0。n<0／n>N 不在契约内，不能据此当作答案为 0。
- **边界：** N=0、C(0,0)=1；N≥p 时阶乘不可逆，必须更换算法。与允许任意模数的杨辉三角递推不同。
- **数值与状态：** ll 保存乘积，每次乘两个规范余数后取模。构造不改外部输入，查询只读；每组新建对象，改变 N 或 p 后重新构造，不直接修改已有表和模数。
- **复杂度：** 预处理 O(N+log p)，空间 O(N)，每次查询 O(1)。
- **依赖：** 自动包含 [modular_inverse.hpp](../modular-arithmetic/modular_inverse.hpp)，再复用原快速幂；复制单文件时按 mod_pow、inv_prime、ModComb 的顺序展开，删除相对 include。

```cpp
#include "mod_combinations.hpp"

ModComb comb(5, 7);
ll a = comb.C(5, 2); // 3
ll b = comb.C(0, 0); // 1
ll c = comb.C(3, 4); // 0
```

模意义组合数为独立整理的一种主写法，不更改个人原稿的精确组合数函数。两份头文件可共同包含；全局 C 返回精确值，comb.C 返回模数下的值。

模组合实现已与杨辉三角对照并完成大上限、边界及依赖核验；P1313／CF300C 原实现复盘见 [7.6 典题](../../../notes/07-math/06-modular-inverse-combinations.md#8-典题与复盘)，均已本地核验，平台结果未单独提供。两题共用现有实现，不另建重复模板。
