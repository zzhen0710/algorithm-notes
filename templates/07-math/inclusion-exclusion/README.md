# 容斥：已知交集的并集计数

[知识笔记与证明](../../../notes/07-math/07-inclusion-exclusion.md) · [实现](inclusion_exclusion.hpp)

## 接口与前提

**用途速记：** 需要调用者提供每个非空集合组合的交集数量；函数按奇加偶减求并集数量。倍数交集可由 n/lcm 求出，但不是所有题都用 lcm；两三类集合或结构简单时，直接列式即可。

`ll inclusion_exclusion(const std::vector<ll>& inter)`：按“奇数个集合加、偶数个集合减”，返回所有集合的并集大小。

- k 是集合数量；每个集合选或不选，共 2ᵏ 种组合，其中 2ᵏ−1 种非空。inter 长度为 `1 << k`，保留下标 0；要求 0≤k≤20，bit 从 0 开始。
- **非空 mask 保存所选集合的真实交集大小，不是并集、独占区域或各数量的乘积。** 所有数据必须描述同一批集合。
- inter[0] 不使用，可填 0；长度为 1 表示零个集合，函数返回 0；空 vector 不在契约内。
- 使用 ll，所有交集数量非负，且**中间带符号累加也必须能表示**。一个简单充分条件是所有非空项之和不超过 LLONG_MAX；函数不检测溢出或表的合法性。
- 只读输入，没有外部状态，多测可直接再次调用。头文件无其他本仓库依赖。
- 使用 GCC/Clang 的 __builtin_popcount 扩展，C++11 下可用；其他编译器需替换位计数。
- 固定 32 位 mask 下，累加时间 O(2ᵏ)、额外空间 O(1)；输入表 O(2ᵏ)。**构造交集表的时间另计。**

## 使用示例

```cpp
#include "inclusion_exclusion.hpp"

// 三集合的下标依次为：空、A、B、AB、C、AC、BC、ABC。
std::vector<ll> inter = {0, 15, 10, 5, 6, 3, 2, 1};
ll covered = inclusion_exclusion(inter); // 22
ll none = 30 - covered;                 // 8；全集大小由调用者提供
```

函数只做交替累加。交集如何求、全集多大、结果是否取补集，均由题目决定；不把倍数、棋盘等题目逻辑塞进通用实现。两三类时直接列式通常更便于默写。
