# 基础博弈：单堆固定取法与标准 Nim

实现：[basic_games.hpp](basic_games.hpp)。来源：[7.14 基础博弈](../../../notes/07-math/14-basic-games.md)。

```cpp
#include "basic_games.hpp"

auto win = subtraction_wins(7, {1, 3, 4}); // win[2]=0，win[6]=1，win[7]=0。
bool first = nim_first_wins({3, 4, 5});   // true；{1,4,5} 为 false。
```

**用途速记：** 固定单堆取法用胜负表，按已知的小状态判断是否能把对手送到败态；标准 Nim 用异或判断多堆局面。二者的游戏规则不同，不把单堆布尔结果异或来替代 Nim。

**两个接口对应不同游戏：** 前者一堆且取走量受 moves 限制；后者每次只选一堆，但可从中任取正数颗。不能把固定取法简单改成多堆，就调用 Nim 接口；[规则对照与一堆 2 颗的反例](../../../notes/07-math/14-basic-games.md#5-nim多堆状态太多时先核对规则)见知识笔记。

| 接口 | 输入前提 | 返回与复杂度 |
| --- | --- | --- |
| `subtraction_wins(n,moves)` | n≥0，能分配 n+1 个位置；moves 每项为正，两人规则相同，无法操作者输 | 下标 0..n 的 `vector<char>`，值 0/1 表示当前玩家败/胜；O(nk+n) 时间、O(n)空间，k 为取法条目数 |
| `nim_first_wins(piles)` | 每堆为非负 ll；一次只从一堆任取正数，可取完，无法操作者输 | bool，true 表示当前先手有必胜策略；O(h) 时间、O(1)额外空间，h 为堆数 |

**Nim 判定只计算异或和是否为 0，不实际模拟取石子。** 每列 1 的奇偶用异或记录，非 0 时存在合法的恢复操作；多位翻转也只要求整堆净减少。若另要输出一步，才构造新大小 `x ^ S`，实际取走 `x - (x ^ S)` 颗，见[判定与构造的区别](../../../notes/07-math/14-basic-games.md#66-回到代码只判定不必实际模拟取石子)。

两函数均只读输入、局部初始化，没有多测清理；重复调用不会共享状态。取法不要求排序；空取法全部必败，空堆数组或全零 Nim 返回 false。石子不足的取法在单堆表中自动跳过。

`vector<char>` 存的是数值标记，直接输出元素会按字符显示；查询时作条件判断或转换为 int，题目要求人名/Yes/No 时由调用者映射。n+1 必须能用 int 表示且内存足够；不累计各堆总数，因此 Nim 堆总和超过 ll 不影响本函数。

不能操作者获胜、允许不取/加石子、一次修改多堆、有限取数等规则，不属于标准 Nim 接口；本组不提供 SG 或任意图博弈的万能封装。构造获胜一步的公式与合法性见[异或证明](../../../notes/07-math/14-basic-games.md#6-为什么异或能够决定胜负)。
