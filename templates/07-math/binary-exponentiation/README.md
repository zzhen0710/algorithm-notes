# 快速幂：整数模幂

使用 C++11。实现：[binary_exponentiation.hpp](binary_exponentiation.hpp)；原理、证明与典题见 [7.3 快速幂](../../../notes/07-math/03-binary-exponentiation.md#4-注释实现)。主写法只维护一份迭代函数。

## 接口与约定

- `ll mod_pow(ll a, ll b, ll p)`：返回 $a^b\bmod p$ 的**规范余数**，结果在 `0..p-1`。
- `ll` 为 `long long`。底数 `a` 可为任意 `ll`，包括负数和 `LLONG_MIN`；先取模，再调整负余数，不对底数取绝对值。
- **`0<=b<=LLONG_MAX`，`1<=p<2^31`**。不要求底数与模数互质，也不要求模数为质数。
- 零次幂按空乘积 1 处理，包括本函数对 $0^0$ 的约定；**`p=1` 时始终返回 0**。
- 只有标量，无下标、区间或容器容量约定。参数按值接收，不修改调用处输入；所有状态在函数内初始化，每次调用独立，**多测无需清理**。

> **模数范围是为了保证直接乘法不溢出。** 规范化后两个因子都小于 $2^{31}$，乘积小于 $2^{62}$，可用 `ll` 表示。函数不检测非法参数，也不负责更大模数下的安全乘法。

时间为 $O(1+\log(b+1))$，辅助空间 $O(1)$；指数为 0 时直接返回。底数可以取模，**不能把指数直接按模数取模**。

## 使用示例

```cpp
#include "binary_exponentiation.hpp"
#include <iostream>

int main() {
    std::cout << mod_pow(3, 13, 1000) << '\n'; // 323
    std::cout << mod_pow(2, 0, 7) << '\n';     // 1
    std::cout << mod_pow(2, 0, 1) << '\n';     // 0
    std::cout << mod_pow(-2, 3, 11) << '\n';   // 3
    std::cout << mod_pow(0, 5, 7) << '\n';     // 0
}
```
