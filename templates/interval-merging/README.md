# 区间合并：合并覆盖与并集长度

实现：[interval_merging.hpp](interval_merging.hpp)。来源：[P1496 的排序合并实现](../../notes/02-sequence-techniques/03-discretization.md#另一种做法排序合并区间)，自行提炼。

## 接口与边界

- `merge_intervals(a)`：输入为 `vector<pair<ll,ll>>`，每对表示**半开区间 `[l,r)`**，要求 `l<=r`。返回按左端点递增、互不相交且不再相接的非空合并区间。
- 空输入返回空；`l==r` 的空区间被忽略；相交或首尾相接就合并。例如 `[1,3)` 与 `[3,5)` 合为 `[1,5)`。
- 端点可为任意 ll，合并过程只比较、不做端点加减；**不会擅自交换非法的左右端点。**
- `union_length(a)`：先合并再累计 `r-l`；除端点合法外，要求每次相减及最终总长度都能用 ll 表示。
- 两接口按值接收，内部排序，不改变调用方的数组；所有状态局部初始化，多次调用独立。

本接口面向连续长度或已采用半开表示的问题。**不要直接用它数整数闭区间覆盖点数**；离散端点的转换和可能溢出的 `r+1` 应先按题意处理。

与[区间选择模板](../interval-scheduling/README.md)区别：这里保留全部覆盖并合并重叠；后者放弃冲突候选，求最多选择条数。两者不能互相替代。

时间 `O(n log(n+1))`，含按值输入与返回结果的额外空间 `O(n)`。通过返回合并区间统一复用，不另写一份只算长度的合并循环。
